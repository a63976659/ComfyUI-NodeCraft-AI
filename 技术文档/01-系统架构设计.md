## Tab 隔离层（跨前后端与智能体）

三个 Tab（开发插件 `develop` / 优化插件 `optimize` / 功能可视化 `visualize`）在架构上贯穿前后端与智能体三层，形成完整的**Tab 隔离层**：

```
前端：读取当前 activeTab → 聊天请求体携带 activeTab 字段
    ↓
后端：聊天路由接收 activeTab → 选择差异化系统提示词
    → develop  → "ComfyUI 插件开发专家"
    → optimize → "ComfyUI 插件性能优化专家"
    → visualize→ "ComfyUI 插件功能分析专家"
    ↓
智能体：工具路由器选择对应 BM25 实例
    → 知识库/开发插件/   (FAQ加载)
    → 知识库/优化插件/  (FAQ加载)
    → 知识库/功能可视化/ (不加 FAQ)
```

- 知识库目录重组为 `知识库/{开发插件|优化插件|功能可视化}/` 三子目录，不同 Tab 的知识互不交叉（前端 tab 逻辑标识符 develop/optimize/visualize 通过 `TAB_FOLDER_MAP` 映射为中文目录名）
- BM25 引擎从全局单例升级为按 Tab 多实例字典，每 Tab 索引完全独立
- FAQ 检索（`数据/踩坑记录/*.json`）仅在 develop / optimize Tab 中启用，visualize 不需要

## 中间件链说明

每个 HTTP 请求按如下顺序经过中间件处理：

```
请求到达
    │
    ▼
[审计中间件] audit_middleware
    │  记录请求元数据（IP、路径、User-Agent、时间戳）
    ▼
[速率限制] RateLimiter
    │  60 次/分钟/IP，超限返回 429
    ▼
[认证检查] _check_auth
    │  开关延迟实现：单用户模式下跳过，多用户模式验证 JWT
    ▼
[业务处理] 各路由处理函数
    │  执行具体业务逻辑
    ▼
[审计完成] 写入响应状态码和耗时到日志
    ▼
返回响应
```

#### CSRF 防护与豁免

写操作（POST/PUT/DELETE/PATCH）请求受 CSRF 令牌校验保护。以下预认证端点因用户尚未持有会话而被豁免：

| 豁免端点 | 用途 |
|---------|------|
| `/nca/billing/verify-login` | RanKing 账号登录验证 |
| `/ai-coder/auth/login` | 本地账号登录 |
| `/ai-coder/auth/register` | 本地账号注册 |
| `/ai-coder/auth/refresh` | Token 刷新 |

GET/HEAD/OPTIONS 请求自动豁免。已认证后的敏感写操作（`/nca/billing/deduct`、`/nca/billing/refund`、`/ai-coder/auth/logout`）仍强制校验 CSRF。

## 模块间通信方式

- **前端 ↔ 后端**：HTTP REST API（JSON 格式）
- **前端 ← 后端**：SSE 流式响应（text/event-stream）
- **前端 ↔ 后端**：WebSocket（aiohttp 内置，心跳 30s）
- **后端 → 智能体**：Python 函数调用（同进程内）
- **智能体 → 知识库**：BM25 密集检索（Markdown 文件）
- **智能体 → LLM**：HTTP 请求（OpenAI 兼容 API）或 TextIteratorStreamer（本地）

```

    │
    ▼

    │  POST /ai-coder/chat-stream

    │  data: {"token": "...", "done": false}
    ▼

    ▼

### WebSocket 通信数据流

```

    │  GET /ai-coder/ws?token=<jwt>
    ▼

    │  失败则关闭连接（code 4001）

    │  1s → 2s → 4s → 最多 30s

## ComfyUI 集成方式

### 1. 侧边栏注册

通过 `app.extensionManager.registerSidebarTab()` 注册：

```javascript
{
    id: "com.aicoder.sidebar",
    icon: "pi pi-code",
    title: "AI 插件助手",
    type: "custom"
}
```

### 2. 前端资源加载

通过 `__init__.py` 中的 `WEB_DIRECTORY` 声明前端目录，ComfyUI 自动加载其中的 JS/CSS 文件。

### 3. 路径集成

使用 ComfyUI 的 `folder_paths` 模块获取系统路径：
- `folder_paths.get_folder_paths("custom_nodes")` → custom_nodes 目录
- `folder_paths.models_dir` → models 目录（用于定位 LLM 模型）

### 4. 路由注册

通过 `__init__.py` 中的 `aiohttp` 路由注册，挂载到 ComfyUI 的 Web 服务器上。
