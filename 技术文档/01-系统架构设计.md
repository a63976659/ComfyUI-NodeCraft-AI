## 前端模块职责划分

| 模块 | 文件 | 职责 |
|------|------|------|
| 侧边栏入口 | `侧边栏入口.js` | 向 ComfyUI extensionManager 注册侧边栏面板，ID: `com.aicoder.sidebar`，图标 `pi pi-code`，标题 "AI 插件助手" |
| 会话视图管理器 | `会话视图管理器.js` | UI 渲染：标题栏（新建插件、设置按钮）、聊天历史区域、输入框 + 发送按钮 |
| 交互与状态 | `交互与状态.js` | HTTP 客户端封装，POST 请求到后端 API，管理前端状态 |
| 样式表 | `样式表.css` | 使用 ComfyUI CSS 变量（`--comfy-*`）集成主题，响应式布局 |

---

## 后端模块职责划分

| 模块 | 文件 | 职责 |
|------|------|------|
| 接口路由 | `接口路由.py` | 定义 aiohttp 路由，处理 HTTP 请求，协调智能体与文件操作 |
| 文件读写操作 | `文件读写操作.py` | 插件脚手架创建（`create_plugin_scaffold()`），文件/目录操作 |
| 系统环境映射 | `系统环境映射.py` | 获取 ComfyUI 路径（`get_custom_nodes_path()`、`get_default_llm_path()`） |

### 后端路由表（9 个端点）

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/ai-coder/sessions` | 获取会话列表 |
| POST | `/ai-coder/sessions` | 创建新会话 |
| DELETE | `/ai-coder/sessions/{id}` | 删除会话 |
| GET | `/ai-coder/sessions/{id}/messages` | 获取会话消息 |
| POST | `/ai-coder/chat` | 聊天（支持附件） |
| GET | `/ai-coder/settings` | 获取设置 |
| POST | `/ai-coder/settings` | 保存设置 |
| GET | `/ai-coder/local-models` | 扫描本地模型 |
| POST | `/ai-coder/create-folder` | 创建插件脚手架 |

## 智能体模块职责划分

| 模块 | 文件 | 职责 |
|------|------|------|
| 模型客户端 | `模型客户端.py` | `AICoderClient` 类，OpenAI 兼容 API 调用，默认 qwen2.5-coder-32b-instruct，温度 0.2 |
| 工具路由器 | `工具路由器.py` | `ToolRouter` 类，关键词匹配意图（UI/模型/路径/节点），读取知识库 Markdown |
| 记忆与上下文压缩 | `记忆与上下文压缩.py` | `ContextManager` 类，tiktoken cl100k_base 编码器，4000 token 限制，滑动窗口压缩 |

---

## 模块间通信方式

- **前端 ↔ 后端**：HTTP REST API（JSON 格式）
- **后端 → 智能体**：Python 函数调用（同进程内）
- **智能体 → 知识库**：文件系统读取（Markdown 文件）
- **智能体 → LLM**：HTTP 请求（OpenAI 兼容 API）

## 数据流图

### 基本对话流程

```
用户输入消息
    │
    ▼
[前端] 交互与状态.js
    │  POST /ai-coder/chat {message: "..."}
    ▼
[后端] 接口路由.py
    │  解析请求，调用智能体
    ▼
[智能体] 记忆与上下文压缩.py
    │  存储用户消息到上下文
    ▼
[智能体] 工具路由器.py
    │  关键词匹配意图 → 读取对应知识库文档
    ▼
[智能体] 记忆与上下文压缩.py
    │  获取压缩后的历史上下文
    ▼
[智能体] 模型客户端.py
    │  构造 messages = [系统提示词 + 知识库内容 + 压缩历史 + 当前消息]
    │  调用 LLM API
    ▼
[智能体] 记忆与上下文压缩.py
    │  存储 AI 回复到上下文
    ▼
[后端] 接口路由.py
    │  返回 JSON 响应
    ▼
[前端] 会话视图管理器.js
    │  渲染 AI 回复到聊天区域
    ▼
用户看到回复
```

### 附件上传流程

```
用户点击"+"按钮选择文件
    │
    ▼
[前端] 会话视图管理器.js
    │  读取文件 → 生成缩略图预览
    │  FileReader → base64 编码
    ▼
[前端] 交互与状态.js
    │  POST /ai-coder/chat {message, attachments: [{name, type, data(base64)}]}
    ▼
[后端] 接口路由.py
    │  解析 attachments → 提取文件信息
    │  将附件元数据保存到消息记录
    ▼
[智能体] 模型客户端.py
    │  将附件内容注入 LLM 上下文
    ▼
返回 AI 回复
```

### 本地模型推理流程

```
用户在设置面板选择"本地模型"
    │
    ▼
[前端] GET /ai-coder/local-models
    │  获取 models/LLM 目录下的模型列表
    ▼
用户选择模型并发送消息
    │
    ▼
[后端] 接口路由.py
    │  检测设置中的模型来源 = "local"
    ▼
[智能体] LocalModelClient
    │  AutoModelForCausalLM.from_pretrained(path, device_map="auto")
    │  AutoTokenizer.from_pretrained(path)
    │  asyncio.run_in_executor 异步推理
    ▼
[后端] 返回推理结果
    ▼
[前端] 渲染 AI 回复
```

## ComfyUI 集成方式

### 1. 侧边栏注册

通过 `app.extensionManager.registerSidebarTab()` 注册：

```javascript
{
    id: "com.aicoder.sidebar",
    icon: "pi pi-code",
    title: "AI 插件助手",
    type: "custom"
}
```

### 2. 前端资源加载

通过 `__init__.py` 中的 `WEB_DIRECTORY` 声明前端目录，ComfyUI 自动加载其中的 JS/CSS 文件。

### 3. 路径集成

使用 ComfyUI 的 `folder_paths` 模块获取系统路径：
- `folder_paths.get_folder_paths("custom_nodes")` → custom_nodes 目录
- `folder_paths.models_dir` → models 目录（用于定位 LLM 模型）

### 4. 路由注册

通过 `__init__.py` 中的 `aiohttp` 路由注册，挂载到 ComfyUI 的 Web 服务器上。
