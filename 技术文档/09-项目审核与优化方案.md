## Critical 级问题（必须立即修复）

### C1: XSS 漏洞 — Markdown 渲染未消毒

**文件**: `前端/消息渲染器.js`  
**问题**: 消息通过 `innerHTML` 直接注入 DOM，AI/用户生成内容未经 XSS 过滤  
**风险**: 恶意用户可注入脚本窃取 Token 或执行任意操作  
**修复方案**:
- 引入 DOMPurify 库对 marked.js 输出进行消毒
- 或使用 `textContent` + 自定义安全渲染器

### C2: 依赖版本未锁定

**文件**: `requirements.txt`、`云端Space代码/requirements.txt`  
**问题**: 使用 `>=` 最小版本约束，无上限锁定  
**风险**: 不同环境可能安装不同版本导致运行时错误、安全漏洞  
**修复方案**:
- 生成 `requirements.lock` 精确锁定版本
- 或改用 `~=` 兼容版本约束

**修复状态**: ✅已修复（requirements.txt 版本锁定）

### C3: 云端 API 缺少速率限制

**文件**: `云端Space代码/app.py`  
**问题**: 开放 API 端点无请求频率限制，可被暴力攻击或滥用  
**修复方案**:
- 添加 IP 级别速率限制中间件
- 关键端点（登录、文件上传）设置更严格阈值

## High 级问题（本周内修复）

### H1: JWT 密钥硬编码在源码中

**文件**: `后端/认证中间件.py` 第 31 行  
**问题**: `JWT_SECRET = "ComfyUI-Ranking-JWT-Secret-v2-beta-2026"` 直接写在源码中  
**风险**: 源码泄露时密钥立即暴露，Git 历史无法清除  
**修复方案**: 改为从环境变量 `RANKING_JWT_SECRET` 读取，提供默认值仅用于开发模式

**修复状态**: ✅已修复（改用 RANKING_JWT_SECRET 环境变量）

### H2: Token 存储在 localStorage

**文件**: `前端/交互与状态.js`  
**问题**: JWT Token 存储在 localStorage，易被 XSS 攻击读取  
**修复方案**: 改为 HttpOnly Cookie 或内存存储 + sessionStorage 折中方案

### H3: 缺少 CSRF 防护

**文件**: `前端/交互与状态.js`  
**问题**: POST/PUT/DELETE 请求未携带 CSRF Token  
**修复方案**: 添加 X-CSRF-Token 请求头验证机制

**修复状态**: ✅已修复（CSRF中间件 + 豁免预认证端点）

### H4: 文件上传缺少大小/类型预校验

**文件**: `后端/接口路由.py`  
**问题**: 文件上传端点未在早期阶段校验文件大小，可能耗尽内存  
**修复方案**: 在读取请求体前检查 Content-Length 头，拒绝超大文件

### H5: 消息流式高度估算不准确

**文件**: `前端/消息渲染器.js`  
**问题**: 流式输出时容器高度动态变化导致页面抖动  
**修复方案**: 使用 ResizeObserver + requestAnimationFrame 平滑更新

## Medium 级问题（两周内改进）

### M1: 外部 API 超时/重试不完善

**文件**: `后端/魔搭同步.py`、`后端/知识库同步.py`  
**问题**: 部分外部 API 调用缺少超时配置或指数退避重试  
**修复方案**: 统一使用带超时的 aiohttp.ClientSession + tenacity 重试装饰器

### M2: 缺少断路器模式

**文件**: `云端Space代码/数据库连接.py`  
**问题**: ModelScope 上传持续失败时仍不断重试，浪费资源  
**修复方案**: 实现简单断路器（连续 N 次失败后暂停，定时探测恢复）

### M3: 前端缺少内存泄漏防护

**文件**: `前端/消息渲染器.js`  
**问题**: 事件监听器和定时器缺少清理机制，长时间使用可能内存溢出  
**修复方案**: 添加 destroy/cleanup 方法，在组件卸载时清理

**修复状态**: ✅已修复（事件监听器清理注册表）

### M4: GraphQL 查询缺少复杂度限制

**文件**: `后端/GraphQL模式/`  
**问题**: 恶意客户端可构造深层嵌套查询耗尽服务器资源  
**修复方案**: 添加查询深度限制和复杂度评分

### M5: 错误消息可能泄露内部信息

**文件**: 多个路由文件  
**问题**: 部分异常直接将 `str(e)` 返回给客户端，可能暴露文件路径等  
**修复方案**: 生产模式下仅返回通用错误消息，详细信息只记录日志

### M6: 用户查询 O(n) 复杂度

**文件**: `云端Space代码/数据库连接.py`  
**问题**: JSON 文件存储的用户查询为线性扫描  
**修复方案**: 构建内存索引或改用 SQLite

### M7: 日志未脱敏

**文件**: `云端Space代码/app.py`  
**问题**: 用户 ID、交易金额等可能直接打印到日志  
**修复方案**: 添加日志脱敏工具函数（截断/掩码）

### M8: 缺少幂等性保护

**文件**: `前端/交互与状态.js`  
**问题**: 用户快速点击发送可能产生重复请求  
**修复方案**: 前端 disable 按钮 + 后端 idempotency_key 校验
