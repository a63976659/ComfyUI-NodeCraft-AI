# ComfyUI-NodeCraft-AI 项目总览

> 本文档提供项目的整体概述，包括定位、技术栈和目录结构。  
> 最后更新时间：2026-06-22

---

## 项目名称

**ComfyUI-NodeCraft-AI**（节点梦工厂）

## 一句话定位

ComfyUI 侧边栏 AI 编程工具，利用 AI 模型编程能力帮助用户快速编写 ComfyUI 自定义节点插件。

## 核心价值

降低 ComfyUI 插件开发门槛，AI + 规范知识库确保生成代码可直接运行。经过四阶段商业级优化，已具备企业级安全性、流式交互、多用户认证与容器化部署能力。

**当前版本**：v0.3.2

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | JavaScript（ES Modules）/ CSS | ComfyUI 侧边栏 UI，多模块架构，CSS 拆分为 14 个子模块，响应式设计，SSE 流式渲染 |
| 后端 | Python / aiohttp | REST API（30+ 端点）、SSE 流式响应、WebSocket、速率限制、审计中间件、可视化双模式分析 |
| 智能体 | OpenAI 兼容 API / transformers / tiktoken | LLM 调用（API + 本地推理）、本地模型 `<tool_call>` XML 工具调用适配层、上下文压缩、BM25 意图检索 |
| 知识库 | Markdown / BM25（纯 Python） | 结构化技能文档，68 段索引，bigram 中英文分词，LRU 缓存 |
| 认证 | JWT（自实现 HMAC-SHA256）/ PBKDF2 | 双 Token（access 15min + refresh 7天）、用户目录隔离、向后兼容单用户 |
| 安全 | RateLimiter / 路径穿越防护 / 输入验证 | 60次/分钟/IP 限制，路径 is_relative_to() 校验，名称长度+保留字检测 |
| GitHub集成 | aiohttp / GitHub REST API / cryptography | Git Trees API 批量查询，5 并发上传，指数退避，断点续传 |
| 量化加速 | BitsAndBytes（可选）/ Flash Attention 2（可选） | 4-bit/8-bit 量化，torch.inference_mode()，KV Cache |
| 实时通信 | WebSocket（aiohttp 内置）/ SSE | WS 心跳 30s，指数退避重连；SSE 打字机效果，停止生成 |
| 可观测性 | MetricsCollector / 审计日志（JSONL）/ OpenAPI | 线程安全指标收集，30天日志轮转，Swagger UI |
| 部署 | Docker / docker-compose | 多阶段构建，GPU 直通配置，健康检查 |

## 项目目录结构

```
ComfyUI-NodeCraft-AI/
├── 前端/                          # ~1800 行 JS + 14 个 CSS 子模块
│   ├── 侧边栏入口.js              # ComfyUI 侧边栏注册，事件清理注册表
│   ├── 交互与状态.js              # HTTP/SSE 客户端，状态管理，事件系统
│   ├── 会话视图管理器.js          # 主协调器：三标签页架构，面板切换资源释放
│   ├── 消息渲染器.js              # 消息渲染，SSE 实时流，停止生成按钮
│   ├── 工具函数.js                # 通用工具函数，常量定义
│   ├── 设置面板.js                # 模型设置 + GitHub 设置 Tab 页
│   ├── 插件开发面板.js            # 插件创建对话框，模板市场卡片 UI
│   ├── 可视化引擎.js              # 3D 力导向图渲染（3d-force-graph 封装）
│   ├── 可视化面板.js              # 双模式（文件模式 / 功能模式）面板与操作栏
│   ├── ...                          # 附件上传、文件夹选择、GitHub 同步、模板市场、插件打包、优化面板等组件
│   ├── 样式表.css                 # 主入口：仅含 @import 聚合
│   └── 样式/                       # 14 个 CSS 子模块
│       ├── 变量与动画.css
│       ├── 布局与容器.css
│       ├── 品牌栏与头部.css
│       ├── 会话列表.css
│       ├── 消息与聊天.css
│       ├── 输入与附件.css
│       ├── 面板与对话框.css
│       ├── 状态栏与底部.css
│       ├── 关于页面.css
│       ├── 文件夹选择器.css
│       ├── 可视化面板.css
│       ├── GitHub同步.css
│       ├── 监控与警告.css
│       └── 响应式设计.css
├── 后端/                          # ~5000 行，17+ 个 Python 文件
│   ├── 接口路由.py                # API 路由定义（30+ 端点），_error_response/_success_response
│   ├── 认证中间件.py              # JWT 签发/验证，PBKDF2 密码哈希，_check_auth
│   ├── 审计日志.py                # JSONL 按天轮转，多条件查询，audit_middleware，30天清理
│   ├── 性能监控.py                # MetricsCollector（线程安全），GET /ai-coder/metrics
│   ├── 文件读写操作.py            # 会话 CRUD，设置加密存储，插件脚手架
│   ├── GitHub同步.py              # GitHub 同步，批量 SHA，5 并发，断点续传
│   ├── 插件分析器.py              # AST 节点提取，依赖分析
│   ├── 插件打包.py                # zip 打包，自动生成 README/pyproject.toml
│   ├── 模板市场.py                # 5 个内置插件模板，GET/POST /ai-coder/templates
│   ├── 模型市场.py                # HuggingFace 搜索/详情/下载，纯 aiohttp
│   ├── 可视化分析.py              # 插件双模式可视化（文件/功能）+ 可视化/ 目录持久化
│   ├── 接口文档.py                # OpenAPI spec（27 端点），Swagger UI
│   └── 系统环境映射.py              # ComfyUI 路径获取
├── 智能体/
│   ├── 工具路由器.py              # BM25 检索引擎，68 段索引，LRU 缓存
│   ├── 模型客户端.py              # LLM 调用，TextIteratorStreamer 流式推理
│   ├── 本地模型客户端.py          # transformers 本地推理，含工具调用循环
│   ├── 本地模型工具解析器.py      # `<tool_call>` XML 标记解析与 JSON 容错修复
│   └── 记忆与上下文压缩.py        # 上下文管理，_build_chat_context 公共函数
├── 知识库/                        # 结构化技能文档（BM25 检索，脚手架指南置顶）
├── 技术文档/                      # 项目技术文档（10 个文件）
├── 数据/                          # 运行时数据（会话、设置）
├── tests/                         # pytest 测试套件，73+ 单元测试
├── Dockerfile                     # 多阶段构建
├── docker-compose.yml             # GPU 直通，健康检查
├── .dockerignore
├── deploy/README-deploy.md        # 部署指南
├── requirements.txt               # Python 依赖
└── __init__.py                    # ComfyUI 插件入口
```
