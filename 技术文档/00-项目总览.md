# ComfyUI-NodeCraft-AI 项目总览

> 本文档提供项目的整体概述，包括定位、技术栈和目录结构。  
> 最后更新时间：2026-06-12

---

## 项目名称

**ComfyUI-NodeCraft-AI**

## 一句话定位

ComfyUI 侧边栏 AI 编程工具，利用 AI 模型编程能力帮助用户快速编写 ComfyUI 自定义节点插件。

## 核心价值

降低 ComfyUI 插件开发门槛，AI + 规范知识库确保生成代码可直接运行。

---

## 版本

**当前版本**：v0.1.0

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | JavaScript / CSS | ComfyUI 侧边栏 UI，支持文件上传、附件预览、模型切换、Markdown 渲染 |
| 后端 | Python / aiohttp | REST API 路由，会话持久化、本地模型推理、附件处理、文件操作 |
| 智能体 | OpenAI 兼容 API / transformers / tiktoken | LLM 调用（API + 本地推理）、上下文压缩、意图识别 |
| 知识库 | Markdown | 结构化技能文档，RAG 按需检索 |

---

## 项目目录结构

```
ComfyUI-NodeCraft-AI/
├── 前端/
│   ├── 交互与状态.js          # HTTP 客户端，状态管理
│   ├── 会话视图管理器.js      # UI 渲染，聊天界面
│   ├── 侧边栏入口.js          # ComfyUI 侧边栏注册
│   └── 样式表.css             # 主题样式
├── 后端/
│   ├── 接口路由.py            # API 路由定义
│   ├── 文件读写操作.py        # 插件脚手架创建
│   └── 系统环境映射.py        # ComfyUI 路径获取
├── 智能体/
│   ├── 工具路由器.py          # 意图识别与知识库检索
│   ├── 模型客户端.py          # LLM API 调用
│   └── 记忆与上下文压缩.py    # 上下文管理与压缩
├── 知识库/                    # 待填充的技能文档
├── 技术文档/                  # 项目技术文档（本目录）
└── __init__.py                # ComfyUI 插件入口
```
