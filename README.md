# 🚀 节点梦工厂 — ComfyUI 全栈 AI 编程助手

> **从开发到优化再到可视化，让 AI 陪你走完 ComfyUI 插件全流程。**

节点梦工厂 是一个深度集成在 ComfyUI 侧边栏的全栈 AI 编程平台。它内置三大智能界面（开发 / 优化 / 可视化），结合按场景隔离的知识库与本地踩坑记录系统，让 AI 真正理解你的项目并直接生成、优化、解读插件代码。无需翻文档、无需切窗口——一个侧边栏，搞定 ComfyUI 插件开发全流程。

📌 **GitHub**：https://github.com/a63976659/ComfyUI-NodeCraft-AI

---

## 💡 设计理念

用 Claude、Codex 等通用 AI 写 ComfyUI 插件，每次输出都不一样，而且不一定能跑——因为底层模型靠概率预测生成结果，没有标准答案，注定输出不稳定。

NodeCraft AI 的做法不同：我们针对 ComfyUI 插件开发场景，配备了**专属知识库**和**代码示例**，把节点注册、输入输出定义、打包结构等固定套路变成标准化参考，让 AI 不再随意发挥，而是按照正确模板输出——**写一次就能用，不用反复修 bug**。

## ComfyUI-Ranking 安装

1. 打开终端，进入 ComfyUI 的 `custom_nodes` 目录：

```bash
cd ComfyUI/custom_nodes
```

2. 克隆项目：

```bash
git clone https://github.com/a63976659/ComfyUI-Ranking.git
```

3.  重启 ComfyUI，在侧边栏即可看到 社区精选 图标。

## 🎯 快速开始

1. **打开侧边栏** — 启动 ComfyUI 后，点击侧边栏中的 NodeCraft AI 图标
2. **配置模型** — 首次使用需在设置中配置 AI 模型（在线 API 或本地模型）
3. **选择界面** — 在顶部 Tab 切换：开发插件 / 优化插件 / 功能可视化
4. **新建会话** — 点击「新建会话」，描述你的需求或上传待分析的插件
5. **获取结果** — AI 结合对应知识库与踩坑记录，生成代码 / 优化建议 / 结构图

💡 **提示**：描述越具体，效果越精准。例如「帮我写一个图片缩放节点，支持按百分比和固定尺寸两种模式」。

---

## 🧠 长对话自动整理（上下文压缩）

对话聊得越久，内容就越多，AI 能记住的篇幅是有限的。插件会在后台自动整理，你不需要做任何操作：

- **快满了才整理** — 只有对话接近 AI 的记忆上限时才会触发，平时不受影响
- **最近的对话完整保留** — 最近 10 轮对话原封不动，当前讨论不会被动过
- **早期内容变成小结** — 更早的对话会被浓缩成简短总结，关键信息留下来
- **做过的事有台账** — AI 之前读过、改过哪些文件，都会留下一句话记录，不会重复劳动
- **界面记录不受影响** — 整理只发生在发给 AI 的内容上，界面里的聊天记录始终完整保存
- **你的偏好不会被整理掉** — 设置中添加的用户偏好每次对话都会重新告诉 AI

## ⚙️ 模型配置说明

### 在线 API 模式

在设置面板中填入模型服务商提供的接口地址和密钥即可使用：
- 兼容 OpenAI 格式的服务商均可接入
- 密钥只保存在本机，不会上传
- 支持流式响应，边生成边显示

### 本地模式

将模型文件放入 `ComfyUI/models/LLM/` 目录，插件会自动识别可用模型。

### 支持的模型系列（本地模式）

| 模型系列 | 说明 |
|---|---|
| **Qwen3 / Qwen3.5** | 支持思考模式，按官方推荐参数生成 |
| **Qwen2.5**（含 Coder） | 编程能力强，中文理解好 |
| **Llama 3.x** | 按官方推荐参数生成，已优化长对话复读问题 |
| **Gemma 4** | 多模态，支持图片识别；12B/E2B/E4B 规格支持音频输入，但**不支持中文语音**（上传中文音频不会报错，模型可能听不懂或理解错误，建议使用英文语音） |

未列出的系列也可尝试加载，将按通用默认参数运行。

### 默认推荐本地模型

`Qwen2.5-Coder-7B-Instruct` — 编程能力强，中文理解好，显存占用友好，适合节点代码生成。

### 默认推荐API模型

`GLM-5.2` — 编程能力强，中文理解好，API零占用显存，适合节点代码生成。

## 📂 项目结构

```
ComfyUI-NodeCraft-AI/
├── 前端/              # 界面渲染与交互（模块化 JS/CSS、双主题、响应式）
├── 后端/              # REST + WebSocket（聊天、会话、同步、认证等）
├── 智能体/            # AI 引擎（模型客户端、工具路由、上下文压缩）
├── 知识库/            # 按 Tab 隔离的开发文档
│   ├── 开发插件/    # 插件开发知识（develop）
│   ├── 优化插件/    # 性能优化知识（optimize）
│   └── 功能可视化/  # 功能分析知识（visualize）
├── 数据/              # 会话记录、踩坑记录与配置存储
├── 技术文档/          # 项目技术文档（10 份）
└── __init__.py        # 插件入口
```

## 🏗️ 技术架构

NodeCraft AI 采用清晰的四层架构设计：

```
┌───────────────────────────────────────────────┐
│  表现层 — 前端 JS/CSS                          │  三Tab侧边栏 + 双主题 + 响应式
├───────────────────────────────────────────────┤
│  服务层 — aiohttp REST + WebSocket             │  路由、认证、同步、文件管理
├───────────────────────────────────────────────┤
│  智能层 — LLM + BM25 多实例知识库              │  RAG 检索、Function Calling、上下文压缩
├───────────────────────────────────────────────┤
│  数据层 — 本地存储                             │  会话、FAQ、知识库、踩坑记录、插件文件
└───────────────────────────────────────────────┘
```
