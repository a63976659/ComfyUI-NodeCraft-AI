# ComfyUI 插件模板库

## 可用模板

| 模板名 | ID | 描述 | 包含文件 | 适用场景 |
|--------|-----|------|----------|----------|
| 基础图像处理节点 | `image-process-node` | IMAGE 输入输出 + 强度控制 + 可选遮罩 | `__init__.py`, `image_node.py`, `js/example.js`, `README.md` | 图像滤镜、变换、合成 |
| 模型加载节点 | `model-loader-node` | 模型文件加载 + 缓存 + 设备管理 | `__init__.py`, `model_loader.py`, `README.md` | 加载 checkpoint/VAE/LoRA |
| 文本处理节点 | `text-process-node` | STRING 输入输出 + 编码/解码 | `__init__.py`, `text_node.py`, `README.md` | 文本生成、转换、解析 |
| 自定义UI扩展 | `custom-ui-extension` | 前端 UI 扩展 + Python-JS 通信 | `__init__.py`, `js/custom_widget.js`, `README.md` | 自定义 widget、侧边栏 |
| API调用节点 | `api-call-node` | 异步 API 请求 + 超时重试 | `__init__.py`, `api_node.py`, `README.md` | 调用外部 API |

## 模板结构说明

每个模板目录包含：
- `template.json` — 模板元数据（id、名称、描述、分类、文件列表）
- `__init__.py` — ComfyUI 节点注册入口
- 节点实现文件 — 具体的节点逻辑代码
- `js/` — 前端 JavaScript 扩展（可选）
- `README.md` — 模板使用说明

## 使用方式

1. 在 NodeCraft AI 的插件开发面板中点击"+"按钮
2. 选择"从模板创建"
3. 在模板列表中选择合适的模板
4. 输入插件名称（仅允许英文、数字、下划线、连字符）
5. 系统自动复制模板文件并创建新插件

## 技术规范

- 所有模板遵循 ComfyUI V3 节点规范
- 节点类名采用 `中文名_Node` 格式（如 `图像处理_Node`、`API调用_Node`）
- `NODE_CLASS_MAPPINGS` 键名使用中文（如 `"图像处理"`、`"API调用"`）
- `NODE_DISPLAY_NAME_MAPPINGS` 使用 `"emoji 中文名 (EnglishHint)"` 格式
- `CATEGORY` 使用 `"emoji 中文分类/子分类"` 格式（如 `"🔧 自定义工具/图像处理"`）
- `INPUT_TYPES` 参数名、`RETURN_NAMES`、COMBO 选项均使用中文显示
- 包含 `IS_CHANGED` 方法实现缓存控制
- 代码注释使用中文
- 模板代码可直接运行，不含占位符逻辑
