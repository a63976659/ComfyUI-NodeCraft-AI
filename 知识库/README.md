# 知识库

本目录存储 NodeCraft AI（节点梦工厂）的知识库文件，用于 RAG 检索增强生成。

## 目录结构

```
知识库/
├── 开发插件/        — ComfyUI 节点开发知识（V3 节点结构、输入输出系统、迁移指南、前端扩展等）
├── 优化插件/        — 性能优化与代码质量相关知识
├── 功能可视化/      — 节点可视化与功能图谱相关知识
├── 技术方案/        — UI 交互、图像处理、数据流、模型调用等技术方案
└── 插件模板/        — 可直接使用的节点插件脚手架模板
```

## 使用方式

- 知识库按 Tab 页隔离：不同 Tab（开发/优化/可视化）只检索其对应子目录下的内容
- 用户可在 Tab 页对应子目录下放置自定义知识文档，AI 对话时会自动检索

## 支持格式

- Markdown (`.md`) — 推荐
- 纯文本 (`.txt`)
- PDF (`.pdf`)

## 注意事项

- 文件命名建议使用中文，保持语义清晰
- 单个文件建议不超过 1MB
