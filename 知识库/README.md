# 知识库目录

本目录存储 NodeCraft AI（节点梦工厂）的知识库文件，用于 RAG 检索增强生成。

## 目录结构

- `开发插件/` — ComfyUI 节点开发知识（V3 节点结构、输入输出系统、迁移指南、前端扩展等）
- `优化插件/` — 性能优化与代码质量相关知识
- `功能可视化/` — 节点可视化与功能图谱相关知识
- 用户也可在 Tab 页对应子目录下放置自定义知识文档

## 同步机制

知识库采用 **云端 → 本地 单向同步** 模式：
- 云端为权威数据源（魔搭 ModelScope Dataset）
- 本地通过 SHA256 哈希比对检测变更，仅下载新增/变更的文件
- 本地多余的文件不会被删除，也不会上传至云端
- 启动时执行一次初始同步，运行期可通过 `/ai-coder/cloud/pull` 触发手动拉取

## 支持格式

- Markdown (`.md`) — 推荐
- 纯文本 (`.txt`)
- PDF (`.pdf`)

## 注意事项

- 文件命名建议使用中文，保持语义清晰
- 单个文件建议不超过 1MB
- 修改知识库内容请在云端管理后台操作，本地修改不会同步到云端
- 知识库按 Tab 页隔离：不同 Tab（开发/优化/可视化）只检索其对应子目录下的内容
