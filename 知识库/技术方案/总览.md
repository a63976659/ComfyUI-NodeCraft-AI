# 技术方案参考库

## 定位

收录经过验证的成功技术方案，作为 ComfyUI 插件开发时的实现参考。每个方案来源于成熟开源项目或实际生产验证的实现方法。

## 分类

| 分类 | 说明 | 典型场景 |
|------|------|---------|
| 图像处理 | 图像变换、批处理、预览等方案 | 实时预览、批量处理、格式转换 |
| 模型调用 | 模型加载、推理、多模型管理方案 | 流式推理、模型切换、显存管理 |
| 数据流 | 缓存、队列、增量计算方案 | 节点缓存、异步队列、数据管道 |
| UI交互 | 前端控件、交互反馈方案 | 自定义控件、进度显示、拖拽交互 |
| 兼容性适配 | 发行版兼容、路径与环境适配方案 | 三发行版兼容、路径解析、子进程解释器 |

## 方案文档模板

每个方案文档应包含以下结构：

```
# 方案名称

## 来源
参考工具/项目：项目名（GitHub链接）
Stars：xxx | 最近更新：xxxx-xx

## 适用场景
什么时候用这个方案

## 核心思路
一句话说明原理

## 实现步骤
1. ...
2. ...

## 关键代码

（精简的核心代码片段）

## ComfyUI 适配要点
在 ComfyUI 插件中使用时的注意事项

## 注意事项
踩坑点和边界情况
```

## 使用方式

开发插件时，AI 会通过 RAG 检索自动匹配相关技术方案作为参考，无需手动查找。
