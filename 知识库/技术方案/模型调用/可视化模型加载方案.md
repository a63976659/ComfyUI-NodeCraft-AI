# 可视化模型加载方案

## 来源
参考工具/项目：ComfyUI-Model-Visual-Loader（https://github.com/a63976659/ComfyUI-Model-Visual-Loader）
定位：为 ComfyUI 打造的可视化模型加载插件，通过缩略图预览、智能缓存、文件夹分类将模型选择可视化

## 适用场景
- 需要从大量模型文件中快速选择的节点
- 需要预览图/缩略图辅助选择的模型加载器
- 支持多模型类型（Checkpoint/LoRA/UNet）统一管理的场景

## 核心思路
利用 ComfyUI 的 `folder_paths` API 获取模型列表，通过同名图片文件自动关联预览图，以 mtime 增量缓存策略避免重复处理，前端以响应式网格展示缩略图供用户选择。

## 实现步骤

### 1. 模型文件发现与枚举
```python
FOLDER_MAP = {
    "checkpoint": "checkpoints",
    "unet": "diffusion_models",
    "lora": "loras",
    "lora_stack": "loras",
}

def get_model_list(model_type):
    folder_type = FOLDER_MAP.get(model_type, model_type)
    filenames = folder_paths.get_filename_list(folder_type)
    
    for filename in filenames:
        full_path = folder_paths.get_full_path(folder_type, filename)
        subfolder = os.path.dirname(filename)  # 子文件夹作为分类
        category = subfolder if subfolder else "根目录"
        image_url = get_cached_image_path(full_path)
        
        data_list.append({
            "name": filename,
            "image": image_url,
            "category": category
        })
    return data_list
```

**要点**：
- 使用 `folder_paths` API 确保与 ComfyUI 系统配置同步
- 前端类型到后端类型需要映射（如 `lora_stack` → `loras`）
- 文件的相对目录路径自动生成分类标签

### 2. 模型元数据管理

| 维度 | 数据来源 | 存储方式 |
|------|--------|--------|
| 名称 | 文件名 | 直接使用，支持目录嵌套 |
| 缩略图 | 同名图片（.png/.jpg/.webp） | 动态生成缓存到 `cached_images/` |
| 注释 | 同名 `.txt` 文件 | 动态读写，支持实时编辑 |

### 3. 三层缓存策略

**图片缓存层（持久化）**：
```python
def get_cached_image_path(model_path):
    base_name, _ = os.path.splitext(model_path)
    
    # 查找同名图片（优先级：.png > .jpg > .jpeg > .webp）
    for ext in [".png", ".jpg", ".jpeg", ".webp"]:
        if os.path.exists(base_name + ext):
            image_source = base_name + ext
            break
    
    # MD5 哈希文件名避免路径遍历
    hash_name = hashlib.md5(model_path.encode('utf-8')).hexdigest()
    cache_path = os.path.join(CACHE_DIR, hash_name + ".png")
    
    # mtime 比较判断缓存是否有效
    if os.path.exists(cache_path):
        if os.path.getmtime(cache_path) == os.path.getmtime(image_source):
            return web_path  # 缓存有效
    
    # 重新生成：压缩为 512x512 PNG
    img = Image.open(image_source).convert("RGB")
    img.thumbnail((512, 512))
    img.save(cache_path, "PNG")
    os.utime(cache_path, (mtime, mtime))  # 设置 mtime 与源图一致
```

**关键创新**：缓存文件的 mtime 设为与源图相同，自动支持增量更新检测

**前端缓存层**：
- JavaScript 对象级缓存（`IMAGE_CACHE`）
- FIFO 淘汰策略，最多 200 张

### 4. 模型加载实现

**Checkpoint**：
```python
def load_checkpoint(self, 模型名称):
    ckpt_path = folder_paths.get_full_path_or_raise("checkpoints", 模型名称)
    out = comfy.sd.load_checkpoint_guess_config(
        ckpt_path, output_vae=True, output_clip=True,
        embedding_directory=folder_paths.get_folder_paths("embeddings")
    )
    return out[:3]  # MODEL, CLIP, VAE
```

**LoRA（带实例级缓存）**：
```python
def load_lora(self, 模型, CLIP, LoRA名称, 模型强度, CLIP强度):
    lora_path = folder_paths.get_full_path_or_raise("loras", LoRA名称)
    
    # 实例级缓存：同路径直接复用
    if self.loaded_lora and self.loaded_lora[0] == lora_path:
        lora = self.loaded_lora[1]
    else:
        lora = comfy.utils.load_torch_file(lora_path, safe_load=True)
        self.loaded_lora = (lora_path, lora)
    
    model_lora, clip_lora = comfy.sd.load_lora_for_models(模型, CLIP, lora, 模型强度, CLIP强度)
    return (model_lora, clip_lora)
```

**LoRA 堆叠（LRU 缓存）**：
```python
_lora_cache = OrderedDict()
_LORA_CACHE_MAX = 10

def _load_lora_cached(lora_path):
    if lora_path in _lora_cache:
        _lora_cache.move_to_end(lora_path)
        return _lora_cache[lora_path]
    
    lora = comfy.utils.load_torch_file(lora_path, safe_load=True)
    _lora_cache[lora_path] = lora
    
    if len(_lora_cache) > _LORA_CACHE_MAX:
        _lora_cache.popitem(last=False)
    return lora
```

### 5. 后端 API 路由

```python
# 获取模型列表
@PromptServer.instance.routes.get("/visual_loader/models")
async def api_get_models(request):
    m_type = request.rel_url.query.get("type", "checkpoint")
    data = get_model_list(m_type)
    return web.json_response(data)

# 图片缓存（二次防御路径遍历）
@PromptServer.instance.routes.get("/visual_loader/view_cache")
async def api_view_cache(request):
    filename = os.path.basename(request.rel_url.query.get("filename"))
    file_path = os.path.join(CACHE_DIR, filename)
    real_path = os.path.realpath(file_path)
    if not real_path.startswith(os.path.realpath(CACHE_DIR) + os.sep):
        return web.Response(status=403)
    return web.FileResponse(real_path) if os.path.exists(real_path) else web.Response(status=404)

# 注释读写
@PromptServer.instance.routes.get("/visual_loader/notes")
@PromptServer.instance.routes.post("/visual_loader/notes")
```

## ComfyUI 适配要点

1. **使用 `folder_paths` API**：确保与 ComfyUI 的模型路径配置同步，支持自定义路径
2. **前端类型映射**：前端可能有 `lora_stack` 等变体，后端需映射到 `folder_paths` 认识的类型
3. **路径安全**：对所有用户输入的路径参数做 `os.path.basename()` + `os.path.realpath()` 双重防御
4. **异步路由**：使用 `@PromptServer.instance.routes` 注册异步处理，不阻塞主线程
5. **URL 时间戳**：图片 URL 带 mtime 参数，利用浏览器 304 缓存同时支持增量更新

## 注意事项

1. **缓存目录管理**：需要在插件启动时确保 `cached_images/` 目录存在
2. **大量模型时的性能**：首次加载会遍历所有模型文件，数百个模型时可能耗时数秒
3. **图片格式兼容**：需处理透明通道（转 RGB）、EXIF 旋转等边界情况
4. **编码问题**：注释文件统一使用 UTF-8 编码
5. **JSON 容错**：`_safe_float()` 处理非法强度值，避免整个加载失败
