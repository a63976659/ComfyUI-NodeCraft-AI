# 模型下载方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：支持从 ModelScope/HuggingFace/HF Mirror 三源下载模型，带断点续传

## 适用场景
- 节点需要自动下载缺失模型的场景
- 需要支持国内用户加速下载的场景
- 大模型文件需要断点续传的场景

## 核心思路
提供三个下载源（ModelScope、HuggingFace、HF Mirror），使用 `huggingface_hub.snapshot_download` 实现断点续传和多线程下载，下载完成后自动注册到模型列表。

## 实现步骤

### 1. 多源下载策略
```python
import os
from huggingface_hub import snapshot_download as hf_snapshot_download
from modelscope import snapshot_download as ms_snapshot_download

def download_model(model_name, source="modelscope"):
    download_path = os.path.join(LLM_MODELS_DIR, model_name.split("/")[-1])
    
    if source == "modelscope":
        ms_snapshot_download(model_name, local_dir=download_path)
    
    elif source == "huggingface":
        # 清除国内镜像设置
        os.environ.pop("HF_ENDPOINT", None)
        hf_snapshot_download(
            repo_id=model_name,
            local_dir=download_path,
            resume_download=True,
            max_workers=4
        )
    
    elif source == "hf_mirror":
        os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"
        hf_snapshot_download(
            repo_id=model_name,
            local_dir=download_path,
            resume_download=True,
            max_workers=4
        )
    
    return download_path
```

### 2. 自动下载与加载一体化
```python
def load_or_download(model_name, auto_download=True):
    model_path = find_local_model(model_name)
    
    if not model_path and auto_download:
        print(f"[下载] 正在下载模型: {model_name}")
        model_path = download_model(model_name)
    
    if model_path:
        tokenizer = AutoTokenizer.from_pretrained(model_path, trust_remote_code=True)
        model = AutoModelForCausalLM.from_pretrained(model_path, device_map="auto")
        LOADED_MODELS[model_path] = (tokenizer, model)
        return tokenizer, model
    
    raise FileNotFoundError(f"模型未找到且下载失败: {model_name}")
```

### 3. 全局模型缓存
```python
LOADED_MODELS = {}

# 避免重复加载
if model_path not in LOADED_MODELS:
    tokenizer = AutoTokenizer.from_pretrained(model_path)
    model = AutoModelForCausalLM.from_pretrained(model_path, device_map="auto")
    LOADED_MODELS[model_path] = (tokenizer, model)
else:
    tokenizer, model = LOADED_MODELS[model_path]
```

## ComfyUI 适配要点

1. **显存清理**：下载/加载前执行 `torch.cuda.empty_cache()` 释放显存
2. **非阻塞设计**：下载过程打印日志到控制台，不阻塞 UI
3. **自动注册**：下载完成后模型自动出现在 `INPUT_TYPES` 的下拉列表中

## 注意事项

1. **环境变量污染**：设置 `HF_ENDPOINT` 后需要在官方下载时清除
2. **模型名称解析**：`Qwen/Qwen2.5-7B` → 下载到 `LLM/Qwen2.5-7B`
3. **网络超时**：国内用户访问 HuggingFace 可能超时，优先使用 ModelScope
4. **磁盘空间**：大模型 7B+ 需要 15GB+ 空间，应提前检查
5. **下载验证**：完成后检查是否存在 `.safetensors` 文件确认完整性
