# 动态加载模型路径方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：ComfyUI 本地 AI 插件，支持 LLM 对话、TTS 语音合成、音视频处理

## 适用场景
- 需要在运行时动态发现新增模型文件的节点
- 模型目录结构不固定，需要自动扫描的场景
- 需要记录用户上次使用的模型并优先显示

## 核心思路
基于 `folder_paths.models_dir` 获取标准模型目录，通过目录扫描动态发现模型文件夹，配合 `config.json` 持久化用户偏好，实现"放入即可用"的模型管理体验。

## 实现步骤

### 1. 模型目录定义与自动创建
```python
import folder_paths
import os

LLM_MODELS_DIR = os.path.join(folder_paths.models_dir, "LLM")
if not os.path.exists(LLM_MODELS_DIR):
    os.makedirs(LLM_MODELS_DIR)
```

### 2. 动态模型扫描
```python
def get_installed_models():
    """扫描本地已安装的模型目录"""
    if not os.path.exists(LLM_MODELS_DIR):
        return []
    models = [d for d in os.listdir(LLM_MODELS_DIR) 
              if os.path.isdir(os.path.join(LLM_MODELS_DIR, d))]
    return sorted(models)
```

### 3. 动态 INPUT_TYPES（每次节点创建时刷新）
```python
class LLM_Node:
    @classmethod
    def INPUT_TYPES(s):
        # 预设模型 + 本地已安装模型合集
        preset_models = ["Qwen2.5-7B-Instruct", "Qwen3-4B"]
        installed = get_installed_models()
        all_models = list(set(preset_models + installed))
        
        return {
            "required": {
                "模型名称": (all_models, {"default": load_config().get("last_model", all_models[0])}),
            }
        }
```

### 4. 配置持久化（记住用户选择）
```python
CONFIG_PATH = os.path.join(os.path.dirname(__file__), "config.json")

def load_config():
    if os.path.exists(CONFIG_PATH):
        try:
            with open(CONFIG_PATH, 'r', encoding='utf-8') as f:

def save_config(model_name):
    config = load_config()

```

## ComfyUI 适配要点

1. **使用 `folder_paths.models_dir`**：确保模型路径与 ComfyUI 配置一致
2. **动态 `INPUT_TYPES`**：每次创建节点时重新扫描，无需重启即可发现新模型
3. **容错节点加载**：每个节点模块独立 try-except，单个失败不影响整体
```python
try:
    from .节点.chat import Chat_Node
    NODE_CLASS_MAPPINGS["对话"] = Chat_Node
except Exception as e:
    logger.warning(f"节点加载失败: {e}")
```

## 注意事项

1. **模型名称格式**：需兼容 `Qwen2.5-7B` 和 `Qwen/Qwen2.5-7B` 两种格式
2. **目录不存在**：首次运行时自动创建模型目录
3. **大量模型时性能**：`os.listdir` 对于数百个模型目录仍然很快（毫秒级）
4. **默认值处理**：配置文件损坏时有 fallback 默认值
