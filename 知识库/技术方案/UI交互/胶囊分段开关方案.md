# 胶囊分段开关方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：顶栏状态切换的胶囊分段控件（pill segmented toggle），蓝色高亮滑块指示当前状态并滑动切换（NodeCraft AI 生产验证）

## 适用场景
- 顶栏/工具栏中的二态开关（启用/禁用、开启/关闭）
- 需要比传统 checkbox 更强的状态可视化与交互反馈
- 两种形态间带滑动过渡动画的切换控件

## 核心思路
胶囊容器内叠三层：**绝对定位的高亮滑块（thumb）** + **左右两个文字分段（seg）**。滑块位置与宽度由 JS 按活动分段的 `offsetLeft`/`offsetWidth` 计算，`transition: left/width` 提供滑动动画。**触发切换的点击事件只绑定在高亮滑块上**，灰色文字分段设置 `pointer-events: none` 不响应点击——高亮部分是当前状态的具象化指示器，点击它触发"把它推到另一侧"的交互隐喻，比点击灰色文字更符合直觉。

## 实现步骤

### 1. DOM 结构与 CSS 分层
```javascript
const pill = document.createElement("div");
pill.className = "tl-toggle-pill";
const thumb = document.createElement("span");    // 高亮滑块（唯一触发点）
thumb.className = "tl-toggle-thumb";
const segLeft = document.createElement("span");  // 左文字分段
segLeft.className = "tl-toggle-seg";
const segRight = document.createElement("span"); // 右文字分段
segRight.className = "tl-toggle-seg";
pill.appendChild(thumb);
pill.appendChild(segLeft);
pill.appendChild(segRight);
```
```css
.tl-toggle-pill {
  position: relative;
  display: inline-flex; align-items: stretch;
  background: var(--comfy-input-bg, #1e1e1e);
  border: 1px solid var(--border-color, #45484c);
  border-radius: 999px; padding: 3px;
  font-size: 12px; user-select: none;
}
.tl-toggle-thumb {
  position: absolute; top: 3px; bottom: 3px; left: 3px; width: 0;
  background: #4a9eff; border-radius: 999px;
  box-shadow: 0 1px 4px rgba(74, 158, 255, 0.4);
  transition: left 0.25s ease, width 0.25s ease;
  cursor: pointer; /* 唯一可交互区域的提示 */
}
.tl-toggle-seg {
  position: relative; z-index: 1;  /* 文字浮于滑块之上 */
  padding: 5px 14px; border-radius: 999px; cursor: default;
  color: var(--descrip-text, #888888); white-space: nowrap;
  pointer-events: none; /* ⚠️ 关键：文字分段不响应点击，事件穿透到滑块 */
}
.tl-toggle-seg.active { color: #ffffff; font-weight: bold; }
```

### 2. 滑块定位（`initThumb`）
```javascript
// 将滑块定位到活动分段；animate=false 时临时禁用过渡，避免初次入场动画
pill.initThumb = (animate) => {
  const target = on ? segLeft : segRight;
  if (!animate) thumb.style.transition = "none";
  thumb.style.left = target.offsetLeft + "px";
  thumb.style.width = target.offsetWidth + "px";
  if (!animate) {
    void thumb.offsetWidth; // 强制回流，恢复过渡供后续滑动使用
    thumb.style.transition = "";
  }
};
```

### 3. 高亮滑块触发滑动切换
```javascript
let on = initialEnabled;
let sliding = false;

const applyTexts = () => {
  // 活动侧显示完整文案，非活动侧显示短文案（宽度随语言变化，滑块自适应）
  segLeft.textContent = on ? "翻译开启" : "开启";
  segRight.textContent = on ? "关闭" : "翻译关闭";
  segLeft.classList.toggle("active", on);
  segRight.classList.toggle("active", !on);
};
applyTexts();

const slideAndToggle = (segIsOn) => {
  if (sliding || segIsOn === on) return;  // sliding 标志防连点
  sliding = true;
  on = !on;
  applyTexts();
  pill.initThumb(true);                       // 播放滑动动画
  setTimeout(() => persistAndReload(), 320);  // 动画播完再保存/刷新
};

// ⚠️ 触发点仅为高亮滑块：点击后滑向另一侧
// （灰色分段 pointer-events:none，点击穿透后落在无监听器的胶囊容器上 → 无反应）
thumb.addEventListener("click", () => slideAndToggle(!on));
```

## ComfyUI 适配要点

1. **挂载位置**：顶栏锚点需做可见性检测与多级 fallback（新版 ComfyUI 的 `.comfy-menu`/`menuContainer` 存在于 DOM 但 `display: none`）
2. **重渲染自愈**：Vue 顶栏重渲染可能移除控件或改变 `offsetLeft`，用低频看门狗（2 秒）检查 `isConnected`/可见性，重插后调用 `initThumb(false)` 重新定位滑块
3. **持久化衔接**：滑动动画播完后（320ms）再调用保存/刷新逻辑，保存走插件自身的 config API（见《设置持久化方案》）
4. **多语言文案**：开关文字随 ComfyUI 设置语言切换，分段宽度必须用 `offsetWidth` 实测，不能硬编码
5. **CSS 变量回退**：所有主题色用 `var(--comfy-xxx, fallback)` 包裹，兼容旧版 ComfyUI

## 注意事项（易踩坑点）

1. **⚠️ 触发点必须是高亮滑块，而非灰色文字**：把 click 绑在文字分段上是常见错误设计——灰色分段本意只是状态标签，若可点击则需 hover 高亮提示，交互暗示混乱；正确做法是滑块 `cursor: pointer` + 分段 `cursor: default`，视觉与行为一致，用户"点击当前高亮处把它推走"
2. **⚠️ z-index 与 pointer-events 必须配套**：文字分段 `z-index: 1` 浮在滑块上方保证文字可见，但这同时会挡住滑块的点击事件；只加 z-index 不加 `pointer-events: none` 会导致滑块点不到。二者缺一不可
3. **⚠️ 滑块初次定位不能带动画**：thumb 初始 `left: 3px; width: 0`，直接设置目标位置会播放一段从 0 宽度入场的动画；必须先 `transition: none` → 定位 → `void offsetWidth` 强制回流 → 恢复过渡
4. **保存时序**：`setTimeout` 的 320ms 必须 ≥ CSS 过渡时长（250ms），否则页面刷新会打断滑动动画，用户看不到过渡反馈
5. **防连点**：动画期间 `sliding = true` 锁定，忽略后续点击（刷新型切换会在 320ms 后跳页，连点可能触发两次保存）
6. **文字不对称布局**：活动侧用完整文案（"翻译开启"）、非活动侧用短文案（"关闭"），两侧宽度不同，滑块宽度必须每次切换都按目标分段重新测量
7. **尺寸依赖回流**：`offsetLeft`/`offsetWidth` 读取前元素必须已插入 DOM 且可见，在 `display: none` 容器内测量会得到 0
