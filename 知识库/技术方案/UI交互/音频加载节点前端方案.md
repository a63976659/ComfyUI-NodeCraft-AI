# 音频加载节点前端方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：ComfyUI 节点内嵌音频播放器 + 波形可视化 + 可拖拽裁剪标记

## 适用场景
- ComfyUI 节点需要加载和预览音频文件
- 需要可视化波形并支持裁剪区间选择的节点
- 需要系统文件选择对话框的节点

## 核心思路
通过系统原生文件对话框（tkinter）选择文件，HTML5 Audio API 播放预览，Canvas 绘制波形图，mousedown/mousemove 实现可拖拽的裁剪标记，实时同步参数到 ComfyUI widget。

## 实现步骤

### 1. 系统文件选择对话框（后端）
```python
import tkinter as tk
from tkinter import filedialog
from aiohttp import web

@server.PromptServer.instance.routes.post("/qwen/browse_file")
async def browse_file(request):
    root = tk.Tk()
    root.withdraw()
    root.attributes('-topmost', True)
    file_path = filedialog.askopenfilename(
        filetypes=[("Media Files", "*.mp4 *.mov *.wav *.mp3 *.flac *.m4a *.ogg")]
    )
    root.destroy()
    return web.json_response({"path": file_path.replace("\\", "/")})
```

### 2. 前端文件浏览按钮
```javascript
this.addWidget("button", "🎵 浏览媒体文件", null, () => {
```

### 3. Canvas 波形绘制
```javascript
const drawWaveform = (audioBuffer) => {
    const raw = audioBuffer.getChannelData(0);
    const step = Math.ceil(raw.length / canvas.width);
    const centerY = canvas.height / 2;
    const amp = canvas.height / 2 - 4;
    
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.beginPath();
    ctx.strokeStyle = "#4ade80";
    
    for (let i = 0; i < canvas.width; i++) {
        let min = 1.0, max = -1.0;
        for (let j = 0; j < step; j++) {
            const idx = i * step + j;
            if (idx < raw.length) {
                const datum = raw[idx];
                if (datum < min) min = datum;
                if (datum > max) max = datum;
            }
        }
        ctx.moveTo(i, centerY + min * amp);
        ctx.lineTo(i, centerY + max * amp);
    }
    ctx.stroke();
};
```

### 5. 可拖拽裁剪标记
```javascript
let dragTarget = null;

canvas.addEventListener("mousedown", (e) => {
    const x = e.offsetX;
    const startX = startTime / audioDuration * canvas.width;
    const endX = (startTime + duration) / audioDuration * canvas.width;
    
    if (Math.abs(x - startX) < 20) dragTarget = 'start';
    else if (Math.abs(x - endX) < 20) dragTarget = 'end';
});

window.addEventListener("mousemove", (e) => {
    if (!dragTarget) return;
    const x = e.offsetX;
    const time = (x / canvas.width) * audioDuration;
    
    if (dragTarget === 'start') {
        startWidget.value = parseFloat(time.toFixed(2));
        startWidget.callback(startWidget.value);
    } else {
        durWidget.value = Math.max(0, time - startWidget.value);
        durWidget.callback(durWidget.value);
    }
    requestAnimationFrame(draw);
});

window.addEventListener("mouseup", () => { dragTarget = null; });
```

## ComfyUI 适配要点

1. **媒体流路由**：后端提供 `/view_media` 路由返回文件流，前端通过 URL 播放
2. **Widget 同步**：拖拽操作实时更新 widget 值，确保执行时参数正确
3. **工作流恢复**：加载工作流时检查 `app.configuringGraph` 避免重置参数

## 注意事项

1. **tkinter 线程安全**：文件对话框必须在主线程调用，异步路由中需注意
2. **大文件加载**：Web Audio API 加载大音频文件可能导致浏览器卡顿
3. **路径分隔符**：Windows 路径需统一转为 `/`
4. **跨域问题**：媒体文件通过后端路由代理，避免跨域限制
