# 组件值联动显隐方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
参考节点：
- 🎬 MiniMax H3 音画多镜头公式（`H3音画多镜头公式`，实现文件 `网页资源/h3_multishot_showcontrol.js`）——单滑块控制同类组件组
- 🖼️ MiniMax H3 全能参考公式（`H3全能参考公式`，实现文件 `网页资源/h3_reference_showcontrol.js`）——多个滑块分别控制各自组件组

定位：用节点上的"数量滑块"组件控制另外一批组件的显示/隐藏，组件组数量随滑块值动态增减，节点高度自动跟随缩放

## 适用场景
- 节点包含大量重复槽位组件（如"镜头1~50"、"参考图1~9"），全部展开会极长难用
- 需要一个数量/模式控件实时控制成组组件的显隐
- 隐藏后节点高度要自动收缩，且恢复时能完整还原（含 multiline 文本框等 DOM 组件）
- 同一套方案已在 `H3全能参考公式`（图片/视频/音频三个数量滑块）复用验证

> 相关方案：若需要根据 COMBO **选项值**（而非数量滑块）关闭组件、且希望组件置灰保留而非隐藏，见《组件选项联动禁用方案》（参考视频动态带运镜节点）。

## 核心思路
"Python 全量注册 + 前端按需显隐"：
1. Python 端一次性注册全部槽位（多镜头节点为 50 镜头 × 7 字段 = 350 个 optional 输入），保证序列化与工作流兼容；
2. 前端 JS 扩展拦截"数量组件"的赋值，按数量对多余槽位做"真隐藏"（type + hidden 标志 + computeSize 三重处理）；
3. 显隐变化后重算节点尺寸，节点高度跟随可见组件数量自动缩放。

## 实现步骤

### 1. Python 端：全量注册槽位 + 数量滑块
```python
class H3音画多镜头公式:
    最大镜头数 = 50
    镜头组件字段 = [
        ("开始时间", "FLOAT", {"default": 0, "min": 0, "max": 100, "step": 0.5, "display": "slider"}),
        ("描述", "STRING", {"multiline": True, "default": ""}),
        # ... 每个镜头包含的固定字段列表
    ]

    @classmethod
    def INPUT_TYPES(cls):
        required = {
            "镜头数量": ("INT", {"default": 3, "min": 1, "max": cls.最大镜头数,
                             "step": 1, "display": "slider"}),
        }
        optional = {}
        for 序号 in range(1, cls.最大镜头数 + 1):
            for 字段名, 字段类型, 配置 in cls.镜头组件字段:
                # 命名规则：镜头{N}{字段}，前端按该规则匹配显隐
                optional[f"镜头{序号}{字段名}"] = (字段类型, {**配置})
        return {"required": required, "optional": optional}
```
要点：
- 组件命名必须规律统一（`镜头{N}{字段}`），这是前端匹配的唯一依据
- Python 端**不做**显隐，隐藏组件的值仍会序列化保存，后端按数量截取并跳过空值即可

### 2. 前端：真隐藏 toggleWidget（核心）
```javascript
function toggleWidget(node, widget, show = false) {
    if (!widget) return;
    // 只在第一次备份最原始的属性，便于恢复（避免多次切换后备份被污染）
    if (widget._h3BackedUp === undefined) {
        widget._h3OrigType = widget.type;
        widget._h3OrigComputeSize = widget.hasOwnProperty('computeSize') ? widget.computeSize : undefined;
        widget._h3BackedUp = true;
    }
    if (show) {
        widget.type = widget._h3OrigType;
        widget.hidden = false;
        if (widget._h3OrigComputeSize !== undefined) widget.computeSize = widget._h3OrigComputeSize;
        else delete widget.computeSize;
        if (widget.inputEl) widget.inputEl.style.display = "";
        if (widget.element) widget.element.style.display = "";
    } else {
        widget.type = "hidden";
        widget.hidden = true;                 // 新版前端读该标志，必须设置（见注意事项1）
        widget.computeSize = () => [0, -4];   // 旧版前端兼容：抵消 4px 渲染缝隙
        if (widget.inputEl) widget.inputEl.style.display = "none";
        if (widget.element) widget.element.style.display = "none";
    }
}
```

### 3. 前端：拦截数量组件赋值
ComfyUI 没有公开的 widget 值变化事件，用 `Object.defineProperty` 包装 `value` 的 getter/setter，保留原描述符链：
```javascript
function addWidgetValueListener(node, widget, handler) {
    if (!widget) return;
    let widgetValue = widget.value;
    let originalDescriptor = Object.getOwnPropertyDescriptor(widget, 'value') ||
        Object.getOwnPropertyDescriptor(Object.getPrototypeOf(widget), 'value');
    if (!originalDescriptor) {
        originalDescriptor = Object.getOwnPropertyDescriptor(widget.constructor.prototype, 'value');
    }
    Object.defineProperty(widget, 'value', {
        get() {
            return originalDescriptor && originalDescriptor.get
                ? originalDescriptor.get.call(widget) : widgetValue;
        },
        set(newVal) {
            if (originalDescriptor && originalDescriptor.set) originalDescriptor.set.call(widget, newVal);
            else widgetValue = newVal;
            handler(node);   // 值变化时重新处理显隐
        }
    });
}
```

### 4. 前端：显隐处理函数 + 节点高度自动缩放
```javascript
const SHOT_WIDGET_SUFFIXES = ["开始时间", "结束时间", "景别", "描述", "运镜方式", "台词", "声音设计"];
const MAX_SHOTS = 50;   // 与 Python 端 最大镜头数 保持一致

function h3MultiShotHandler(node) {
    if (node.comfyClass !== "H3音画多镜头公式") return;
    const widgetIndex = getWidgetIndex(node);          // 见下方索引缓存
    const shotCount = parseInt(widgetIndex.get("镜头数量").value) || 3;

    for (let i = 1; i <= MAX_SHOTS; i++) {
        const show = i <= shotCount;
        for (const suffix of SHOT_WIDGET_SUFFIXES) {
            toggleWidget(node, widgetIndex.get(`镜头${i}${suffix}`), show);
        }
    }

    // 重算尺寸：节点高度跟随可见组件缩放，保留当前宽度，无变化时跳过重排
    if (node.computeSize) {
        const size = node.computeSize();
        if (node.size && node.size[0] > size[0]) size[0] = node.size[0];
        if (!node.size || node.size[0] !== size[0] || node.size[1] !== size[1]) node.setSize(size);
    }
    node.setDirtyCanvas(true, true);
}

// 组件索引缓存：节点创建后组件列表固定，避免每次显隐都遍历（350个组件时拖动更流畅）
function getWidgetIndex(node) {
    if (!node._h3WidgetIndex) {
        node._h3WidgetIndex = new Map();
        for (const w of node.widgets || []) node._h3WidgetIndex.set(w.name, w);
    }
    return node._h3WidgetIndex;
}
```

### 5. 前端：扩展注册入口
```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "h3.multishot.showcontrol",
    nodeCreated(node) {
        if (node.comfyClass === "H3音画多镜头公式") {
            h3MultiShotHandler(node);   // 初始处理（含加载旧工作流后恢复正确显隐）
            const shotCountWidget = node.widgets?.find(w => w.name === "镜头数量");
            if (shotCountWidget) addWidgetValueListener(node, shotCountWidget, h3MultiShotHandler);
        }
    }
});
```
`nodeCreated` 在节点新建与从工作流加载时都会触发，初始执行一次 handler 即可覆盖两种场景，无需单独处理 `onConfigure`。

## 变体：参考节点的多滑块独立控制（H3全能参考公式）

当节点存在**多个并行的数量滑块**、各自控制一组独立槽位时（如全能参考节点的"图片数量/视频数量/音频数量"），复用同一套 `toggleWidget` + `addWidgetValueListener`，差异仅在处理函数按滑块分组循环、注册时为每个滑块各挂一个监听。

### Python 端：按素材类型分组循环注册槽位
```python
# 槽位上限与官方手册一致：图片≤9 视频≤3 音频≤3，每个槽位含"用途"+"描述"两个组件
optional = {}
for 序号 in range(1, 10):
    optional[f"参考图{序号}用途"] = (H3_ASSET_USAGES, {"default": "无"})

for 序号 in range(1, 4):
    optional[f"参考视频{序号}用途"] = (H3_ASSET_USAGES, {"default": "无"})
    optional[f"参考视频{序号}描述"] = ("STRING", {"multiline": True, "default": ""})
for 序号 in range(1, 4):
    optional[f"参考音频{序号}用途"] = (H3_ASSET_USAGES, {"default": "无"})
    optional[f"参考音频{序号}描述"] = ("STRING", {"multiline": True, "default": ""})
```
命名规则：`参考{类型}{N}{字段}`，三类槽位用不同前缀区分，前端按前缀+序号匹配。

### 前端：单处理函数读取三个滑块、分组显隐
```javascript
function h3ReferenceHandler(node) {
    if (node.comfyClass !== "H3全能参考公式") return;
    const widgetIndex = getWidgetIndex(node);

    // 三个数量滑块任一缺省则整体跳过
    const imageCountWidget = widgetIndex.get("图片数量");
    const videoCountWidget = widgetIndex.get("视频数量");
    const audioCountWidget = widgetIndex.get("音频数量");
    if (!imageCountWidget || !videoCountWidget || !audioCountWidget) return;

    const imageCount = parseInt(imageCountWidget.value) || 0;
    const videoCount = parseInt(videoCountWidget.value) || 0;
    const audioCount = parseInt(audioCountWidget.value) || 0;

    // 按各自数量滑块显隐素材槽位（每个槽位含"用途"+"描述"两个组件）
    for (let i = 1; i <= 9; i++) {
        const show = i <= imageCount;
        toggleWidget(node, widgetIndex.get(`参考图${i}用途`), show);
        toggleWidget(node, widgetIndex.get(`参考图${i}描述`), show);
    }
    for (let i = 1; i <= 3; i++) {
        const show = i <= videoCount;
        toggleWidget(node, widgetIndex.get(`参考视频${i}用途`), show);
        toggleWidget(node, widgetIndex.get(`参考视频${i}描述`), show);
    }
    for (let i = 1; i <= 3; i++) {
        const show = i <= audioCount;
        toggleWidget(node, widgetIndex.get(`参考音频${i}用途`), show);
        toggleWidget(node, widgetIndex.get(`参考音频${i}描述`), show);
    }

    // 与单滑块版完全相同：重算节点尺寸 + 刷新画布
    if (node.computeSize) {
        const size = node.computeSize();
        if (node.size && node.size[0] > size[0]) size[0] = node.size[0];
        if (!node.size || node.size[0] !== size[0] || node.size[1] !== size[1]) node.setSize(size);
    }
    node.setDirtyCanvas(true, true);
}

app.registerExtension({
    name: "h3.reference.showcontrol",
    nodeCreated(node) {
        if (node.comfyClass === "H3全能参考公式") {
            h3ReferenceHandler(node);   // 初始处理
            // 关键差异：为每个数量滑块都注册值监听，共用同一个 handler
            for (const countName of ["图片数量", "视频数量", "音频数量"]) {
                const countWidget = node.widgets?.find(w => w.name === countName);
                if (countWidget) addWidgetValueListener(node, countWidget, h3ReferenceHandler);
            }
        }
    }
});
```

### 与单滑块版的差异点

| 维度 | 单滑块（多镜头节点） | 多滑块（全能参考节点） |
|---|---|---|
| 控制组件 | 1 个滑块管 1 组槽位 | N 个滑块各管 1 组槽位 |
| 值监听注册 | 1 次 | 每个滑块各注册 1 次，共用同一 handler |
| 槽位命名 | `镜头{N}{字段}` | `参考{类型}{N}{字段}`，多前缀分组 |
| 数量语义 | 数量即有效镜头上限（min=1） | 数量仅控制显隐（min=0），实际采用以填写内容为准 |
| 隐藏组件默认值 | 描述为空不生成镜头行 | 用途为"无"且描述为空不生成素材行 |

### 补充要点

1. **多滑块共用 handler 无冲突**：任一滑块变化都会全量重算三组显隐，逻辑幂等，无需记录"哪个滑块变了"
2. **数量滑块允许为 0**：全能参考的滑块 min=0，`parseInt(...) || 0` 兜底；多镜头节点 min=1 用 `|| 3` 兜底，兜底值按业务含义选择
3. **滑块语义要在节点 DESCRIPTION 中声明**：如"数量滑块仅控制组件显隐，实际使用的素材以填写了用途或描述的槽位为准"，避免用户误以为隐藏即删除

## ComfyUI 适配要点

1. **widget.hidden 标志是关键**：新版前端的可见性判断读取 `widget.hidden` 而非 `widget.type`，只设 type="hidden" 会导致隐藏组件仍参与尺寸计算和命中检测，造成节点高度错乱、末尾组件无法点击
2. **computeSize 返回 [0, -4]**：-4px 抵消 ComfyUI 默认的组件间渲染缝隙（旧版前端兼容需要）
3. **DOM 组件要同步隐藏**：multiline STRING 等 DOM widget 需额外设 `inputEl`/`element` 的 `style.display`
4. **备份只做一次**：`_h3BackedUp` 标志防止多次切换后把"隐藏态属性"当成原始属性备份
5. **数据流不变**：显隐纯前端行为，后端始终通过 widget.value 获取数据，隐藏组件的值照常序列化

## 注意事项

1. **JS 与 Python 常量必须双端同步**：组件命名规则（`镜头{N}{字段}` ↔ `SHOT_WIDGET_SUFFIXES`）、数量上限（`最大镜头数` ↔ `MAX_SHOTS`）改任何一端都要同步另一端
2. **禁用 JS 时全量展示**：Python 端无显隐逻辑，前端 JS 失效时节点会显示全部组件，功能仍可用（后端按数量截取兜底）
3. **只隐藏不删除**：绝不从 `node.widgets` 移除组件，避免索引错乱和序列化丢失
4. **多滑块复用**：`H3全能参考公式` 用同一套 toggleWidget + 值监听实现了三个数量滑块（图片≤9/视频≤3/音频≤3）独立控制各自槽位组，证明方案可复用于多个控制组件
5. **性能**：组件数百个级别时务必缓存组件索引（Map），否则每次滑块变化都遍历查找会明显卡顿
6. **显隐后必须 setDirtyCanvas(true, true)**，否则画布不刷新；尺寸无变化时跳过 setSize，避免无谓重排
