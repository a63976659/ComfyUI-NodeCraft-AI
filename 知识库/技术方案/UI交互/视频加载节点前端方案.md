# 视频加载节点前端方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：ComfyUI 节点内嵌视频播放器 + Canvas 时间轴 + 可拖拽裁剪标记

## 适用场景
- ComfyUI 节点需要加载和预览视频文件
- 需要时间轴可视化和帧定位的视频处理节点
- 需要可交互裁剪区间选择的视频编辑节点

## 核心思路
HTML5 Video 元素播放预览，Canvas 绘制时间轴刻度和裁剪标记，通过 `timeupdate` 事件实时同步播放进度，后端 OpenCV 获取视频元信息（FPS、总帧数），裁剪模式下自动循环播放选中区间。

## 实现步骤

### 1. 视频播放器
```javascript
const video = document.createElement("video");
video.controls = false;
video.playsInline = true;
video.style.cssText = "width:100%; flex-grow:1; object-fit:contain;";
video.src = `/qwen/view_media?path=${encodeURIComponent(filePath)}&t=${Date.now()}`;

// 点击播放/暂停
video.onclick = () => { video.paused ? video.play() : video.pause(); };

// 播放按钮状态切换
video.addEventListener('play', () => { playBtn.innerText = "⏸"; });
video.addEventListener('pause', () => { playBtn.innerText = "▶"; });
```

### 2. Canvas 时间轴绘制
```javascript
const draw = () => {
    const pxPerSec = canvas.width / videoDuration;
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    // 自动计算刻度间隔
    const timeStep = videoDuration > 60 ? 10 : videoDuration > 10 ? 1 : 0.5;
    
    // 绘制时间刻度
    ctx.strokeStyle = "#888";
    ctx.fillStyle = "#aaa";
    ctx.font = "9px sans-serif";
    for (let t = 0; t <= videoDuration; t += timeStep) {
        const x = t * pxPerSec;
        ctx.beginPath();
        ctx.moveTo(x, 0);
        ctx.lineTo(x, 5);
        ctx.stroke();
        ctx.fillText(formatTime(t), x, 7);
    }
    
    // 播放进度遮罩
    const playX = video.currentTime * pxPerSec;
    ctx.fillStyle = "rgba(255, 255, 255, 0.2)";
    ctx.fillRect(0, 0, playX, canvas.height);
};

video.addEventListener('timeupdate', () => { requestAnimationFrame(draw); });
```

### 3. 视频元信息获取（后端）
```python
import cv2

@server.PromptServer.instance.routes.get("/qwen/video_metadata")
async def video_metadata(request):
    file_path = request.query.get("path", "")
    cap = cv2.VideoCapture(file_path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    cap.release()
    return web.json_response({"fps": fps, "total_frames": total_frames})
```

### 4. 裁剪区间可视化
```javascript
// 遮蔽未选中区域
const sX = startTime * pxPerSec;
const eX = (startTime + duration) * pxPerSec;

ctx.fillStyle = "rgba(0, 0, 0, 0.5)";
ctx.fillRect(0, 0, sX, height);       // 左侧遮蔽
ctx.fillRect(eX, 0, width - eX, height);  // 右侧遮蔽

// 开始标记（青色）
ctx.strokeStyle = "#00ffff";
ctx.beginPath(); ctx.moveTo(sX, 0); ctx.lineTo(sX, height); ctx.stroke();

// 结束标记（红色）
ctx.strokeStyle = "#ff0055";
ctx.beginPath(); ctx.moveTo(eX, 0); ctx.lineTo(eX, height); ctx.stroke();
```

### 5. 裁剪模式自动循环播放
```javascript
video.addEventListener('timeupdate', () => {
    if (isCropMode && !video.paused) {
        const endTime = startTime + duration;
        if (video.currentTime >= endTime) {
            video.pause();
            video.currentTime = startTime;  // 跳回起点
        }
    }
});
```

## ComfyUI 适配要点

1. **媒体代理路由**：视频通过后端路由流式传输，避免跨域
2. **防缓存**：URL 加 `&t=${Date.now()}` 确保路径变更后视频更新
3. **工作流恢复**：检查 `app.configuringGraph` 避免初始化时重置参数
4. **节点区分**：同一个 JS 文件支持多种节点（加载视频/裁剪视频），通过 `nodeData.name` 判断

## 注意事项

1. **视频编解码**：浏览器对视频编码支持有限（H.264 最广泛）
2. **大文件加载**：超长视频可能导致浏览器内存问题
3. **FPS 精度**：可变帧率视频的 FPS 值可能不准确
4. **OpenCV 依赖**：后端获取元信息需要 `opencv-python`
