# 节点隐藏输入端口方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
参考节点：合并多组提示词（`合并多组提示词`，实现文件 `网页资源/dynamic_inputs.js` + `节点文件/工具节点.py`）
定位：节点需要大量同类型输入端口（最多 50 个）但平时只显示少数几个——Python 端全量注册，前端按连线情况动态增删输入端口，界面始终只保留"最后连线 + 1 个空位"

## 适用场景
- 节点有大批量同类型输入槽（如合并 N 组提示词、多路图像混合），全部展示会让节点极高
- 希望"连线即扩展"：用户连上一个端口就自动露出下一个空位，断开后自动收回
- 与「组件值联动显隐方案」的本质区别：那个方案隐藏的是 **widget**（只改显隐标志，数据仍在）；本方案增删的是 **输入端口**（`node.inputs` 数组真实增删，被删端口在执行时不存在）

## 核心思路
"Python 全量注册 + `**kwargs` 兜底收集 + 前端按连线动态增删端口"：
1. Python 端循环注册全部端口（50 个 STRING），执行函数用 `**kwargs` 收集，天然容忍部分端口缺失；
2. 前端在 `onNodeCreated` 立即把 50 个端口裁剪到 2 个；
3. `onConnectionsChange` 监听连线变化，按"最后一个有连线的端口 + 1 个空位"动态 `addInput`/`removeInput`，钳制在 [2, 50]；
4. 端口数量变化后 `computeSize` + `setSize` 让节点高度跟随端口数收缩/伸展。

## 实现步骤

### 1. Python 端：全量注册 + forceInput + kwargs 收集
```python
class 合并多组提示词:
    @classmethod
    def INPUT_TYPES(cls):
        optional_inputs = {
            "分隔符": (["逗号", "句号", "斜杠", "换行", "无", "下划线", "中划线", "长破折号"],
                     {"default": "逗号"})
        }
        for i in range(1, 51):
            # forceInput: 强制只显示为连线端口，不生成文本框 widget
            optional_inputs[f"提示词{i}"] = ("STRING", {"default": "", "forceInput": True})
        return {"required": {}, "optional": optional_inputs}

    def 合并提示词(self, 分隔符="逗号", **kwargs):
        # 前端删掉的端口不会出现在 kwargs 中——用 in 判断 + 非空过滤即可兜底
        提示词列表 = []
        for i in range(1, 51):
            key = f"提示词{i}"
            if key in kwargs and kwargs[key] and isinstance(kwargs[key], str) and kwargs[key].strip():
                提示词列表.append(kwargs[key].strip())
        分隔符映射 = {"逗号": ", ", "句号": "。", "斜杠": "/", "换行": "\n", "无": "",
                   "下划线": "_", "中划线": "-", "长破折号": "—"}
        return (分隔符映射.get(分隔符, ", ").join(提示词列表),)
```
要点：
- `forceInput: True` 让端口只作为连线插槽存在，不渲染成 widget
- 命名规律 `提示词{N}` 是前端增删端口时的命名依据，必须双端一致
- optional + **kwargs：端口被前端删除后执行时自动缺席，无需任何特殊处理

### 2. 前端：核心增删逻辑（显示数 = 最后连线 + 1 空位）
```javascript
const updateNodeInputs = function(node) {
    if (!node.inputs) return;   // 初始化瞬间可能为空，做保护

    // 找到最后一个有连线的输入索引
    let lastLinkIndex = -1;
    for (let i = 0; i < node.inputs.length; i++) {
        if (node.inputs[i].link !== null) lastLinkIndex = i;
    }

    // 显示规则：最后连线 + 1 个空位，钳制 [2, 50]
    let targetCount = lastLinkIndex + 2;
    if (targetCount < 2) targetCount = 2;
    if (targetCount > 50) targetCount = 50;

    const currentCount = node.inputs.length;
    let hasChanged = false;

    if (currentCount < targetCount) {
        // 扩容：名称必须与 Python 端一致（i 是 0 基索引，端口号 = i + 1）
        for (let i = currentCount; i < targetCount; i++) {
            node.addInput(`提示词${i + 1}`, "STRING");
        }
        hasChanged = true;
    } else if (currentCount > targetCount) {
        // 收缩：从末尾往前删（被删端口必然无连线，因为 targetCount > 最后连线索引）
        for (let i = currentCount; i > targetCount; i--) {
            node.removeInput(i - 1);
        }
        hasChanged = true;
    }

    // 端口数变化后重算尺寸，节点高度跟随端口数收缩/伸展
    if (hasChanged) {
        node.setSize(node.computeSize());
        node.setDirtyCanvas(true, true);
    }
};
```

### 3. 前端：两个挂载点
```javascript
app.registerExtension({
    name: "Comfy.ToolsNode.MergePrompts",
    async beforeRegisterNodeDef(nodeType, nodeData, app) {
        // 名称必须对应 Python 端 NODE_CLASS_MAPPINGS 的 Key
        if (nodeData.name !== "合并多组提示词") return;

        // 挂载点①：新建节点时，立即把 Python 传来的 50 个端口裁剪成 2 个
        const onNodeCreated = nodeType.prototype.onNodeCreated;
        nodeType.prototype.onNodeCreated = function() {
            const r = onNodeCreated ? onNodeCreated.apply(this, arguments) : undefined;
            updateNodeInputs(this);
            return r;
        };

        // 挂载点②：连线变化时重新计算（只处理输入端口 type === 1）
        const onConnectionsChange = nodeType.prototype.onConnectionsChange;
        nodeType.prototype.onConnectionsChange = function(type, index, connected, link_info, slotObj) {
            const r = onConnectionsChange ? onConnectionsChange.apply(this, arguments) : undefined;
            if (type === 1) {
                // 延迟执行：等 LiteGraph 内部状态（link 引用）更新完毕再读
                setTimeout(() => updateNodeInputs(this), 20);
            }
            return r;
        };
    }
});
```

## ComfyUI 适配要点

1. **增删端口用 LiteGraph 原生 API**：`node.addInput(名称, 类型)` / `node.removeInput(索引)`，引擎自动处理端口位置、连线挂接与序列化
2. **端口名称即执行时的参数名**：前端 addInput 的名称必须与 Python `INPUT_TYPES` 的键逐字一致（`提示词{i+1}`），否则执行时 kwargs 收不到值
3. **从末尾删除是安全的**：显示数恒大于"最后连线索引"，被删区间内必无连线，不会破坏已有连接
4. **onConnectionsChange 必须延迟读取**：回调触发时 LiteGraph 的 link 引用尚未更新完毕，同步读 `input.link` 会得到旧状态，用 setTimeout(20ms) 等待
5. **加载旧工作流自动恢复**：configure 按保存的端口列表恢复（可能多于 2 个），onConnectionsChange/初始裁剪规则会把它收敛到正确数量

## 注意事项

1. **本方案真删端口，与 widget 显隐语义不同**：被 removeInput 的端口在序列化中消失、执行时缺席；若需要"隐藏但保留数据"，应改用组件显隐/禁用方案
2. **上限必须双端一致**：Python 循环上限（50）与前端钳制上限（50）不同步会导致扩不动或多删
3. **空位规则决定用户体验**："最后连线 + 1 空位"保证用户始终能看到下一个可连的端口；最少保留 2 个避免节点缩成单端口
4. **JS 失效时功能完好**：前端不工作时节点显示全部 50 个端口，后端 kwargs 收集照常，仅失去收敛效果
5. **系统级隐藏输入是另一机制**：`INPUT_TYPES` 中的 `"hidden": {"prompt": "PROMPT", "extra_pnginfo": "EXTRA_PNGINFO", "unique_id": "UNIQUE_ID"}` 用于注入执行上下文（完整提示图/元信息/节点 ID），与本方案的"用户可见端口收敛"是两回事，不要混淆
6. **尺寸重算只在变化时执行**：hasChanged 为假时跳过 setSize，避免连线抖动引发无谓重排
