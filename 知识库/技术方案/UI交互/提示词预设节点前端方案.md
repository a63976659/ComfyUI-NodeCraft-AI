# 提示词预设节点前端方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：在节点前端展示预设文件内容，支持标题动态变化、内容滚动、复制、缩放自适应

## 适用场景
- 节点需要显示文件/预设的文本内容
- 需要标题随选择内容动态变化
- 需要在节点内嵌入可滚动、可复制的文本区域
- 前端内容需随节点缩放自适应

## 核心思路
通过后端 API 提供预设文件列表和内容，前端使用 DOM Widget 在节点中嵌入可滚动的文本容器。监听 widget 选择事件动态更新标题和内容，通过 `onResize` 实现高度自适应。

## 实现步骤

### 1. 标题跟随加载文件变动
```javascript
// 监听预设选择变化，动态修改节点标题
预设部件.callback = async () => {
    if (预设部件.value && 预设部件.value !== "无") {
        this.title = `提示词预设 - ${预设部件.value}`;
    }
};
```
关键：使用 ComfyUI 的 `widget.callback` 机制拦截选择事件，直接修改 `node.title`。

### 2. 前端内容显示加载文件内容
```javascript
// 通过后端 API 获取预设文件列表和内容
const response = await fetch("/preset_preview/list");
const data = await response.json();

// 创建 DOM 容器展示内容
预览容器.textContent = 当前预设数据.完整内容;
预览容器.className = "preset-content-preview preset-content-loaded";
```

CSS 样式：
```css
.preset-content-preview {
    word-wrap: break-word;
    white-space: pre-wrap;      /* 保留原始格式并自动换行 */
    font-family: monospace;     /* 等宽字体确保对齐 */
    overflow: auto;             /* 内容过长时启用滚动条 */
}
```

### 3. 前端内容可复制
使用原生 HTML 文本节点（`textContent`），无需额外 JS 复制按钮，浏览器原生选择+复制机制即可。

### 4. 前端居中节点内部方法
```css
.preset-content-preview {
    display: flex;
    align-items: flex-start;
    justify-content: flex-start;
    margin: 5px auto;              /* 左右自动边距水平居中 */
    width: calc(100% - 16px);      /* 左右各留 8px */
}
```

### 5. 上下滚动轴设计方法
```javascript
$el("style", {
    textContent: `
        .preset-content-preview::-webkit-scrollbar { width: 6px; }
        .preset-content-preview::-webkit-scrollbar-track { background: rgba(0,0,0,0.1); }
        .preset-content-preview::-webkit-scrollbar-thumb { background: var(--descrip-text); }
    `
});
```
- 使用 WebKit 伪元素自定义滚动条外观
- 宽度 6px，颜色与主题变量同步

### 6. 前端跟随节点缩放方法
```javascript
node.onResize = function(size) {
    this._nodeWidth = size[0];
    this._nodeHeight = size[1];
    
    const 标题高度 = 30;
    const 下拉框高度 = 30;
    const 边距 = 20;
    const 可用高度 = this.size[1] - 标题高度 - 下拉框高度 - 边距;
    
    this.预览容器.style.height = `${Math.max(40, 可用高度)}px`;
    this.setDirtyCanvas(true, true);
};
```
- 重写 `onResize` 拦截节点拉伸事件
- 计算可用高度动态调整容器
- `setDirtyCanvas()` 强制重绘

## ComfyUI 适配要点

1. **DOM Widget 注册**：使用 `addDOMWidget()` 将 DOM 容器注入节点
2. **尺寸保存**：将 `_nodeWidth`/`_nodeHeight` 保存用于序列化恢复
3. **API 路由注册**：后端需通过 `PromptServer.instance.routes` 注册预设列表 API
4. **`setDirtyCanvas(true, true)`**：第一个参数强制重绘前景，第二个强制重绘背景

## 注意事项

1. **$el 工具函数**：ComfyUI 前端提供的 DOM 创建工具，需从 `comfyui` 模块导入
2. **pre-wrap 与 pre 区别**：`pre-wrap` 保留换行但允许折行，`pre` 不折行可能超出容器
3. **动态 API 缓存**：避免每次选择都请求后端，应在首次加载时缓存全部预设内容
4. **节点最小尺寸**：设置 `node.size` 最小值防止内容被压缩到不可见
