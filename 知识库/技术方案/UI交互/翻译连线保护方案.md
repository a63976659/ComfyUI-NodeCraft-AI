# 翻译连线保护方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：确保翻译修改显示名后不影响节点间连线匹配和工作流保存/加载

## 适用场景
- 修改节点输入/输出的显示名但不能影响连线逻辑
- 需要保证工作流文件（JSON）与翻译状态无关
- 需要在翻译开/关切换后连线不断裂

## 核心思路
严格区分 `name`（内部标识，用于连线匹配和序列化）和 `label`（显示标签，仅用于 UI 渲染）。翻译只修改 `label`，永不修改 `name`。ComfyUI/LiteGraph 的连线逻辑、保存逻辑都使用 `name`，因此翻译完全不影响功能。

## 实现步骤

### 1. name/label 分离策略
```javascript
static safeApplyTranslation(item, translation) {
    if (this.needsTranslation(item) && translation) {
        // 永远不修改 item.name
        if (!item._original_name) {
            item._original_name = item.name;  // 备份（实际等于 name 本身）
        }
        item.label = translation;  // 只修改显示标签
    }
}
```

### 2. 输入/输出翻译应用
```javascript
static applyNodeTranslation(node) {
    const t = TUtils.T.Nodes[class_type];
    
    // 翻译输入端口
    node.inputs?.forEach((item) => {
        if (item.name in t["inputs"]) {
            // item.name 保持不变，只改 label
            this.safeApplyTranslation(item, t["inputs"][item.name]);
        }
    });
    
    // 翻译输出端口
    node.outputs?.forEach((item) => {
        if (item.name in t["outputs"]) {
            this.safeApplyTranslation(item, t["outputs"][item.name]);
        }
    });
    
    // 翻译 widgets
    node.widgets?.forEach((item) => {
        if (item.name in t["widgets"]) {
            this.safeApplyTranslation(item, t["widgets"][item.name]);
        }
    });
}
```

### 3. LiteGraph 渲染机制利用
```javascript
// LiteGraph 内部渲染逻辑（伪代码）
function drawSlotLabel(slot) {
    // 优先使用 label，fallback 到 name
    const displayText = slot.label || slot.name;
    ctx.fillText(displayText, x, y);
}

// 连线匹配逻辑（伪代码）
function findCompatibleSlot(sourceSlot, targetNode) {
    for (const input of targetNode.inputs) {
        if (input.type === sourceSlot.type) {  // 用 type 匹配，不用 name/label
            return input;
        }
    }
}
```

### 4. 工作流序列化保护
```javascript
// ComfyUI 保存工作流时
function serializeNode(node) {
    return {
        inputs: node.inputs.map(i => ({
            name: i.name,      // 保存英文原名
            type: i.type,
            link: i.link       // 连线 ID
        })),
        // label 不被序列化
    };
}
```

## ComfyUI 适配要点

1. **LiteGraph label 支持**：LiteGraph 原生支持 `slot.label` 属性，渲染时优先使用
2. **序列化只保存 name**：ComfyUI 工作流 JSON 中不包含 label 字段
3. **type 匹配连线**：连线兼容性由 `slot.type`（如 "MODEL", "IMAGE"）决定
4. **ComfyUI prompt 构建**：生成 prompt 时使用 input name 匹配参数

## 注意事项

1. **绝对不改 name**：这是本方案的铁律，一旦修改 name 将导致连线断裂
2. **label 初始为空**：LiteGraph 的 slot 默认无 label 属性，渲染时 fallback 到 name
3. **翻译关闭恢复**：关闭翻译时需 `delete item.label` 或 `item.label = ""`，让渲染回退到 name
4. **动态新增 slot**：节点运行中动态新增的 input/output 也需要翻译，需在 `nodeCreated` 钩子中处理
5. **工作流跨环境**：因为保存的是英文 name，工作流在未安装翻译插件的环境中也能正常加载
