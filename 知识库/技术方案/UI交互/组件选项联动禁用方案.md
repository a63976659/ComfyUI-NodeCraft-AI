# 组件选项联动禁用方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
参考节点：🎞️ 视频动态带运镜（`视频动态带运镜`，实现文件 `网页资源/showcontrol_video_transition.js` 中的 `videoDynamicWithCameraHandler`）
同文件复用验证：`视频首尾帧转场`、`视频首尾帧转场-增强版`、`视频动效提示词` 三个节点
定位：根据 COMBO 下拉选项的值（如"无"/具体选项）控制依赖组件的**禁用/启用**（置灰关闭），选项切换即时生效

## 适用场景
- 节点有"总开关"型 COMBO 组件（如 动态类型、运镜方式、主要转场方式），选"无"时其下属参数组件无意义
- 希望关闭组件但**保留可见性和已填的值**（置灰而非消失），避免用户误以为数据丢失
- 存在级联依赖：一级选项决定哪些组件可用，二级选项再决定更深层组件是否可用
- 与「组件值联动显隐方案」的区别：本方案用 `disabled` 禁用，组件仍占位；显隐方案用真隐藏，节点高度收缩

## 核心思路
"COMBO 选项即开关 + `widget.disabled` 置灰"：
1. Python 端照常注册全部组件，总开关 COMBO 默认"无"，后端对"无"做防御性短路（不生成对应段落）；
2. 前端 JS 拦截总开关组件的赋值，按选项值设置依赖组件的 `disabled` 标志；
3. ComfyUI 原生支持 `disabled` 渲染（置灰、不可交互），无需改 type/computeSize/高度，实现成本极低。

## 实现步骤

### 1. Python 端：总开关 COMBO + 后端防御性短路
```python
class 视频动态带运镜:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                # 总开关①：动态类型，默认"无"
                "动态类型": (["无", "人物动作", "动物行为", "物体运动", "自然现象", "特效动画"],
                          {"default": "无"}),
                # 依赖组件（动态类型为"无"时被前端禁用）
                "具体动态": ("STRING", {"multiline": False, "default": "行走"}),
                "动态程度": (["轻微", "适中", "明显", "剧烈", "夸张"], {"default": "适中"}),
                # ...
            },
            "optional": {
                # 总开关②：运镜方式，默认"无"
                "运镜方式": (CAMERA_MOVEMENTS, {"default": "无"}),
                # 依赖组件（运镜方式为"无"时被前端禁用）
                "镜头目标": ("STRING", {"default": "主体"}),
                "运镜时长": ("FLOAT", {"default": 3.0, "min": 1.0, "max": 15.0, "display": "slider"}),
                # ...
            }
        }

    def _generate_dynamic_description(self, 主体, 动态类型, 具体动态, ...):
        # 后端防御：禁用不清空值，必须按总开关值短路，"无"时不生成动态段落
        if 动态类型 == "无":
            return ""
        # ...
```

### 2. 前端：禁用版 toggleWidget（一行核心）
```javascript
// 与"真隐藏"版不同：只切换 disabled 标志，ComfyUI 原生渲染置灰效果，
// 无需备份 type/computeSize，无需重算节点高度
function toggleWidget(node, widget, show = false) {
    if (!widget) return;
    widget.disabled = !show;
}
```

### 3. 前端：双轴并行控制处理函数（视频动态带运镜）
一个节点可有多个互相独立的总开关，各自控制一组依赖组件，用布尔条件直接计算：
```javascript
function videoDynamicWithCameraHandler(node) {
    if (node.comfyClass !== "视频动态带运镜") return;

    const 动态类型Widget = findWidgetByName(node, "动态类型");
    const 运镜方式Widget = findWidgetByName(node, "运镜方式");
    if (!动态类型Widget || !运镜方式Widget) return;

    // 轴①：动态类型 !== "无" → 启用动态参数组
    const 显示动态参数 = 动态类型Widget.value !== "无";
    for (const name of ["具体动态", "动态程度", "动态速度", "动态节奏", "与环境互动"]) {
        toggleWidget(node, findWidgetByName(node, name), 显示动态参数);
    }

    // 轴②：运镜方式 !== "无" → 启用运镜参数组
    const 显示运镜参数 = 运镜方式Widget.value !== "无";
    for (const name of ["镜头目标", "多个主体", "运镜速度", "运镜时长", "视觉连贯性"]) {
        toggleWidget(node, findWidgetByName(node, name), 显示运镜参数);
    }
}
```
handler 幂等：每次全量重算两组状态，任何开关变化都调同一函数，无需判断"谁变了"。

### 4. 前端：监听只挂在控制组件上
```javascript
function addWidgetValueListener(node, widget, handler) {
    if (!widget) return;
    let widgetValue = widget.value;
    let originalDescriptor = Object.getOwnPropertyDescriptor(widget, 'value') ||
        Object.getOwnPropertyDescriptor(Object.getPrototypeOf(widget), 'value');
    if (!originalDescriptor) {
        originalDescriptor = Object.getOwnPropertyDescriptor(widget.constructor.prototype, 'value');
    }
    Object.defineProperty(widget, 'value', {
        get() {
            return originalDescriptor && originalDescriptor.get
                ? originalDescriptor.get.call(widget) : widgetValue;
        },
        set(newVal) {
            if (originalDescriptor && originalDescriptor.set) originalDescriptor.set.call(widget, newVal);
            else widgetValue = newVal;
            handler(node);
        }
    });
}

app.registerExtension({
    name: "video-transition.showcontrol",
    nodeCreated(node) {
        if (node.comfyClass === "视频动态带运镜") {
            videoDynamicWithCameraHandler(node);   // 初始处理（覆盖新建与工作流加载）
            // 只给两个总开关挂监听即可（该节点其余监听为兼容旧逻辑的冗余）
            addWidgetValueListener(node, findWidgetByName(node, "动态类型"), videoDynamicWithCameraHandler);
            addWidgetValueListener(node, findWidgetByName(node, "运镜方式"), videoDynamicWithCameraHandler);
        }
    }
});
```

### 5. 进阶：switch 映射表 + 级联控制（视频首尾帧转场-增强版）
当"选项 → 依赖组件"是多对多映射时，用"默认全关 + switch 按选项启用"结构：
```javascript
function enhancedVideoTransitionHandler(node) {
    const mainTransitionWidget = findWidgetByName(node, "主要转场方式");
    if (!mainTransitionWidget) return;
    const occlusionTypeWidget = findWidgetByName(node, "遮挡物类型");
    const characterEffectWidget = findWidgetByName(node, "人物动态效果");
    // ... 获取全部受控 widget

    // 第一层：默认禁用所有受控组件（幂等复位）
    for (const w of [/* 全部受控 widget */]) toggleWidget(node, w, false);

    // 第二层：按主选项启用对应子集（多个选项可复用同一分支）
    switch (mainTransitionWidget.value) {
        case "运镜提示词转场":
        case "运动匹配转场":
            toggleWidget(node, motionSubtypeWidget, true);
            toggleWidget(node, motionDirectionWidget, true);
            // ...
            break;
        case "遮挡物转场":
            toggleWidget(node, occlusionTypeWidget, true);
            // 第三层级联：二级选项的值再决定更深层组件
            if (occlusionTypeWidget.value === "前景物体遮挡") {
                toggleWidget(node, findWidgetByName(node, "前景遮挡物"), true);
            }
            break;
        case "无":
            break;   // 全关
        default:
            // 兜底分支：未知选项给一组安全默认（避免新增选项后组件全锁死）
            break;
    }

    // 级联规则也可用"效果值"判断：效果为"无"时其强度组件一并关闭
    if (characterEffectWidget && !characterEffectWidget.disabled) {
        toggleWidget(node, characterIntensityWidget, characterEffectWidget.value !== "无");
    }
}
```
级联时监听要覆盖**每一层的控制组件**：主转场方式、遮挡物类型、人物动态效果、环境动态效果都要挂 `addWidgetValueListener`，任一变化全量重算。

## ComfyUI 适配要点

1. **disabled 是原生支持的**：ComfyUI 对 `widget.disabled = true` 的组件自动置灰且不响应交互，无需修改 type/hidden/computeSize，也不影响节点高度
2. **禁用 ≠ 清空**：disabled 组件的值照常保留并序列化，后端必须按总开关值防御性短路（如 `动态类型 == "无"` 直接返回空段落），不能假设禁用组件没有值
3. **总开关默认"无"**：让新建节点默认处于"精简形态"，用户按需展开，降低认知负担
4. **监听最小化**：只给真正影响显隐的总开关组件挂值监听即可；受控组件本身不需要监听（除非它还级联控制更深层组件）
5. **handler 幂等全量重算**：每次先复位（全关或按条件重算）再启用，避免增量更新漏状态

## 注意事项

1. **不要引用不存在的 API**：早期版本曾尝试 `widget.linkedWidgets`，该属性不存在，级联关系必须自己在 handler 中维护
2. **switch 必须有兜底分支**：Python 端新增选项而前端未同步 case 时，走 default 分支给出安全默认，否则新选项下所有组件被锁死
3. **级联层级加深时监听清单要同步扩展**：每一层新增控制组件都要在 `nodeCreated` 中追加监听，否则深层联动失效
4. **与真隐藏方案可组合**：同一节点可一部分组件用 disabled 置灰（保留值语义）、一部分用真隐藏（收缩高度），按"用户是否需要感知该组件存在过"选择
5. **选项值用中文语义"无"**：前后端都以字符串"无"作为关闭判据，改判据值需前后端同步
6. **禁用 JS 时兜底仍可用**：前端失效时所有组件可用，后端按总开关值短路保证输出正确，仅失去界面收敛效果
