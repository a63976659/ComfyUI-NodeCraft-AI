# 文件选择上传方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：通过 ComfyUI 内置的 image_upload 参数实现点击打开系统文件选择器上传图像

## 适用场景
- 节点需要用户选择本地图像文件
- 需要打开系统文件选择器（而非手动输入路径）
- 需要将上传的图像加入 ComfyUI 的输入文件列表

## 核心思路
利用 ComfyUI 框架内置的 `image_upload: True` 参数声明，框架自动在 COMBO widget 旁生成上传按钮。点击后调用系统文件选择器，上传成功后文件存入 ComfyUI 输入目录，文件名自动添加到下拉列表。

## 实现步骤

### 1. 后端声明 image_upload
```python
class 判断并输出加载的图像:
    @classmethod
    def INPUT_TYPES(cls):
        图像文件列表 = cls.获取图像文件列表()
        return {
            "required": {
                "图像文件": ([""] + 图像文件列表, {"image_upload": True}),
            },
        }
    
    @classmethod
    def 获取图像文件列表(cls):
        import folder_paths
        input_dir = folder_paths.get_input_directory()
        files = [f for f in os.listdir(input_dir) 
                 if f.lower().endswith(('.png', '.jpg', '.jpeg', '.webp', '.gif'))]
        return sorted(files)
```

### 2. 框架自动处理
ComfyUI 前端检测到 `image_upload: True` 后自动：
- 在 COMBO widget 旁添加上传按钮图标
- 点击触发 `<input type="file" accept="image/*">` 系统对话框
- 上传到 `/upload/image` API
- 文件存入 `ComfyUI/input/` 目录
- 刷新 COMBO 选项列表

### 3. 图像加载与处理
```python
def 加载图像(self, 图像文件):
    import folder_paths
    image_path = folder_paths.get_annotated_filepath(图像文件)
    img = Image.open(image_path)
    img = img.convert("RGB")
    img_array = np.array(img).astype(np.float32) / 255.0
    return torch.from_numpy(img_array).unsqueeze(0)  # [1, H, W, 3]
```

## ComfyUI 适配要点

1. **`image_upload: True`**：唯一需要的配置，框架处理所有上传逻辑
2. **COMBO 类型必需**：image_upload 只能与列表类型（COMBO）配合使用
3. **`folder_paths.get_input_directory()`**：获取 ComfyUI 标准输入目录
4. **`get_annotated_filepath()`**：处理带子文件夹标注的文件路径

## 注意事项

1. **空选项**：列表首项为 `""` 表示未选择，执行时需判空
2. **文件类型限制**：在后端过滤文件扩展名，而非依赖前端限制
3. **IS_CHANGED**：如需检测文件修改，实现 `IS_CHANGED` 方法返回文件哈希
4. **大文件处理**：ComfyUI 上传有默认大小限制，超大文件需调整配置
5. **路径安全**：使用 `folder_paths` API 而非手动拼接路径，防止目录遍历
