# 选择性翻译方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：实现按插件、按类型（节点名/COMBO选项）选择性启用或禁用翻译

## 适用场景
- 翻译覆盖面广但用户只需部分翻译
- 某些插件的翻译质量不佳需要禁用
- 部分内容翻译后反而影响使用（如 COMBO 选项翻译后不易对照文档）

## 核心思路
提供两级选择性禁用：1）插件级禁用——在后端编译阶段跳过指定插件的翻译文件；2）类型级禁用——前端根据配置开关跳过 COMBO 选项等特定类型的翻译。管理界面提供复选框列表供用户勾选。

## 实现步骤

### 1. 插件级禁用（后端过滤）
```python
def get_nodes_translation(locale, disabled_plugins=None):
    path = CUR_PATH.joinpath(locale, "Nodes")
    disabled = set(disabled_plugins or [])  # O(1) 查找
    translations = {}
    
    for jpath in path.glob("*.json"):
        if jpath.stem in disabled:  # 文件名（无扩展名）即插件名
            continue
        translations.update(try_get_json(jpath))
    
    return translations
```

### 2. 插件管理 UI
```javascript
function buildPluginPanel(parentEl) {
    const disabled = new Set(currentConfig.disabled_plugins || []);
    
    fetch("./translation_node/get_plugin_list")
        .then(resp => resp.json())
        .then(plugins => {
            plugins.forEach(name => {
                const checked = !disabled.has(name);
                const div = document.createElement("div");
                div.innerHTML = `
                    <label style="display:flex;gap:6px;align-items:center;">
                        <input type="checkbox" ${checked ? "checked" : ""} 
                               data-plugin="${name}" />
                        <span>${name}</span>
                    </label>
                `;
                listEl.appendChild(div);
            });
        });
    
    // 保存按钮
    saveBtn.addEventListener("click", async () => {
        const newDisabled = [];
        listEl.querySelectorAll("input[type=checkbox]").forEach(cb => {
            if (!cb.checked) {
                newDisabled.push(cb.dataset.plugin);
            }
        });
        await saveConfig(..., newDisabled, ...);
        location.reload();
    });
}
```

### 3. COMBO 选项翻译开关（前端条件判断）
```javascript
replaceText(target) {
    // 检查 COMBO 翻译是否启用
    if (!isOptionTranslationEnabled()) {
        const el = target.nodeType === Node.TEXT_NODE ? target.parentElement : target;
        if (el?.closest?.(".litecontextmenu")) return;  // 跳过右键菜单选项
    }
    
    // SELECT 元素的 option 翻译
    if (target.nodeName === "SELECT" && isOptionTranslationEnabled()) {
        Array.from(target.options).forEach(option => {
            if (option.text && !isAlreadyTranslatedText(option.text)) {
                const translated = this.MT(option.text);
                if (translated) option.text = translated;
            }
        });
    }
}
```

### 4. 内容级条件翻译
```javascript
for (let value of values) {
    let originalContent = value._originalContent || value.content;
    
    // 节点名始终翻译
    if (value.value in tN) {
        value.content = tN[value.value]["title"] || value.content;
    }
    // 菜单选项受开关控制
    else if (isOptionTranslationEnabled() && value.content in t) {
        value.content = t[value.content];
    }
}
```

## ComfyUI 适配要点

1. **插件名 = 文件名**：翻译 JSON 文件名对应 custom_nodes 目录名
2. **get_plugin_list API**：后端提供可用翻译文件列表供前端展示
3. **disabled_plugins 数组**：配置中存储被禁用插件的名称列表
4. **`.litecontextmenu`**：LiteGraph 右键菜单的容器 class

## 注意事项

1. **插件名一致性**：disabled_plugins 中的名称必须与 JSON 文件名完全匹配
2. **重载生效**：插件级禁用改变后端编译结果，必须刷新页面重新获取
3. **默认全部启用**：disabled_plugins 为空数组时表示全部启用
4. **性能影响**：禁用越多插件，编译结果越小，加载越快
