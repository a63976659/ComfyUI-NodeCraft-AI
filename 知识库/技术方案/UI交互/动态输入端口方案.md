# 动态输入端口方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：根据用户连线情况自动增减节点输入端口，始终保留一个空位等待下一次连接

## 适用场景
- 节点需要接受不定数量的输入（如合并多组文本）
- 希望减少视觉噪音，只显示已用+1个空输入
- 需要根据连接状态自动调整节点大小

## 核心思路
后端预定义大量可选输入（如50个），前端在节点创建时精简为最少数量（2个）。监听 `onConnectionsChange` 事件，每次连线变化时计算"最后一个有连线的输入索引+1"作为目标显示数量，动态 `addInput()`/`removeInput()` 调整端口数。

## 实现步骤

### 1. 后端预定义大量可选输入
```python
class 合并多组提示词:
    @classmethod
    def INPUT_TYPES(cls):
        optional_inputs = {
            "分隔符": (["逗号", "句号", "斜杠", "换行", "无"], ),
        }
        for i in range(1, 51):
            optional_inputs[f"提示词{i}"] = ("STRING", {"default": "", "forceInput": True})
        return {"required": {}, "optional": optional_inputs}
```
`forceInput: True` 确保这些输入只能通过连线接入，不显示为 widget。

### 2. 前端动态增减逻辑
```javascript
const updateNodeInputs = function(node) {
    // 查找最后一个有连线的输入
    let lastLinkIndex = -1;
    for (let i = 0; i < node.inputs.length; i++) {
        if (node.inputs[i].link !== null) {
            lastLinkIndex = i;
        }
    }
    
    // 目标数量 = 最后连接索引 + 2（保留1个空位），至少2个
    let targetCount = Math.max(2, Math.min(50, lastLinkIndex + 2));
    const currentCount = node.inputs.length;
    
    // 增加输入
    if (currentCount < targetCount) {
        for (let i = currentCount; i < targetCount; i++) {
            node.addInput(`提示词${i + 1}`, "STRING");
        }
    }
    // 移除多余输入（从后往前删除未连接的）
    else if (currentCount > targetCount) {
        for (let i = currentCount; i > targetCount; i--) {
            node.removeInput(i - 1);
        }
    }
    
    // 重新计算节点尺寸
    const newSize = node.computeSize();
    node.setSize(newSize);
    node.setDirtyCanvas(true, true);
};
```

### 3. 事件监听绑定
```javascript
app.registerExtension({
    name: "合并多组提示词.dynamicInputs",
    async beforeRegisterNodeDef(nodeType, nodeData) {
        if (nodeData.name === "合并多组提示词") {
            const onNodeCreated = nodeType.prototype.onNodeCreated;
            nodeType.prototype.onNodeCreated = function() {
                onNodeCreated?.apply(this, arguments);
                // 初始精简：移除多余输入，只保留2个
                while (this.inputs.length > 2) {
                    this.removeInput(this.inputs.length - 1);
                }
            };
            
            const onConnectionsChange = nodeType.prototype.onConnectionsChange;
            nodeType.prototype.onConnectionsChange = function(type, index, connected, link_info) {
                onConnectionsChange?.apply(this, arguments);
                if (type === 1) {  // 1 = INPUT
                    updateNodeInputs(this);
                }
            };
        }
    }
});
```

## ComfyUI 适配要点

1. **`forceInput: True`**：让输入只接受连线，不生成 widget
2. **`onConnectionsChange`**：type=1 为输入变化，type=2 为输出变化
3. **`addInput(name, type)`**：动态添加输入端口，名称必须与后端 `INPUT_TYPES` 中定义的一致
4. **`removeInput(index)`**：只能移除未连接的输入，否则会断开连线
5. **`computeSize()`**：重新计算节点最小尺寸以适配新的端口数量

## 注意事项

1. **名称匹配**：动态添加的输入名必须与后端定义完全一致（`提示词1` ~ `提示词50`）
2. **删除顺序**：从后往前删除，避免索引偏移
3. **上限保护**：`Math.min(50, ...)` 防止超出后端定义的最大数量
4. **加载恢复**：节点加载时需根据保存的连线状态重新计算显示数量
5. **性能考虑**：批量增删时只在最后调用一次 `setDirtyCanvas`
