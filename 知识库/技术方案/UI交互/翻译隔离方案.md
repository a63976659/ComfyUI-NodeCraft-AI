# 翻译隔离方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：实现翻译层与原始数据的完全隔离，确保翻译不污染原始节点定义，卸载后完全恢复

## 适用场景
- 需要修改 UI 显示但不能影响内部逻辑
- 需要可逆的数据变换（开关切换立即恢复）
- 插件卸载后必须零残留

## 核心思路
采用非入侵式设计：只修改 `title`（显示标题）和 `label`（显示标签）等纯显示属性，永远不修改 `name`（内部标识）和 `comfyClass`（类型标识）。通过 `_original_*` 前缀属性备份原始值，关闭翻译时恢复。使用 `atexit` 钩子确保卸载时清理。

## 实现步骤

### 1. 节点类型级别隔离
```javascript
static applyNodeTypeTranslationEx(nodeName) {
    let nodesT = this.T.Nodes;
    var nodeType = LiteGraph.registered_node_types[nodeName];
    if (!nodeType) return;
    
    let class_type = nodeType.comfyClass || nodeType.type;
    if (nodesT.hasOwnProperty(class_type)) {
        // 只修改 nodeType.title（显示名），不修改 class_type（内部标识）
        nodeType.title = nodesT[class_type]["title"];
    }
}
```

### 2. 节点实例级别隔离
```javascript
static applyNodeTranslation(node) {
    // 备份原始标题
    if (!node._original_title) {
        node._original_title = node.constructor.comfyClass || node.constructor.type;
    }
    
    // 应用翻译
    node.title = t["title"];
    
    // 关闭翻译时恢复
    if (!isTranslationEnabled()) {
        if (node._original_title && !node._translation_custom_title) {
            node.title = node._original_title;
            delete node._original_title;
        }
    }
}
```

### 3. Widget name/label 分离
```javascript
static safeApplyTranslation(item, translation) {
    if (this.needsTranslation(item) && translation) {
        if (!item._original_name) {
            item._original_name = item.name;  // 保存英文原名（永不改变）
        }
        item.label = translation;  // 只修改显示标签
    }
}

// 内部匹配始终用 item.name
node.inputs.forEach((item) => {
    if (item.name in t["inputs"]) {  // 用英文原名匹配
        this.safeApplyTranslation(item, t["inputs"][item.name]);
    }
});
```

### 4. Vue 节点隔离（新版 ComfyUI）
```javascript
// 新版 ComfyUI 部分节点由 Vue 渲染，标识与显示字段与旧版不同
app.registerExtension({
    name: "translation.vue",
    beforeRegisterVueAppNodeDefs(nodeDefs) {
        for (const nodeDef of nodeDefs) {
            // Vue 节点标识在 nodeDef.name（而非 constructor.comfyClass）
            const t = TUtils.T.Nodes[nodeDef.name];
            if (t && t.title) {
                // Vue 节点使用 display_name 作为显示名（而非 node.title）
                nodeDef.display_name = t.title;
            }
        }
    }
});
```

### 5. 卸载清理机制
```python
import atexit
from shutil import rmtree

def unregister():
    """插件卸载时删除 web 扩展链接"""
    translation_node_ext_path = COMFY_PATH.joinpath("web", "extensions", ADDON_NAME)
    try:
        rmtree(translation_node_ext_path)
    except BaseException:
        pass

atexit.register(unregister)
```

## ComfyUI 适配要点

1. **title vs comfyClass**：ComfyUI 使用 `comfyClass` 做内部匹配，`title` 仅用于显示
2. **name vs label**：LiteGraph 的 widget/slot 中 `name` 用于匹配，`label` 用于渲染
3. **_original_* 约定**：以下划线开头的属性不会被 ComfyUI 序列化保存
4. **atexit 钩子**：Python 进程退出时自动执行清理
5. **Vue 节点差异**：新版 Vue 节点使用 `nodeDef.display_name`（而非 `node.title`）做显示，标识在 `nodeDef.name`（而非 `constructor.comfyClass`）
6. **beforeRegisterVueAppNodeDefs**：处理 Vue 节点翻译的专用钩子

## 注意事项

1. **不能修改 name**：修改 `item.name` 会导致连线断裂、保存的工作流加载失败
2. **自定义标题保护**：如果用户手动修改了节点标题，不应被翻译覆盖
3. **恢复顺序**：关闭翻译时先恢复 nodeType.title 再恢复 node.title
4. **内存泄漏**：`_original_*` 属性在节点删除时随节点 GC 回收，无需手动清理
5. **符号链接方式**：使用符号链接而非文件复制，便于开发期热更新
