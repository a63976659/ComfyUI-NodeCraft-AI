# 颜色预设选择输出方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：通过预设名选择颜色配色方案，自动展开为主色/辅色/点缀色及占比信息输出

## 适用场景
- 需要提供固定的颜色方案供用户选择
- 选中预设后需输出结构化的颜色信息（色值+占比）
- 需要将颜色信息作为提示词组件传递给下游

## 核心思路
在常量配置中定义颜色预设字典（预设名 → 颜色信息），节点 INPUT_TYPES 中使用预设名列表作为 COMBO 选项。执行时根据选中的预设名查表获取详细颜色信息，展开为格式化的提示词输出。

## 实现步骤

### 1. 颜色预设配置（常量字典）
```python
COLOR_PRESETS_DETAILS = {
    "奶油樱花": {
        "colors": ["#FFCDD2 (粉)", "#FFF9C4 (鹅黄)", "#E1F5FE (天蓝)"],
        "percentages": ["60%", "30%", "10%"]
    },
    "香芋奶茶": {
        "colors": ["#E1C4FF (香芋紫)", "#FFE4E1 (肉粉)", "#F5F5DC (米白)"],
        "percentages": ["60%", "30%", "10%"]
    },
    # ... 更多预设
}
```

### 2. 节点输入定义
```python
@classmethod
def INPUT_TYPES(cls):
    return {
        "required": {
            "颜色预设": (["无"] + list(COLOR_PRESETS_DETAILS.keys()), {"default": "无"}),
            # ... 其他输入
        }
    }
```

### 3. 执行逻辑：查表展开
```python
def 生成提示词(self, 颜色预设="无", ...):
    components = {}
    
    if 颜色预设 != "无":
        components["配色方案"] = 颜色预设
        if 颜色预设 in COLOR_PRESETS_DETAILS:
            color_info = COLOR_PRESETS_DETAILS[颜色预设]
            components["主色"] = f"{color_info['colors'][0]} (占比{color_info['percentages'][0]})"
            components["辅色"] = f"{color_info['colors'][1]} (占比{color_info['percentages'][1]})"
            components["点缀色"] = f"{color_info['colors'][2]} (占比{color_info['percentages'][2]})"
    
    return (self.构建提示词(**components),)
```

## ComfyUI 适配要点

1. **COMBO 类型**：预设列表作为元组传入 `INPUT_TYPES`，ComfyUI 自动渲染为下拉框
2. **"无"选项**：列表首项为"无"，执行时跳过颜色处理
3. **字符串输出**：颜色信息最终拼接为字符串类型输出，兼容下游文本处理

## 注意事项

1. **预设可扩展**：字典结构便于用户后续追加新的配色方案
2. **占比规范**：建议主色60%+辅色30%+点缀色10%=100%
3. **色值格式**：同时包含 HEX 码和中文描述，提高可读性
4. **与"无"的判断**：始终检查 `!= "无"` 而非 truthy 判断，避免预设名为空字符串时误判
