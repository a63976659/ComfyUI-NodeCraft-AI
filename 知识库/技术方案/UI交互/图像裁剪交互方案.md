# 图像裁剪交互方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：在节点上显示图像并提供可视化裁剪交互，支持预设比例、红框指示器、拖拽定位、刻度标尺

## 适用场景
- 需要在节点中嵌入图像预览
- 需要可视化的裁剪区域选择（红框指示器）
- 需要鼠标拖拽交互调整参数
- 需要带刻度的标尺辅助定位

## 核心思路
通过 `onDrawBackground` 在节点背景层绘制图像、遮罩、红框、刻度和UI控件。使用 `onMouseDown`/`onMouseMove`/`onMouseUp` 实现拖拽交互，通过 `captureInput` 锁定输入焦点。预设模式自动计算裁剪尺寸并锁定手动输入。

## 实现步骤

### 1. 预设与前端互动
```javascript
const ratios = { 
    "1:1": 1, "2:3": 2/3, "3:2": 3/2, "3:4": 3/4, 
    "4:3": 4/3, "9:16": 9/16, "16:9": 16/9 
};

if (!isCustom) {
    const r = ratios[presetW.value] || 1;
    let baseW, baseH;
    if (img.width / img.height > r) {
        baseH = img.height;
        baseW = baseH * r;
    } else {
        baseW = img.width;
        baseH = baseW / r;
    }
    targetW = snap16(baseW * scaleVal);
    targetH = snap16(baseH * scaleVal);
    // 预设模式禁用手动宽高输入
    widthW.disabled = true;
    heightW.disabled = true;
} else {
    widthW.disabled = false;
    heightW.disabled = false;
}

// 对齐16倍数
const snap16 = val => Math.max(16, Math.floor(val / 16) * 16);
```

### 2. 红框指示器显示
```javascript
node.onDrawBackground = function(ctx) {
    const paddingLeft = 30;
    const scale = drawW / img.width;
    
    // 计算红框位置
    const cropW = widthW.value * scale;
    const cropH = heightW.value * scale;
    const cropX = paddingLeft + (xW.value * scale);
    const cropY = topMargin + (yW.value * scale);
    
    // 绘制遮罩（暗化红框外区域）
    ctx.fillStyle = "rgba(0, 0, 0, 0.6)";
    if (cropY > topMargin)
        ctx.fillRect(paddingLeft, topMargin, drawW, cropY - topMargin);
    if (cropY + cropH < imgBottom)
        ctx.fillRect(paddingLeft, cropY + cropH, drawW, imgBottom - (cropY + cropH));
    // 左右遮罩...
    
    // 绘制红框
    ctx.strokeStyle = "#ff0000";
    ctx.lineWidth = 2;
    ctx.strokeRect(cropX, cropY, cropW, cropH);
    
    // 尺寸标注
    ctx.fillStyle = "white";
    ctx.font = "12px Arial";
    ctx.fillText(`${widthW.value} x ${heightW.value}`, cropX + 5, cropY + 15);
};
```

### 3. 节点上显示图像
```javascript
const refresh = async () => {
    const fileW = findWidget(node, "图像文件");
    if (!fileW || !fileW.value) return;
    
    if (node.imgUrl !== fileW.value) {
        const img = new Image();
        img.src = `/view?filename=${encodeURIComponent(fileW.value)}&type=input`;

        node.imgUrl = fileW.value;
    }
};

// 在 onDrawBackground 中绘制
ctx.drawImage(node.imgCache, paddingLeft, topMargin, drawW, drawH);
```

### 4. 刻度标尺显示
```javascript
// 根据缩放自动调整刻度粒度
let step = 100;
const minPxGap = 40;
if (100 * scale < minPxGap) {
    if (200 * scale >= minPxGap) step = 200;
    else if (500 * scale >= minPxGap) step = 500;
    else if (1000 * scale >= minPxGap) step = 1000;
    else step = 2000;
}

// 绘制 X 轴刻度
for (let i = 0; i <= img.width; i += step / 2) {
    const isMajor = (i % step === 0);
    const tickX = paddingLeft + (i * scale);
    const tickLen = isMajor ? 6 : 3;
    
    ctx.moveTo(tickX, topMargin);
    ctx.lineTo(tickX, topMargin - tickLen);
    
    if (isMajor) {
        ctx.fillText(i.toString(), tickX, topMargin - 8);
    }
}
```

### 5. 拖拽调整参数
```javascript
node.onMouseDown = function(e, localPos) {
    const [mx, my] = localPos;
    
    if (mx >= cropX && mx <= cropX + cropW && 
        my >= cropY && my <= cropY + cropH) {
        this.dragState = {
            startX: mx, startY: my,
            initialValX: xW.value, initialValY: yW.value
        };
        this.captureInput(true);
        return true;
    }
};

node.onMouseMove = function(e, localPos) {
    const [mx, my] = localPos;
    if (!this.dragState) return;
    
    const deltaX = (mx - this.dragState.startX) / this.renderScale;
    const deltaY = (my - this.dragState.startY) / this.renderScale;
    
    let newX = this.dragState.initialValX + deltaX;
    let newY = this.dragState.initialValY + deltaY;
    
    // 边界限制
    newX = Math.max(0, Math.min(newX, maxX));
    newY = Math.max(0, Math.min(newY, maxY));
    
    xW.value = Math.round(newX);
    yW.value = Math.round(newY);
    this.setDirtyCanvas(true, true);
};

node.onMouseUp = function() {
    this.dragState = null;
    this.captureInput(false);
};
```

## ComfyUI 适配要点

1. **`onDrawBackground`**：在节点背景层绘制，图像和UI元素都在此方法中
2. **`captureInput(true)`**：锁定输入焦点到当前节点，防止拖拽时意外操作其他节点
3. **`/view?filename=&type=input`**：ComfyUI 内置的文件查看 API
4. **widget.disabled**：设为 true 禁止用户手动编辑值
5. **`node.setSize()`**：设置节点最小尺寸以容纳图像预览

## 注意事项

1. **坐标取整**：`Math.floor()` 防止 Canvas 亚像素渲染导致的模糊
2. **图像缓存**：使用 `node.imgCache` 避免每帧重新加载
3. **遮罩绘制顺序**：先画图像 → 再画遮罩 → 再画红框 → 最后画UI
4. **拖拽边界**：裁剪框不能超出图像边界 `maxX = img.width - cropW`
5. **16倍数对齐**：Stable Diffusion 模型要求宽高为16的倍数
6. **高DPI屏幕**：`renderScale` 需考虑 `window.devicePixelRatio`
