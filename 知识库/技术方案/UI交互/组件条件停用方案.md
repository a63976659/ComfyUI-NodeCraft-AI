# 组件条件停用方案

## 来源
参考工具/项目：ComfyUI-prompt-formula（https://www.bilibili.com/video/BV1UBB2YhEpJ）
定位：根据主选项切换动态启用/禁用相关子组件，同时保证后端始终能正常输出

## 适用场景
- 节点有一个主控选项（如"转场方式"），不同选项对应不同的子参数
- 需要隐藏/禁用不相关的子参数减少视觉噪音
- 后端必须容忍被禁用组件传来的默认值，确保输出不出错

## 核心思路
前端通过监听主控 widget 的 callback，根据当前值决定哪些子 widget 启用、哪些禁用。后端所有可选参数使用默认值"无"，执行逻辑中检查参数是否为"无"来决定是否处理，确保即使前端隐藏了组件，后端也能安全输出。

## 实现步骤

### 1. 后端定义所有可选参数（默认值为"无"）
```python
class 视频首尾帧转场:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "主要转场方式": (TRANSITION_TYPES, {"default": "运镜提示词转场"}),
                "首帧描述": ("STRING", {"multiline": True}),
                "尾帧描述": ("STRING", {"multiline": True}),
            },
            "optional": {
                "运动子类型": (MOTION_SUBTYPES, {"default": "缩放转场"}),
                "运动方向": (MOTION_DIRECTIONS, {"default": "向前"}),
                "变形子类型": (MORPH_SUBTYPES, {"default": "有机变形"}),
                "遮挡物类型": (OCCLUSION_TYPES, {"default": "前景物体遮挡"}),
            }
        }
```

### 2. 前端条件隐显逻辑
```javascript
const videoTransitionHandler = function(node) {
    const mainWidget = findWidgetByName(node, "主要转场方式");
    const motionSubtype = findWidgetByName(node, "运动子类型");
    const morphSubtype = findWidgetByName(node, "变形子类型");
    const occlusionType = findWidgetByName(node, "遮挡物类型");
    
    function toggleWidget(widget, show) {
        if (!widget) return;
        widget.disabled = !show;
    }
    
    // 先全部禁用
    toggleWidget(motionSubtype, false);
    toggleWidget(morphSubtype, false);
    toggleWidget(occlusionType, false);
    
    // 根据主选项启用相关子组件
    switch (mainWidget.value) {
        case "运镜提示词转场":
            toggleWidget(motionSubtype, true);
            toggleWidget(motionDirectionWidget, true);
            break;
        case "形态变形转场":
            toggleWidget(morphSubtype, true);
            break;
        case "遮挡物转场":
            toggleWidget(occlusionType, true);
            break;
    }
};
```

### 3. 监听主控 widget 变化
```javascript
const mainWidget = findWidgetByName(node, "主要转场方式");
if (mainWidget) {
    const origCb = mainWidget.callback;
    mainWidget.callback = function() {
        if (origCb) origCb.apply(this, arguments);
        videoTransitionHandler(node);
    };
}
```

### 4. 后端安全输出（容忍无效参数）
```python
def 生成转场提示词(self, 主要转场方式, 首帧描述, 尾帧描述,
                    运动子类型="无", 运动方向="无", 变形子类型="无",
                    遮挡物类型="无", ...):
    
    转场输出 = ""
    
    # 只处理当前转场方式相关的参数
    if 主要转场方式 == "运镜提示词转场":
        if 运动子类型 != "无" and 运动方向 != "无":
            转场输出 = self._generate_motion(运动子类型, 运动方向)
    elif 主要转场方式 == "形态变形转场":
        if 变形子类型 != "无":
            转场输出 = self._generate_morph(变形子类型)
    elif 主要转场方式 == "遮挡物转场":
        if 遮挡物类型 != "无":
            转场输出 = self._generate_occlusion(遮挡物类型)
    
    # 组装完整输出（即使转场为空也能正常返回）
    组件 = [x for x in [首帧描述, 转场输出, 尾帧描述] if x]
    完整提示词 = "，".join(组件) if 组件 else ""
    
    # 清理多余逗号
    完整提示词 = re.sub(r',\s+,', ',', 完整提示词)
    
    return (转场输出, 完整提示词)
```

## ComfyUI 适配要点

1. **widget.disabled**：ComfyUI 原生支持，禁用后 widget 变灰且不可编辑
2. **参数仍然传递**：即使 widget 被禁用，其 value 仍会传递到后端执行函数
3. **callback 链式调用**：保存并调用原始 callback，不覆盖框架行为
4. **optional 输入**：被禁用的参数放在 optional 中，允许不连线

## 注意事项

1. **默认值一致**：前端禁用的 widget 保持其默认值，后端需用该值作为"未使用"标记
2. **序列化完整**：所有 widget（包括被禁用的）的值都会被序列化保存
3. **加载恢复**：`onConfigure` 中需重新执行隐显逻辑以恢复正确状态
4. **输出类型固定**：无论哪种模式，`RETURN_TYPES` 不变，确保下游连线不断
5. **空值保护**：后端始终检查参数有效性，避免 None 或空字符串导致异常
