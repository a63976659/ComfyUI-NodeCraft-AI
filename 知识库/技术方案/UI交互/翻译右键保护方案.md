# 翻译右键保护方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：翻译右键菜单显示文本的同时，通过回调包装确保菜单功能不受影响

## 适用场景
- 需要翻译上下文菜单（右键菜单）的显示文本
- 菜单回调函数依赖 `content` 字段做逻辑分发
- 需要在不修改 LiteGraph 源码的前提下实现菜单翻译

## 核心思路
拦截 `LiteGraph.ContextMenu` 构造函数，在菜单项创建前将 `content` 翻译为中文显示，同时包装每个菜单项的 `callback`：在回调执行前临时恢复 `content` 为英文原文，让 LiteGraph 内部逻辑正确匹配，执行后恢复中文显示。菜单存在**两种回调类型**：独立回调（`value.callback`）和共享回调（`options.callback`），两者都必须包装。

## 实现步骤

### 1. 拦截 ContextMenu 构造函数
```javascript
static applyContextMenuTranslation(app) {
    const originalContextMenu = LiteGraph.ContextMenu;
    
    LiteGraph.ContextMenu = function(values, options) {
        // 翻译菜单项
        for (let value of values) {
            if (value == null || !value.hasOwnProperty("content")) continue;
            
            // 用 _originalContent || content 确保取到最早的英文原始值，防止多次翻译覆盖
            let originalContent = value._originalContent || value.content;
            let isTranslated = false;
            
            // 尝试翻译节点名
            if (value.value in tN) {
                value.content = tN[value.value]["title"] || value.content;
                isTranslated = true;
            }
            // 尝试翻译菜单文本
            else if (value.content in menuT) {
                value.content = menuT[value.content];
                isTranslated = true;
            }
            // 动态菜单：正则匹配 "Convert X to input/widget"
            else {
                const translated = translateDynamicMenu(value.content);
                if (translated) {
                    value.content = translated;
                    isTranslated = true;
                }
            }
            
            if (isTranslated) {
                value._originalContent = originalContent;
                // 包装回调（见步骤2）
            }
        }
        
        // 调用原始构造函数
        const ctx = originalContextMenu.call(this, values, options);
        return ctx;
    };
    
    // 保持原型链
    LiteGraph.ContextMenu.prototype = originalContextMenu.prototype;
}
```

### 2. 回调包装（核心保护机制，两种回调都需处理）
```javascript
// 类型一：包装单个菜单项的独立回调 value.callback
if (typeof value.callback === "function") {
    const originalCallback = value.callback;
    value.callback = function(v, ...args) {
        const translatedContent = v.content;
        v.content = v._originalContent;    // 执行前恢复英文
        const result = originalCallback.apply(this, [v, ...args]);
        v.content = translatedContent;     // 执行后恢复中文
        return result;
    };
}

// 类型二：包装共享回调 options.callback（菜单项无独立 callback 时由此处理）
if (options && typeof options.callback === "function") {
    const originalOptCallback = options.callback;
    options.callback = function(v, ...args) {
        if (v && v._originalContent) {
            const translatedContent = v.content;
            v.content = v._originalContent;
            const result = originalOptCallback.apply(this, [v, ...args]);
            v.content = translatedContent;
            return result;
        }
        return originalOptCallback.apply(this, [v, ...args]);
    };
}
```

### 3. 动态菜单正则翻译（Convert X to input/widget）
```javascript
function translateDynamicMenu(content) {
    // "Convert 种子 to input" 这类动态生成的菜单项
    let m = content.match(/^Convert (.*) to input$/);
    if (m) {
        const inner = translateWidgetName(m[1]);  // 翻译内部变量名
        return `转换 ${inner} 为输入`;
    }
    m = content.match(/^Convert (.*) to widget$/);
    if (m) {
        const inner = translateWidgetName(m[1]);
        return `转换 ${inner} 为控件`;
    }
    return null;
}
```

### 4. 画布菜单选项翻译
```javascript
// 拦截画布右键菜单生成
var originalGetCanvasMenuOptions = LGraphCanvas.prototype.getCanvasMenuOptions;
LGraphCanvas.prototype.getCanvasMenuOptions = function() {
    var res = originalGetCanvasMenuOptions.apply(this, arguments);
    
    for (let item of res) {
        if (item == null || !item.hasOwnProperty("content")) continue;
        if (item.content in menuT) {
            if (!item._originalContent) item._originalContent = item.content;
            item.content = menuT[item.content];
        }
    }
    return res;
};
```

## ComfyUI 适配要点

1. **LiteGraph.ContextMenu**：LiteGraph 的菜单构造函数，所有右键菜单通过此创建
2. **value.content**：菜单项的显示文本，同时被部分回调用作逻辑标识
3. **两种回调类型**：`value.callback`（独立回调）和 `options.callback`（共享回调），必须都包装
4. **动态菜单正则**：`/Convert (.*) to input/` 等动态生成项需正则匹配翻译
5. **原型链保持**：`LiteGraph.ContextMenu.prototype = originalContextMenu.prototype` 确保 instanceof 检查通过

## 注意事项

1. **必须保持原型链**：替换构造函数后如果不保持原型链，`instanceof` 检查会失败
2. **_originalContent 检查**：只对实际翻译过的菜单项包装回调，避免无谓开销
3. **防止多次翻译覆盖**：始终用 `value._originalContent || value.content` 取最早的英文原始值
4. **嵌套菜单**：子菜单也通过 ContextMenu 创建，拦截会自动处理
5. **异步回调**：如果 callback 是异步的，恢复中文需在 await 之后
6. **value vs options.callback**：LiteGraph 先检查 value.callback，不存在时用 options.callback
