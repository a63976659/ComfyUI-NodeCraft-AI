# 翻译数据加载方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：实现多语言翻译数据的组织、存储、编译与加载，支持按插件分文件管理

## 适用场景
- 需要为插件提供多语言/国际化支持
- 需要大量文本映射的场景（如翻译、别名管理）
- 需要按模块分文件管理配置数据并动态合并

## 核心思路
翻译数据按三层结构组织：Nodes（节点翻译）、Menus（菜单翻译）、Categories（分类翻译），每层按插件名分独立 JSON 文件存储。后端提供编译 API 将多文件合并为单一响应（支持 Gzip 压缩），前端通过一次请求获取全部翻译数据缓存到内存。

## 实现步骤

### 1. 翻译数据文件结构
```
zh-CN/
├── Nodes/                    # 按插件名分文件
│   ├── internal.json         # ComfyUI 核心节点翻译
│   ├── ComfyUI-Easy-Use.json # 第三方插件翻译
│   └── ...                   # 共 366 个文件
├── Menus/                    # 菜单文本映射
│   └── *.json                # 键值对：英文→中文
└── Categories/               # 节点分类翻译
    └── *.json
```

### 2. 节点翻译 JSON 格式

### 3. 后端编译 API
```python
@server.PromptServer.instance.routes.post("/translation_node/get_translation")
async def get_translation(request):
    locale = post.get("locale", GLOBAL_CONFIG.get("locale", "zh-CN"))
    if not GLOBAL_CONFIG.get("translation_enabled"):
        return web.Response(status=200, body="{}")
    
    json_data = compile_translation(locale, disabled_plugins)
    return web.Response(status=200, body=json_data,
                       headers={"Content-Encoding": "gzip"})

def compile_translation(locale, disabled_plugins=None):
    """合并三类翻译数据为单一对象"""
    nodes_translation = get_nodes_translation(locale, disabled_plugins)
    node_category_translation = get_category_translation(locale)
    menu_translation = get_menu_translation(locale)
    
    return json.dumps({
        "Nodes": nodes_translation,
        "NodeCategory": node_category_translation,
        "Menu": menu_translation
    }, ensure_ascii=False)

def get_nodes_translation(locale, disabled_plugins=None):
    path = CUR_PATH.joinpath(locale, "Nodes")
    disabled = set(disabled_plugins or [])
    translations = {}
    for jpath in path.glob("*.json"):
        if jpath.stem in disabled:
            continue  # 跳过禁用的插件翻译
        translations.update(try_get_json(jpath))
    return translations
```

### 4. 前端加载与缓存
```javascript
static async syncTranslation() {
    const response = await fetch("./translation_node/get_translation", {
        method: "POST",
        body: JSON.stringify({ locale: currentConfig.locale })
    });
    const data = await response.json();
    TUtils.T = data;  // 全局缓存翻译数据

    // 加载后三步合并处理
    this.postProcess(data);
}
```

### 5. 加载后三步合并处理
```javascript
static postProcess(data) {
    // 步骤1：合并 NodeCategory 到 Menu（分类翻译也走菜单翻译通道）
    Object.assign(data.Menu, data.NodeCategory || {});

    // 步骤2：提取每个 Nodes 的 title 到 Menu（节点名也可作菜单文本翻译）
    for (const [cls, t] of Object.entries(data.Nodes || {})) {
        if (t.title && !(cls in data.Menu)) {
            data.Menu[cls] = t.title;
        }
    }

    // 步骤3：构建 translatedValueSet（所有中文目标值，供 O(1) 去重判断）
    buildTranslatedSet(data.Menu);
}
```

### 6. 后端多编码读取（utf-8/gbk fallback）
```python
def try_get_json(jpath):
    for encoding in ("utf-8", "gbk"):  # 优先 utf-8，失败回退 gbk
        try:
            with open(jpath, "r", encoding=encoding) as f:
                return json.load(f)
        except (UnicodeDecodeError, json.JSONDecodeError):
            continue
    return {}
```

## ComfyUI 适配要点

1. **PromptServer 路由注册**：使用 `@server.PromptServer.instance.routes.post()` 注册后端 API
2. **Gzip 压缩**：翻译数据量大（366个文件），压缩后传输减少 70%+ 体积
3. **插件名作为文件名**：与 ComfyUI 的 `custom_nodes` 目录名一一对应，便于管理
4. **ensure_ascii=False**：JSON 序列化时保留中文字符原文

## 注意事项

1. **文件编码**：所有 JSON 文件必须为 UTF-8 编码
2. **JSON 键名匹配**：节点翻译的键名必须与 `comfyClass` 完全一致
3. **增量更新**：新增插件时只需添加新的 JSON 文件，无需修改其他文件
4. **缺失处理**：翻译中缺失的键自动使用英文原名显示
5. **启动性能**：文件数量多时可考虑预编译缓存机制
6. **加载后三步合并**：合并 NodeCategory 到 Menu、提取 Nodes.title 到 Menu、构建 translatedValueSet
7. **多编码兼容**：读取 JSON 时先试 utf-8，失败回退 gbk，避免个别文件编码不一致导致整体加载失败
