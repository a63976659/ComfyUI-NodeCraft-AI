# 翻译搜索兼容方案

## 来源
参考工具/项目：ComfyUI-Chinese-Translation（https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation）
定位：确保翻译后的节点搜索功能正常，搜索结果显示中文名，同时英文搜索不受影响

## 适用场景
- 翻译了节点显示名后需要保持搜索功能可用
- 需要搜索结果同时支持原始名和翻译名
- 需要在不修改搜索引擎的前提下实现双语搜索体验

## 核心思路
不修改 ComfyUI/LiteGraph 的搜索逻辑（仍以英文类名为索引），而是通过 MutationObserver 监听搜索结果列表的 DOM 变化，在搜索结果渲染后将显示文本替换为中文翻译名。用户可用英文搜索（底层匹配），搜索结果显示中文（表层翻译）。

## 实现步骤

### 1. 搜索框 Observer 设置
```javascript
function setupSearchBoxObserver() {
    const searchObserver = observeFactory(
        document.querySelector(".litegraph"),
        (mutationsList, observer) => {
            for (let mutation of mutationsList) {
                for (const sb of mutation.addedNodes) {
                    if (!sb || !sb.querySelector) continue;
                    
                    // 检测搜索建议列表出现
                    const helper = sb.querySelector(".helper");
                    if (!helper) continue;
                    
                    // 监听搜索结果变化
                    const helperObserver = observeFactory(helper, (mutations) => {
                        for (let m of mutations) {
                            for (const item of m.addedNodes) {
                                translateSearchItem(item);
                            }
                        }
                    });
                    
                    // 初始化已有结果
                    for (let item of helper.querySelectorAll(".lite-search-item")) {
                        translateSearchItem(item);
                    }
                }
            }
        }
    );
}
```

### 2. 搜索结果项翻译
```javascript
function translateSearchItem(item) {
    if (item.innerText && texe.T.Nodes[item.innerText]) {
        // 将英文类名替换为中文翻译名
        item.innerText = texe.T.Nodes[item.innerText]["title"] || item.innerText;
    }
}
```

### 3. 搜索流程分析
```
用户输入: "KSam"
    ↓
LiteGraph 搜索引擎（不修改）:
    遍历 LiteGraph.registered_node_types
    过滤类名包含 "KSam" 的节点
    ↓
搜索结果 DOM 渲染:
    <div class="lite-search-item">KSampler</div>
    <div class="lite-search-item">KSamplerAdvanced</div>
    ↓
MutationObserver 捕获新增节点:
    translateSearchItem(item)
    ↓
最终显示:
    <div class="lite-search-item">K采样器</div>
    <div class="lite-search-item">K采样器(高级)</div>
```

### 4. 搜索结果点击处理
```javascript
// LiteGraph 内部搜索结果点击逻辑使用 value 属性（非 innerText）
// 因此翻译 innerText 不影响点击添加节点的行为

// 搜索结果 item 结构：
// <div class="lite-search-item" data-type="KSampler">K采样器</div>
//                                ^^^^^^^^^^^^^^^^^ 点击时用这个值创建节点
//                                                  ^^^^^^ 只是显示翻译
```

## ComfyUI 适配要点

1. **`.helper`**：LiteGraph 搜索建议列表的容器 class
2. **`.lite-search-item`**：每个搜索结果项的 class
3. **搜索匹配逻辑不变**：LiteGraph 用 registered_node_types 的 key 做模糊匹配
4. **data-type 属性**：搜索结果点击时使用此属性创建节点，翻译 innerText 不影响

## 注意事项

1. **搜索仍是英文**：用户需输入英文类名的部分字符来搜索，中文搜索需额外扩展
2. **标题变化时机**：搜索结果先渲染英文，MutationObserver 翻译后可能有短暂闪烁
3. **虚拟滚动**：如果搜索结果使用虚拟滚动，需监听滚动事件重新翻译可见项
4. **搜索框清空**：清空搜索框时建议列表消失，Observer 自动停止无需手动清理
5. **新版 ComfyUI 搜索**：新版使用 Vue 组件渲染搜索结果，需额外适配 `.p-virtualscroller`
