# 视频提取单帧方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：从视频中精确提取指定时间点的单帧图像，输出 ComfyUI IMAGE 格式

## 适用场景
- 从视频中提取关键帧用于后续图像处理
- 视频转图像的预处理步骤
- 需要精确定位到特定时间点的帧提取

## 核心思路
使用 OpenCV 的 `VideoCapture` 打开视频，通过 `CAP_PROP_POS_FRAMES` 精确定位到指定帧号（由时间戳 × FPS 计算），读取帧后转换为 ComfyUI 标准的 `[batch, H, W, 3]` float32 张量。

## 实现步骤

### 1. 时间戳转帧号 + 精确定位
```python
import cv2
import numpy as np
import torch

def extract_single_frame(path, time_seconds):
    cap = cv2.VideoCapture(path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    
    # 时间戳转帧号
    target_frame = int(time_seconds * fps)
    target_frame = min(target_frame, total_frames - 1)  # 防越界
    
    # 精确定位
    cap.set(cv2.CAP_PROP_POS_FRAMES, target_frame)
    ret, frame = cap.read()
    cap.release()
    
    if not ret:
        return torch.zeros((1, 64, 64, 3), dtype=torch.float32)
    
    # BGR -> RGB + 归一化
    frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    frame = frame.astype(np.float32) / 255.0
    
    return torch.from_numpy(np.array([frame]))  # [1, H, W, 3]
```

### 3. 错误降级
```python
# 解码失败返回默认黑色帧
if not ret:
    return torch.zeros((1, 64, 64, 3), dtype=torch.float32)
```

## ComfyUI 适配要点

1. **IMAGE 格式**：`[batch, height, width, 3]`，float32，范围 `[0, 1]`
2. **单帧 batch=1**：即使是单帧也必须有 batch 维度
3. **输入参数**：时间（秒）作为 FLOAT 类型输入
```python
RETURN_TYPES = ("IMAGE",)
"当前时间": ("FLOAT", {"default": 0.0, "min": 0.0, "step": 0.01})
```

## 注意事项

1. **BGR 转 RGB**：OpenCV 默认 BGR 格式，必须转换
2. **帧号越界**：目标帧号不能超过 total_frames - 1
3. **关键帧定位**：`CAP_PROP_POS_FRAMES` 可能不精确（视频编码问题），非关键帧需要顺序解码
4. **可变帧率**：VFR 视频中时间戳转帧号可能不准确
5. **内存释放**：使用后必须 `cap.release()` 释放资源
