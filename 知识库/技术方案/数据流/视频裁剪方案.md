# 视频裁剪方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：从视频中裁剪指定时间段，同时输出帧序列、音频和视频文件

## 适用场景
- 从长视频中截取片段用于后续处理
- 需要同时获取视频帧序列和音频的场景
- 视频预处理管道中的裁剪步骤

## 核心思路
FFmpeg 无损快速裁剪视频文件（`-c copy`），OpenCV 逐帧解码提取帧序列，FFmpeg 独立提取音频轨道。三路输出分别对应 ComfyUI 的 IMAGE、AUDIO、VIDEO 类型。

## 实现步骤

### 1. FFmpeg 无损视频裁剪
```python
import subprocess

def crop_video(path, start_time, duration, output_path):
    cmd = ["ffmpeg", "-y", "-ss", str(start_time), "-i", path]
    if duration > 0:
        cmd.extend(["-t", str(duration)])
    cmd.extend(["-c", "copy", output_path])  # 无损复制，不重编码
    subprocess.run(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
```

### 2. 帧序列提取（OpenCV）
```python
def extract_frames(path, start_time, end_time):
    cap = cv2.VideoCapture(path)
    fps = cap.get(cv2.CAP_PROP_FPS)
    
    start_frame = int(start_time * fps)
    end_frame = int(end_time * fps)
    
    cap.set(cv2.CAP_PROP_POS_FRAMES, start_frame)
    
    frames = []
    for i in range(end_frame - start_frame):
        ret, frame = cap.read()
        if not ret:
            break
        frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        frames.append(frame)
    
    cap.release()
    
    # 转为 ComfyUI IMAGE 格式
    frames_np = np.array(frames, dtype=np.float32) / 255.0
    return torch.from_numpy(frames_np)  # [N, H, W, 3]
```

### 3. 音频轨道同步提取
```python
def extract_audio(path, start_time, duration):
    temp_wav = tempfile.mktemp(suffix=".wav")
    cmd = ["ffmpeg", "-y"]
    if start_time > 0:
        cmd.extend(["-ss", str(start_time)])
    cmd.extend(["-i", path])
    if duration > 0:
        cmd.extend(["-t", str(duration)])
    cmd.extend(["-vn", "-acodec", "pcm_s16le", "-ar", "44100", "-ac", "2", temp_wav])
    subprocess.run(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    
    waveform, sample_rate = torchaudio.load(temp_wav)
    os.remove(temp_wav)
    return {"waveform": waveform.unsqueeze(0), "sample_rate": sample_rate}
```

### 4. 三路输出
```python
RETURN_TYPES = ("IMAGE", "AUDIO", "VIDEO")
RETURN_NAMES = ("图像序列", "音频", "视频")

def execute(self, path, start_time, duration):
    end_time = start_time + duration if duration > 0 else None
    
    frames = extract_frames(path, start_time, end_time)
    audio = extract_audio(path, start_time, duration)
    video = crop_video(path, start_time, duration, output_path)
    
    return (frames, audio, video)
```

## ComfyUI 适配要点

1. **多类型输出**：同时输出 IMAGE（帧序列）、AUDIO（音频）、VIDEO（视频文件）
2. **IMAGE 格式**：`[N, H, W, 3]` float32，N 为帧数
3. **AUDIO 格式**：`{"waveform": Tensor, "sample_rate": int}`
4. **VIDEO 格式**：文件路径字符串或自定义对象

## 注意事项

1. **FFmpeg 必须安装**：系统 PATH 中需要有 ffmpeg
2. **显存/内存占用**：长视频的帧序列可能非常大（1分钟 30fps = 1800 帧）
3. **`-c copy` 限制**：无损裁剪的起止点只能在关键帧处精确
4. **临时文件管理**：裁剪生成的临时文件需要及时清理
5. **无音频视频**：某些视频可能没有音轨，需要容错处理
6. **BGR 转 RGB**：OpenCV 读取的帧默认 BGR，必须转换
