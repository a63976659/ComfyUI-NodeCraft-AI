# 音频裁剪方案

## 来源
参考工具/项目：ComfyUI-Artificial-Intelligence（https://github.com/a63976659/ComfyUI-Artificial-Intelligence）
定位：通过 FFmpeg + torchaudio 双方案实现精确音频裁剪

## 适用场景
- 需要从长音频中截取指定时间段的节点
- 音频预处理管道中的裁剪步骤
- 需要前端可视化交互选择裁剪区间的场景

## 核心思路
优先使用 FFmpeg 命令行裁剪（快速、支持所有格式），失败时降级到 torchaudio 纯 Python 处理。输出标准化为 PCM 16-bit、44100Hz、立体声的 ComfyUI AUDIO 格式。

## 实现步骤

### 1. FFmpeg 方案（优先）
```python
import subprocess
import tempfile

def crop_audio_ffmpeg(path, start_time, duration):
    temp_wav = tempfile.mktemp(suffix=".wav")
    
    cmd = ["ffmpeg", "-y"]
    if start_time > 0:
        cmd.extend(["-ss", str(start_time)])
    cmd.extend(["-i", path])
    if duration > 0:
        cmd.extend(["-t", str(duration)])
    # 标准化输出：PCM 16-bit, 44100Hz, 立体声
    cmd.extend(["-vn", "-acodec", "pcm_s16le", "-ar", "44100", "-ac", "2", temp_wav])
    
    subprocess.run(cmd, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    return temp_wav
```

### 2. torchaudio 降级方案
```python
import torchaudio

def crop_audio_torchaudio(path, start_time, duration):
    waveform, sample_rate = torchaudio.load(path)
    
    start_frame = int(start_time * sample_rate)
    if duration > 0:
        end_frame = start_frame + int(duration * sample_rate)
    else:
        end_frame = waveform.shape[1]
    
    cropped = waveform[:, start_frame:end_frame]
    return cropped, sample_rate
```

### 3. 输出为 ComfyUI AUDIO 格式
```python
import torch

# 加载裁剪后的音频
waveform, sample_rate = torchaudio.load(temp_wav)
waveform = waveform.unsqueeze(0)  # [1, channels, samples]

return ({"waveform": waveform, "sample_rate": sample_rate},)
```

## ComfyUI 适配要点

1. **AUDIO 类型格式**：`{"waveform": Tensor[batch, channels, samples], "sample_rate": int}`
2. **参数设计**：开始时间和持续时间作为 FLOAT 输入（秒为单位）
```python
"开始时间": ("FLOAT", {"default": 0.0, "min": 0.0, "step": 0.01}),
"持续时间": ("FLOAT", {"default": 0.0, "min": 0.0, "step": 0.01}),  # 0=全长
```

## 注意事项

1. **FFmpeg 必须安装**：需要在系统 PATH 中配置
2. **临时文件清理**：使用 `tempfile.mktemp` 需要手动删除
3. **duration=0 表示全长**：需要特殊处理
4. **采样率统一**：不同源文件采样率不同，统一输出 44100Hz
5. **视频文件兼容**：`-vn` 参数自动忽略视频轨，只提取音频
