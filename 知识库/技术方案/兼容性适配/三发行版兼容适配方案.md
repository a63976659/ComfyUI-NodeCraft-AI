# 三发行版兼容适配方案

## 来源
参考工具/项目：NodeCraft AI 生产验证（本项目 `技术文档/13-桌面版与便携版兼容适配.md`，2026-07-28 全部改造点落地并验证）+ Flying-Translation2.0 适配经验 + ComfyUI 官方 README（https://github.com/Comfy-Org/ComfyUI）
定位：让插件在秋叶整合包/手动安装、桌面版 Desktop、便携版 Portable 三种发行版下均可正常运行的路径与环境适配方案

## 适用场景
- 插件需要读写 models/custom_nodes 等 ComfyUI 目录的场景
- 插件需要持久化自身数据（配置、缓存、日志）的场景
- 插件需要启动子进程或弹出系统对话框的场景
- 需要同时支持秋叶整合包、桌面版（Windows/macOS）、便携版（仅 Windows）的场景

## 核心思路
三种发行版的 Python 环境与目录布局差异巨大，适配核心是：**不信任任何硬编码假设**——目录解析优先 `folder_paths` + 同级布局推导兜底，数据落在插件自身目录内，子进程用 `sys.executable`，GUI 弹窗带非 tkinter 回退链，可选依赖全部 try 化。

## 发行版差异事实表

| 维度 | 秋叶整合包 / 手动安装 | 桌面版 Desktop | 便携版 Portable |
|------|---------------------|---------------|----------------|
| 支持平台 | 全平台 | Windows + macOS | 仅 Windows |
| Python | 完整版（含 tkinter/venv） | uv 管理的 `.venv`（无 tkinter） | `python_embeded` 嵌入式（无 tkinter/venv/ensurepip） |
| 目录布局 | 程序与数据同根 | **程序与数据分离**：custom_nodes 在用户数据目录且可重定向，可能与 models 不共根 | 程序与数据同根 |
| 全局 `python` 命令 | 通常有 | 无 | 无 |

**三类典型故障**：
1. **依赖连坐**——顶层裸导入缺失依赖（如脱离 ComfyUI 时的 `folder_paths`、桌面版的 tkinter），把整条导入链拖垮；
2. **相对路径推算失效**——用 `..\..` 从插件目录硬推 ComfyUI 根/模型目录，桌面版程序与数据分离后全部失效；
3. **tkinter 缺失**——桌面版/便携版不带 tkinter，且子线程内异常不会传播到主线程，静默失败难排查。

## 实现步骤

### 1. folder_paths try 化 + models 目录解析策略
顶层裸 `import folder_paths` 在脱离 ComfyUI（单测/独立脚本）时会炸掉整条导入链；桌面版下 `folder_paths.models_dir` 可能指向程序资源目录而非用户数据目录。

```python
from pathlib import Path

try:
    import folder_paths
except Exception:
    folder_paths = None  # 脱离 ComfyUI 时兜底，各函数内判空


def get_custom_nodes_path():
    """获取 custom_nodes 目录：folder_paths 优先，插件位置推导兜底"""
    if folder_paths is not None:
        try:
            paths = folder_paths.get_folder_paths("custom_nodes")
            if paths:
                return Path(paths[0])
        except Exception:
            pass
    return Path(__file__).resolve().parent.parent  # 插件目录的上级


def get_models_dir() -> Path:
    """优先 custom_nodes 同级 models（三种发行版默认布局中两者都同级），
    不存在时回退 folder_paths.models_dir（桌面版该值可能不准，仅作兜底）"""
    同级models = get_custom_nodes_path().parent / "models"
    if 同级models.is_dir():
        return 同级models
    if folder_paths is not None:
        try:
            return Path(folder_paths.models_dir)
        except Exception:
            pass
    return 同级models
```

### 2. 数据目录落在插件自身目录内
插件自身的配置、缓存、日志等数据全部存放在插件目录内（如 `数据/`、`logs/`），不依赖 ComfyUI 根目录布局，三种发行版天然兼容。前端资源用相对路径声明 `WEB_DIRECTORY = "./前端"`，由 ComfyUI 解析，天然安全。

### 3. 子进程一律 sys.executable
桌面版/便携版没有全局 `python` 命令，裸 `"python"` 会导致工具静默降级：

```python
import sys
proc = await asyncio.create_subprocess_exec(sys.executable, "-m", "pylint", ...)
```

### 4. GUI 对话框非 tkinter 回退链
桌面版/便携版无 tkinter，回退链：tkinter → PowerShell WinForms（Windows）→ osascript（macOS）→ zenity/kdialog（Linux）。PowerShell 实现三要点：`[Console]::OutputEncoding=UTF8` 防中文路径乱码、TopMost 宿主窗体防对话框被压后台、`-STA` + `CREATE_NO_WINDOW` 防控制台闪现。tkinter 子线程异常须经容器变量显式捕获（线程内异常不会传播到主线程）。

### 5. venv/site-packages 路径用 sysconfig
禁止手工硬拼 `Lib/site-packages`（POSIX 布局不同）：

```python
import sysconfig
主环境site_packages = Path(sysconfig.get_paths()["purelib"])  # 全平台/venv 通用
```

venv 内部路径走平台分支：Win `Scripts/python.exe + Lib/site-packages`，POSIX `bin/python + lib/pythonX.Y/site-packages`。便携版嵌入式 Python 无 venv/ensurepip，需 `importlib.util.find_spec("venv"/"ensurepip")` 预检并给出可读提示。

### 6. 路径白名单覆盖全部合法根
路径穿越防护白名单须覆盖：ComfyUI 根（custom_nodes 父目录）+ custom_nodes + models，三根独立 resolve 后逐一 `is_relative_to` 校验——桌面版下 custom_nodes 与 models 不共根，单一白名单会误拦合法请求。

### 7. __init__.py 两段式导入加固
日志、版本号等辅助模块的导入全部 try 化（失败回退标准 logging / 仅记录异常），保证已声明的 `WEB_DIRECTORY`/`NODE_CLASS_MAPPINGS` 始终可被 ComfyUI 读到，避免整个插件被标记为加载失败。

## ComfyUI 适配要点（开发守则）

1. **禁止顶层裸导入运行时可能缺失的模块**：ComfyUI 运行时模块（`folder_paths`/`server`）与可选三方依赖一律 try 化或函数内延迟导入；
2. **禁止裸 `"python"` 子进程**：一律 `sys.executable`；
3. **禁止相对层级推算 ComfyUI 目录**：custom_nodes/models 用解析函数获取，不要 `..\..` 硬推；
4. **禁止硬编码 venv/site-packages 布局**：主环境用 `sysconfig.get_paths()["purelib"]`；
5. **GUI 弹窗必须有非 tkinter 回退**，且子线程异常必须经容器变量显式捕获；
6. **路径白名单校验须覆盖全部合法根**（根/custom_nodes/models）。

## 注意事项

- **不含模型功能的插件可低成本兼容三发行版**：models 目录不共根、venv 缺失两大雷区只在读写模型目录/创建 venv 时触发；数据落插件目录内 + 遵守守则即可天然兼容；
- **桌面版 custom_nodes 可被用户重定向**，任何"models 与 custom_nodes 必定共根"的假设都不可靠，解析时必须先探测目录存在性；
- **tkinter 静默失败难排查**：桌面版/便携版下子线程 tkinter 异常不会传播到主线程，必须在初始化阶段显式捕获并触发回退；
- 完整改造细节与验证记录见本项目 `技术文档/13-桌面版与便携版兼容适配.md`。
