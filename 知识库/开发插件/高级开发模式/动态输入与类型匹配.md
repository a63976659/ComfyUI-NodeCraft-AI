# 动态输入与类型匹配

## MatchType 泛型类型连接

MatchType 允许节点的输出类型动态匹配输入类型，实现类型安全的通用节点。

### Template - 定义类型模板

在输出端声明类型模板：

```python
class PassThroughNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="PassThroughNode",
            display_name="Pass Through",
            category="utils",
            inputs=[
                io.AnyType.Input("input", display_name="Any"),
            ],
            outputs=[
                io.AnyType.Output("OUTPUT", match_type=io.MatchType.Template("T")),
            ],
        )
```

### Input - 匹配输入类型

在输入端声明需要匹配的类型：

```python
inputs=[
    io.AnyType.Input("input", match_type=io.MatchType.Input("T")),
],
```

### Output - 匹配输出类型

在输出端使用匹配的类型：

```python
outputs=[
    io.AnyType.Output("OUTPUT", match_type=io.MatchType.Output("T")),
],
```

### 完整 MatchType 示例

```python
class SwitchNode(io.ComfyNode):
    """根据布尔值切换输出 A 或 B，输出类型与输入类型一致"""
    
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="SwitchNode",
            display_name="Switch",
            category="utils",
            inputs=[
                io.Boolean.Input("on", default=True),
                io.AnyType.Input("on_value", match_type=io.MatchType.Input("T")),
                io.AnyType.Input("off_value", match_type=io.MatchType.Input("T")),
            ],
            outputs=[
                io.AnyType.Output("OUTPUT", match_type=io.MatchType.Output("T")),
            ],
        )

    @classmethod
    def execute(cls, on, on_value, off_value):
        return io.NodeOutput(on_value if on else off_value)
```

## Autogrow 动态输入增长

Autogrow 允许用户在 UI 上动态添加输入端口。

### 基本用法

```python
class MergeImagesNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="MergeImagesNode",
            display_name="Merge Images",
            category="image",
            inputs=[
                io.Image.Input(
                    "images",
                    autogrow=io.Autogrow(
                        min_count=2,       # 最少 2 个输入
                        max_count=8,       # 最多 8 个输入
                        add_label="+Image", # 添加按钮标签
                    ),
                ),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
        )

    @classmethod
    def execute(cls, **kwargs):
        images = [v for k, v in sorted(kwargs.items()) if k.startswith("images_")]
        # 拼接所有图像
        result = torch.cat(images, dim=0)
        return io.NodeOutput(result)
```

### Autogrow 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| min_count | int | 1 | 最少输入数量 |
| max_count | int | 0 (无限) | 最多输入数量 |
| add_label | str | "+" | 添加按钮显示文本 |

### Autogrow 与 MatchType 组合

```python
inputs=[
    io.AnyType.Input(
        "values",
        autogrow=io.Autogrow(min_count=1, max_count=16),
        match_type=io.MatchType.Input("T"),
    ),
],
```

## DynamicCombo 动态下拉选项

DynamicCombo 允许下拉选项在运行时动态生成（如扫描模型文件列表）。

### 基本用法

```python
import folder_paths

class DynamicModelLoader(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="DynamicModelLoader",
            display_name="Dynamic Model Loader",
            category="loaders",
            inputs=[
                io.Combo.Input(
                    "model_name",
                    choices=io.DynamicCombo(
                        callback=cls._get_model_list,
                        refresh_button=True,      # 显示刷新按钮
                        refresh_label="Refresh",   # 刷新按钮标签
                    ),
                ),
            ],
            outputs=[
                io.Model.Output("MODEL"),
            ],
        )

    @staticmethod
    def _get_model_list():
        return folder_paths.get_filename_list("checkpoints")

    @classmethod
    def execute(cls, model_name):
        from comfy.sd import load_checkpoint_guess_config
        model = load_checkpoint_guess_config(model_name)
        return io.NodeOutput(model)
```

### DynamicCombo 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| callback | callable | 必需 | 返回选项列表的回调函数 |
| refresh_button | bool | False | 是否显示刷新按钮 |
| refresh_label | str | "Refresh" | 刷新按钮文本 |

### 常用动态选项回调

```python
# 获取检查点模型列表
folder_paths.get_filename_list("checkpoints")

# 获取 LoRA 列表
folder_paths.get_filename_list("loras")

# 获取 VAE 列表
folder_paths.get_filename_list("vae")

# 获取 ControlNet 列表
folder_paths.get_filename_list("controlnet")

# 获取自定义目录列表
folder_paths.get_filename_list("my_custom_folder")
```

## 节点扩展/展开（GraphBuilder）

GraphBuilder 允许节点在执行时动态创建新节点并插入工作流图。

### 基本用法

```python
from comfy_execution.graph_utils import GraphBuilder

class LoopNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="LoopNode",
            display_name="Loop",
            category="utils",
            inputs=[
                io.Image.Input("image"),
                io.Int.Input("iterations", default=3, min=1, max=100),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
        )

    @classmethod
    def execute(cls, image, iterations):
        graph = GraphBuilder()
        
        current = image
        for i in range(iterations):
            # 在图中动态插入节点
            node = graph.node("MyBlurNode", image=current, radius=2.0)
            current = node.out(0)
        
        # 编译图并获取结果
        result = graph.build().get_output(current)
        return io.NodeOutput(result)
```

### GraphBuilder API

```python
# 创建图构建器
graph = GraphBuilder()

# 添加节点
node = graph.node("NodeTypeId", input1=value1, input2=value2)

# 获取节点输出
output = node.out(index)  # index 为输出索引

# 构建并执行
result = graph.build().get_output(output_ref)
```

## 节点替换（向后兼容迁移）

NodeReplace 允许将旧节点透明替换为新节点，同时保持已保存工作流的兼容性。

### 基本用法

```python
from comfy_api.latest import ComfyExtension, io, NodeReplace
from typing_extensions import override

class NewImageProcessNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="NewImageProcessNode",
            display_name="Image Process V2",
            category="image",
            inputs=[
                io.Image.Input("image"),
                io.Float.Input("strength", default=1.0),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
        )

    @classmethod
    def execute(cls, image, strength):
        # 新的实现
        result = image * strength
        return io.NodeOutput(result)

class MyExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [NewImageProcessNode]

    @override
    async def get_node_replacements(self) -> list[NodeReplace]:
        return [
            NodeReplace(
                old="OldImageProcessNode",     # 旧 node_id
                new="NewImageProcessNode",     # 新 node_id
                input_map={                    # 输入名映射（可选）
                    "img": "image",            # 旧名 → 新名
                    "power": "strength",
                },
            ),
        ]
```

### NodeReplace 参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| old | str | ✓ | 旧节点 node_id |
| new | str | ✓ | 新节点 node_id |
| input_map | dict | | 旧输入名到新输入名的映射 |

### 迁移最佳实践

1. 保留旧的 `node_id` 在 `NodeReplace` 中注册
2. 使用 `input_map` 处理输入名称变更
3. 新节点应兼容旧节点的输入格式
4. 在 `search_aliases` 中添加旧名称以提高可发现性
5. 设置 `is_deprecated=True` 标记旧版节点（如果仍保留）
