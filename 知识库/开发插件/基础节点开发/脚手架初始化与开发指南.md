# 脚手架初始化与开发指南

## 自动生成的项目结构

新建插件项目时，系统自动生成以下文件和目录：

```
{plugin_name}/
├── __init__.py          # ComfyUI 节点注册入口
├── README.md            # 项目说明文档
├── requirements.txt     # Python 依赖声明
├── 逻辑处理模块/        # 节点业务代码目录
└── 界面与静态资源/      # 前端 JS/CSS 资源目录
```

### 各文件用途说明

| 文件/目录 | 用途 | 是否必需 |
|-----------|------|---------|
| `__init__.py` | ComfyUI 加载插件的入口点，包含节点注册映射和前端目录声明 | ✅ 必需 |
| `README.md` | 项目介绍、安装说明、使用文档 | 推荐 |
| `requirements.txt` | 声明额外 Python 依赖（pip install 使用） | 推荐 |
| `逻辑处理模块/` | 存放节点类代码，每个功能模块一个 .py 文件 | ✅ 必需 |
| `界面与静态资源/` | 存放前端扩展 JS 文件和 CSS 样式 | 如需前端功能 |

脚手架生成后，`逻辑处理模块/` 与 `界面与静态资源/` 默认为空目录，需要开发者按需添加节点代码与前端扩展文件。`requirements.txt` 默认为空文件，仅在引入 ComfyUI 未内置的依赖时才需要填写。

## __init__.py 模板详解

自动生成的 `__init__.py` 内容如下：

```python
# AI 自动生成的 ComfyUI 节点注册入口
WEB_DIRECTORY = "./界面与静态资源"

NODE_CLASS_MAPPINGS = {}
NODE_DISPLAY_NAME_MAPPINGS = {}
__all__ = ['NODE_CLASS_MAPPINGS', 'NODE_DISPLAY_NAME_MAPPINGS', 'WEB_DIRECTORY']
```

### 各字段含义

- **WEB_DIRECTORY**: 指定前端资源目录路径，ComfyUI 启动时会自动加载该目录下的 `.js` 文件
- **NODE_CLASS_MAPPINGS**: 字典，键为节点 ID（字符串），值为节点类。ComfyUI 通过此映射发现和加载节点
- **NODE_DISPLAY_NAME_MAPPINGS**: 字典，键为节点 ID，值为用户友好的显示名称
- **__all__**: 模块导出列表，确保 ComfyUI 能正确访问这些变量

### 完善 __init__.py 的方式

当用户创建了节点类后，需要更新 `__init__.py`：

```python
# AI 自动生成的 ComfyUI 节点注册入口
WEB_DIRECTORY = "./界面与静态资源"

from .逻辑处理模块.图像处理 import ImageEnhanceNode
from .逻辑处理模块.文本处理 import TextFormatNode

NODE_CLASS_MAPPINGS = {
    "ImageEnhanceNode": ImageEnhanceNode,
    "TextFormatNode": TextFormatNode,
}
NODE_DISPLAY_NAME_MAPPINGS = {
    "ImageEnhanceNode": "图像增强",
    "TextFormatNode": "文本格式化",
}
__all__ = ['NODE_CLASS_MAPPINGS', 'NODE_DISPLAY_NAME_MAPPINGS', 'WEB_DIRECTORY']
```

## 从脚手架到第一个节点

### 第 1 步：在逻辑处理模块中创建节点文件

在 `逻辑处理模块/` 目录中创建 Python 文件（如 `图像处理.py`）：

```python
import torch
from comfy_api.latest import io

class ImageEnhanceNode(io.ComfyNode):
    """图像增强节点 - 调整亮度和对比度"""

    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="ImageEnhanceNode",
            display_name="图像增强",
            description="调整图像的亮度和对比度",
            category="image/enhance",
            inputs=[
                io.Image.Input("image", display_name="输入图像"),
                io.Float.Input("brightness", display_name="亮度", default=1.0, min=0.0, max=3.0, step=0.1),
                io.Float.Input("contrast", display_name="对比度", default=1.0, min=0.0, max=3.0, step=0.1),
            ],
            outputs=[
                io.Image.Output("IMAGE", display_name="输出图像"),
            ],
        )

    @classmethod
    def execute(cls, image, brightness, contrast):
        # image 格式: [B, H, W, C] float32, 范围 0-1
        result = image * brightness
        mean = result.mean(dim=-1, keepdim=True)
        result = (result - mean) * contrast + mean
        result = torch.clamp(result, 0.0, 1.0)
        return io.NodeOutput(result)
```

### 第 2 步：在 __init__.py 中注册

将节点导入并加入映射字典：

```python
from .逻辑处理模块.图像处理 import ImageEnhanceNode

NODE_CLASS_MAPPINGS = {
    "ImageEnhanceNode": ImageEnhanceNode,
}
NODE_DISPLAY_NAME_MAPPINGS = {
    "ImageEnhanceNode": "图像增强",
}
```

### 第 3 步：重启 ComfyUI

节点将在菜单中显示：`Add Node → image/enhance → 图像增强`

## 前端扩展开发指南

`界面与静态资源/` 目录用于存放前端 JavaScript 文件。

### 适用场景

- 自定义 Widget（如颜色选择器、滑块等）
- 节点外观定制（颜色、图标、大小）
- 事件监听和 UI 交互
- Python 节点与前端的通信

### 基本结构

在 `界面与静态资源/` 中创建 `.js` 文件：

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "MyPlugin.Extension",
    async nodeCreated(node) {
        if (node.comfyClass === "ImageEnhanceNode") {
            // 自定义节点创建后的行为
        }
    }
});
```

ComfyUI 启动时会自动加载 WEB_DIRECTORY 指定目录中的所有 `.js` 文件。

## 命名规范

### 必须英文命名
- **插件根目录**：如 `ComfyUI-MyNodes`、`my_image_tool`（只允许字母、数字、下划线、连字符）
- **`__init__.py`**：固定名称，不可更改

### 允许中文命名
- **业务子目录**：如 `逻辑处理模块/`、`界面与静态资源/`
- **业务 Python 文件**：如 `图像处理.py`、`文本工具.py`

### 常见错误
- ❌ 中文命名插件根目录（ComfyUI 无法识别）
- ❌ 忘记在 `__init__.py` 中导入和注册节点
- ❌ `node_id` 包含空格或特殊字符
- ❌ 修改 `__init__.py` 文件名

## requirements.txt 使用说明

仅需声明项目额外依赖（ComfyUI 内置包不需要）：

```
# 示例：项目需要 OpenCV
opencv-python>=4.5.0
# 示例：项目需要 Pillow（注意：ComfyUI 已内置，通常不需要）
```

### 注意事项
- ComfyUI 内置：torch, numpy, PIL/Pillow, transformers 等不需要声明
- 每行一个包名，可选版本约束
- 安装命令：`pip install -r requirements.txt`
