# 项目结构与打包

## 标准目录结构

```
ComfyUI-MyCustomNodes/
├── __init__.py              # V3 入口点（必需）
├── README.md                # 项目说明（必需）
├── requirements.txt         # 依赖声明（必需）
├── pyproject.toml           # 项目元数据（可选）
├── nodes/                   # 节点定义目录
│   ├── __init__.py
│   ├── image_nodes.py
│   ├── text_nodes.py
│   └── utils.py
├── web/                     # 前端扩展目录（WEB_DIRECTORY 声明）
│   └── my_extension.js
├── models/                  # 模型文件（可选）
└── assets/                  # 静态资源（可选）
```

## V3 入口点 __init__.py 完整模板

```python
"""
ComfyUI My Custom Nodes
V3 API 自定义节点扩展
"""
from comfy_api.latest import ComfyExtension, io
from typing_extensions import override

# 声明前端扩展目录
WEB_DIRECTORY = "./web"

# 从节点模块导入所有节点类
from .nodes.image_nodes import (
    ImageInvertNode,
    ImageBrightnessNode,
)
from .nodes.text_nodes import (
    TextConcatNode,
)

class MyCustomNodesExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [
            ImageInvertNode,
            ImageBrightnessNode,
            TextConcatNode,
        ]

async def comfy_entrypoint() -> MyCustomNodesExtension:
    return MyCustomNodesExtension()
```

## 多文件节点组织方式

当节点数量增多时，按功能拆分为多个文件：

```
nodes/
├── __init__.py          # 统一导出所有节点类
├── image_nodes.py       # 图像处理节点
├── text_nodes.py        # 文本处理节点
├── model_nodes.py       # 模型加载节点
└── utils.py             # 共享工具函数
```

`nodes/__init__.py` 示例：

```python
from .image_nodes import ImageInvertNode, ImageBrightnessNode
from .text_nodes import TextConcatNode
from .model_nodes import ModelLoaderNode

__all__ = [
    "ImageInvertNode",
    "ImageBrightnessNode",
    "TextConcatNode",
    "ModelLoaderNode",
]
```

## WEB_DIRECTORY 前端扩展目录声明

在 `__init__.py` 中声明 `WEB_DIRECTORY` 变量，ComfyUI 会自动扫描该目录下的 JS 文件并加载：

```python
# __init__.py
WEB_DIRECTORY = "./web"
```

目录结构：

```
web/
├── my_extension.js      # 主扩展文件
├── widgets/             # 自定义 Widget
│   └── color_picker.js
└── styles/              # 自定义样式
    └── custom.css
```

## 条件导入节点

当某些依赖可选时，使用 try/except 优雅降级：

```python
from comfy_api.latest import ComfyExtension, io
from typing_extensions import override

NODE_LIST = []

# 始终可用的节点
from .nodes.basic_nodes import BasicNode
NODE_LIST.append(BasicNode)

# 依赖 rembg 的节点（可选）
try:
    import rembg
    from .nodes.rembg_nodes import RembgNode
    NODE_LIST.append(RembgNode)
except ImportError:
    pass

# 依赖 insightface 的节点（可选）
try:
    import insightface
    from .nodes.face_nodes import FaceAnalysisNode
    NODE_LIST.append(FaceAnalysisNode)
except ImportError:
    pass

class MyExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return NODE_LIST

async def comfy_entrypoint() -> MyExtension:
    return MyExtension()
```

## 发布流程

1. 确保项目根目录文件夹为英文命名（如 `ComfyUI-MyCustomNodes`）
2. 确认 `__init__.py`、`README.md`、`requirements.txt` 三个必需文件存在
3. 测试所有节点在 ComfyUI 中正常加载和执行
4. 在 GitHub 创建公开仓库
5. 用户通过 `custom_nodes/` 目录下 `git clone` 安装
6. 在 ComfyUI Manager 中注册以获得可搜索性
