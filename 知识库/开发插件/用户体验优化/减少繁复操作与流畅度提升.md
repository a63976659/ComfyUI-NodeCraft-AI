# 减少繁复操作与流畅度提升

## 状态记忆与持久化

通过 `localStorage`、`sessionStorage` 或后端会话数据自动恢复用户上次的选择，避免每次打开界面都要重复设置参数、选择文件夹、勾选选项。

### 适用场景
- 用户切换标签页或刷新页面后保留上次操作上下文
- 节点参数、模型选择、文件夹路径等高频选择项

### 代码示例

```javascript
// 通用持久化工具：存取 JSON 状态
const StateStore = {
    save(key, value) {
        try {
            localStorage.setItem(key, JSON.stringify(value));
        } catch (e) {
            console.warn("[StateStore] 保存失败:", e);
        }
    },
    load(key, defaultValue = null) {
        try {
            const raw = localStorage.getItem(key);
            return raw ? JSON.parse(raw) : defaultValue;
        } catch (e) {
            return defaultValue;
        }
    }
};

// 使用：恢复上次选择的模型
const lastModel = StateStore.load("nodecraft.lastModel", "qwen2.5-coder");
modelSelect.value = lastModel;

modelSelect.addEventListener("change", (e) => {
    StateStore.save("nodecraft.lastModel", e.target.value);
});
```

### 注意事项
- key 命名加项目前缀避免与其他扩展冲突（如 `nodecraft.xxx`）
- 不要存储敏感数据（如 API 密钥明文），应通过后端加密存储
- 解析失败时降级到默认值，避免脏数据导致界面崩溃

## 智能默认值与操作合并

减少用户决策成本：根据当前上下文（已选模型、已打开项目、最近使用记录）自动填充合理默认值；将一个用户动作触发的多个关联步骤合并执行，避免用户重复点击。

### 设计原则
- 默认值必须可被用户覆盖，不要剥夺选择权
- 合并操作中任一步失败要给出明确错误并回滚，避免「半成功」状态

## 防抖与节流

针对高频触发事件（输入搜索、滚动、窗口缩放、鼠标移动）使用 debounce / throttle，避免过度计算与请求，是提升流畅度最直接的手段。

### debounce（防抖）：最后一次触发后延迟执行

适用于搜索框输入、表单校验、自动保存。

```javascript
function debounce(fn, delay = 300) {
    let timer = null;
    return function (...args) {
        clearTimeout(timer);
        timer = setTimeout(() => fn.apply(this, args), delay);
    };
}

// 知识库搜索框：用户停止输入 300ms 后才发起请求
const searchInput = document.querySelector("#kb-search");
searchInput.addEventListener("input", debounce(async (e) => {
    const results = await api.searchKnowledge(e.target.value);
    renderResults(results);
}, 300));
```

### throttle（节流）：固定时间间隔内最多执行一次

适用于滚动加载、resize、拖拽等连续触发事件。

```javascript
function throttle(fn, interval = 100) {
    let lastTime = 0;
    return function (...args) {
        const now = Date.now();
        if (now - lastTime >= interval) {
            lastTime = now;
            fn.apply(this, args);
        }
    };
}

// 会话列表无限滚动加载
sessionList.addEventListener("scroll", throttle(() => {
    if (isNearBottom(sessionList)) loadMoreSessions();
}, 200));
```

### 选择建议
- 输入类（搜索、自动保存）→ debounce
- 连续触发类（滚动、resize、拖拽）→ throttle
- 需要立即响应首次触发 → throttle 的 leading 模式或 debounce + 立即执行

## 虚拟滚动与批量 DOM 更新

长列表（>500 条）一次性渲染会导致界面卡死。虚拟滚动只渲染可视区域 DOM；DOM 更新使用 `requestAnimationFrame` 或 `DocumentFragment` 批量提交，避免多次回流重绘。

### 虚拟滚动核心思路

```javascript
class VirtualList {
    constructor(container, items, itemHeight = 48, renderItem) {
        this.container = container;
        this.items = items;
        this.itemHeight = itemHeight;
        this.renderItem = renderItem;
        this.viewport = container.clientHeight;
        this.init();
    }
    init() {
        // 占位容器撑开总高度
        this.spacer = document.createElement("div");
        this.spacer.style.height = `${this.items.length * this.itemHeight}px`;
        this.spacer.style.position = "relative";
        this.container.appendChild(this.spacer);

        this.container.addEventListener("scroll", this.onScroll.bind(this));
        this.render();
    }
    onScroll() {
        requestAnimationFrame(() => this.render());
    }
    render() {
        const scrollTop = this.container.scrollTop;
        const startIdx = Math.floor(scrollTop / this.itemHeight);
        const endIdx = Math.min(
            this.items.length,
            startIdx + Math.ceil(this.viewport / this.itemHeight) + 5
        );
        const fragment = document.createDocumentFragment();
        for (let i = startIdx; i < endIdx; i++) {
            const node = this.renderItem(this.items[i], i);
            node.style.position = "absolute";
            node.style.top = `${i * this.itemHeight}px`;
            node.style.width = "100%";
            fragment.appendChild(node);
        }
        this.spacer.innerHTML = "";
        this.spacer.appendChild(fragment);
    }
}
```

### 批量 DOM 更新

```javascript
// ❌ 错误：循环中直接操作 DOM 触发多次重排
items.forEach(item => list.appendChild(createRow(item)));

// ✅ 正确：用 DocumentFragment 一次性插入
const fragment = document.createDocumentFragment();
items.forEach(item => fragment.appendChild(createRow(item)));
list.appendChild(fragment);

// ✅ 跨帧批量更新避免阻塞
function batchUpdate(updates, batchSize = 50) {
    let i = 0;
    function next() {
        const end = Math.min(i + batchSize, updates.length);
        for (; i < end; i++) updates[i]();
        if (i < updates.length) requestAnimationFrame(next);
    }
    next();
}
```

### 适用阈值
- 列表 < 100 条：直接渲染
- 100~500 条：DocumentFragment + 分批渲染
- \> 500 条：虚拟滚动

## 错误边界与防御性编程

UI 局部异常不应导致整个面板白屏。所有外部输入（用户输入、API 响应、localStorage、URL 参数）都按「不可信」对待，加入校验、空值保护、类型检查与 try/catch 兜底。

### 局部错误边界

```javascript
function safeRender(name, renderFn, fallback = "组件加载失败") {

    } catch (e) {
        console.error(`[${name}] 渲染异常:`, e);
        const div = document.createElement("div");
        div.className = "error-fallback";
        div.textContent = fallback;
        return div;
    }
}

// 使用

```

### 网络请求容错（超时 + 重试）

```javascript
async function fetchWithRetry(url, options = {}, { retries = 2, timeout = 10000 } = {}) {
    for (let i = 0; i <= retries; i++) {
        const controller = new AbortController();
        const timer = setTimeout(() => controller.abort(), timeout);
        try {
            const res = await fetch(url, { ...options, signal: controller.signal });
            clearTimeout(timer);
            if (!res.ok) throw new Error(`HTTP ${res.status}`);
            return await res.json();
        } catch (e) {
            clearTimeout(timer);
            if (i === retries) throw e;
            await new Promise(r => setTimeout(r, 500 * (i + 1))); // 指数退避
        }
    }
}
```

### 关键防御点
- 用户输入长度上限、特殊字符过滤
- API 响应结构变化时降级到本地缓存
- 任何 JSON.parse 都要 try/catch
- 数组方法前先校验是否真是数组

## 状态一致性与事件广播

多组件共享状态时（如顶栏模型、侧边栏会话、主区消息），必须用统一的事件广播机制保证同步，避免某个组件状态过期导致用户困惑。

### 全局事件总线

```javascript
class EventBus {
    constructor() { this.listeners = new Map(); }
    on(event, fn) {
        if (!this.listeners.has(event)) this.listeners.set(event, new Set());
        this.listeners.get(event).add(fn);
        return () => this.off(event, fn); // 返回取消函数
    }
    off(event, fn) {
        this.listeners.get(event)?.delete(fn);
    }
    emit(event, payload) {
        this.listeners.get(event)?.forEach(fn => {
            try { fn(payload); } catch (e) { console.error(e); }
        });
    }
}

window.NodeCraftBus = new EventBus();
```

### 单一数据源原则
- 共享状态只允许一个组件持有「写权限」
- 其他组件只读 + 订阅事件
- 禁止直接互相调用方法修改状态

## 内存泄漏预防

前端长时间运行（ComfyUI 通常一开就是几小时）必须主动清理事件监听器、定时器、WebSocket 连接、DOM 引用，否则内存持续增长导致卡顿甚至崩溃。

### 监听器清理

```javascript
class Panel {
    constructor(root) {
        this.root = root;
        this.cleanups = []; // 收集清理函数

        const onResize = throttle(() => this.layout(), 100);
        window.addEventListener("resize", onResize);
        this.cleanups.push(() => window.removeEventListener("resize", onResize));

        const unsub = NodeCraftBus.on("model:changed", this.onModelChange);
        this.cleanups.push(unsub);

        this.timer = setInterval(() => this.refresh(), 5000);
        this.cleanups.push(() => clearInterval(this.timer));
    }
    destroy() {
        this.cleanups.forEach(fn => fn());
        this.cleanups = [];
        this.root.innerHTML = "";
        this.root = null;
    }
}
```

## ComfyUI 插件场景特定优化

针对 ComfyUI 自定义节点的运行环境，有几条特定优化路径：节点参数记忆、工作流模板一键生成、文件路径智能补全、避免阻塞主线程。

### 节点参数记忆

利用 ComfyUI 的 `app.registerExtension` 钩子，监听节点参数变化并写入 localStorage，下次创建同类节点时自动恢复。

```javascript
import { app } from "../../scripts/app.js";

const PARAM_KEY = "nodecraft.nodeParams";

app.registerExtension({
    name: "NodeCraft.ParamMemory",
    async nodeCreated(node) {
        const saved = StateStore.load(PARAM_KEY, {})[node.comfyClass];
        if (saved && node.widgets) {
            node.widgets.forEach(w => {
                if (saved[w.name] !== undefined) w.value = saved[w.name];
            });
        }

        const origOnChange = node.onWidgetChanged;
        node.onWidgetChanged = function (name, value, ...rest) {
            const all = StateStore.load(PARAM_KEY, {});
            all[node.comfyClass] = { ...(all[node.comfyClass] || {}), [name]: value };
            StateStore.save(PARAM_KEY, all);
            origOnChange?.call(this, name, value, ...rest);
        };
    }
});
```

### 避免阻塞 ComfyUI 主线程

ComfyUI 前端是单页应用，插件的扩展代码与 ComfyUI 共享主线程：

- 大量计算放入 `Web Worker`，主线程只接收结果
- 长循环用 `requestIdleCallback` 或分帧处理
- 不要在 `nodeCreated` 等高频钩子中执行重操作（同步 IO、复杂正则、JSON.parse 大字符串）
- 网络请求一律异步，绝不使用同步 XHR

```javascript
// 分帧处理大数据集
function processInIdle(items, processor) {
    let i = 0;
    function step(deadline) {
        while (i < items.length && deadline.timeRemaining() > 0) {
            processor(items[i++]);
        }
        if (i < items.length) requestIdleCallback(step);
    }
    requestIdleCallback(step);
}
```

### 注意事项
- 所有持久化 key 加 `nodecraft.` 前缀避免污染其他插件
- ComfyUI 升级可能改变内部 API，钩子代码要做兼容判断
- 前端扩展异常会被 ComfyUI 捕获但仍会污染日志，关键路径必须 try/catch
