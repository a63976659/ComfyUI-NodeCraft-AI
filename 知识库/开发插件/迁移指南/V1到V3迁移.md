# V1 到 V3 迁移

## 迁移检查清单

1. [ ] 将节点基类从 `NODE_CLASS_MAPPINGS` 字典改为 `io.ComfyNode` 继承
2. [ ] 将 `INPUT_TYPES` 类方法改为 `define_schema` 类方法
3. [ ] 将输入定义从 `required`/`optional` 字典改为 `io.Type.Input()` 对象
4. [ ] 将输出定义从元组列表改为 `io.Type.Output()` 对象
5. [ ] 将 `RETURN_TYPES` 元组替换为 `outputs` 列表
6. [ ] 将 `RETURN_NAMES` 替换为 `Output` 的命名参数
7. [ ] 将 `FUNCTION` 字符串改为 `execute` 类方法
8. [ ] 将 `CATEGORY` 字符串改为 Schema 的 `category` 字段
9. [ ] 将注册方式从 `NODE_CLASS_MAPPINGS` 改为 `ComfyExtension.get_node_list()`
10. [ ] 将入口点从模块级变量改为 `async def comfy_entrypoint()` 函数
11. [ ] 将 `IS_CHANGED` 改为 `fingerprint_inputs`
12. [ ] 将 `VALIDATE_INPUTS` 改为 `validate_inputs`
13. [ ] 将执行方法从实例方法改为 `@classmethod`
14. [ ] 将返回值从元组改为 `io.NodeOutput()`

## V1 vs V3 对比表

| 方面 | V1 | V3 |
|------|----|----|
| 基类 | 无（普通类） | `io.ComfyNode` |
| 执行方法 | 实例方法，名称由 `FUNCTION` 指定 | `execute` 类方法 |
| 输入定义 | `INPUT_TYPES` 返回字典 | `define_schema` 返回 `io.Schema` |
| 输出定义 | `RETURN_TYPES` + `RETURN_NAMES` | `outputs` 列表中 `io.Type.Output()` |
| 返回值 | 元组 | `io.NodeOutput(...)` |
| 注册 | `NODE_CLASS_MAPPINGS` 字典 | `ComfyExtension.get_node_list()` |
| 入口点 | 模块级变量 | `async def comfy_entrypoint()` |
| 状态管理 | 实例属性 | 类方法 + `cls.hidden` |
| 缓存控制 | `IS_CHANGED` | `fingerprint_inputs` |
| 输入验证 | `VALIDATE_INPUTS` | `validate_inputs` |
| 懒加载 | `check_lazy_status` + `always_execute` | `check_lazy_status` + `lazy=True` |
| 节点 ID | 类名（字典键） | `io.Schema(node_id=...)` |
| 显示名称 | `NODE_DISPLAY_NAME` | `io.Schema(display_name=...)` |

## Side-by-side 代码示例

### V1 ImageInvert

```python
class ImageInvert:
    """V1 风格的图像反转节点"""

    FUNCTION = "invert"
    CATEGORY = "image/adjust"
    RETURN_TYPES = ("IMAGE",)
    RETURN_NAMES = ("IMAGE",)
    OUTPUT_NODE = False

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "strength": ("FLOAT", {
                    "default": 1.0,
                    "min": 0.0,
                    "max": 1.0,
                    "step": 0.01,
                }),
            },
            "optional": {
                "mask": ("MASK",),
            },
        }

    @classmethod
    def IS_CHANGED(cls, image, strength, mask=None):
        return strength

    @classmethod
    def VALIDATE_INPUTS(cls, image, strength, mask=None):
        if strength < 0 or strength > 1:
            return "Strength must be between 0 and 1"
        return True

    def invert(self, image, strength, mask=None):
        result = 1.0 - image
        result = image * (1.0 - strength) + result * strength
        
        if mask is not None:
            result = image * (1 - mask.unsqueeze(-1)) + result * mask.unsqueeze(-1)
        
        return (result,)


# V1 注册方式
NODE_CLASS_MAPPINGS = {
    "ImageInvert": ImageInvert,
}

NODE_DISPLAY_NAME_MAPPINGS = {
    "ImageInvert": "Image Invert",
}
```

### V3 ImageInvert

```python
from comfy_api.latest import ComfyExtension, io
from typing_extensions import override


class ImageInvert(io.ComfyNode):
    """V3 风格的图像反转节点"""

    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="ImageInvert",
            display_name="Image Invert",
            category="image/adjust",
            description="Invert image colors with adjustable strength",
            inputs=[
                io.Image.Input("image"),
                io.Float.Input("strength", default=1.0, min=0.0, max=1.0, step=0.01),
                io.Mask.Input("mask", optional=True),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
        )

    @classmethod
    def fingerprint_inputs(cls, image, strength, mask=None):
        return strength

    @classmethod
    def validate_inputs(cls, image, strength, mask=None):
        if strength < 0 or strength > 1:
            return "Strength must be between 0 and 1"
        return True

    @classmethod
    def execute(cls, image, strength, mask=None):
        result = 1.0 - image
        result = image * (1.0 - strength) + result * strength

        if mask is not None:
            result = image * (1 - mask.unsqueeze(-1)) + result * mask.unsqueeze(-1)

        return io.NodeOutput(result)


class MyExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [ImageInvert]


async def comfy_entrypoint() -> MyExtension:
    return MyExtension()
```

## 关键迁移差异详解

### 1. 输入定义迁移

V1 字典格式：

```python
@classmethod
def INPUT_TYPES(cls):
    return {
        "required": {
            "image": ("IMAGE",),
            "strength": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 1.0, "step": 0.01}),
        },
        "optional": {
            "mask": ("MASK",),
        },
    }
```

V3 Schema 格式：

```python
@classmethod
def define_schema(cls):
    return io.Schema(
        inputs=[
            io.Image.Input("image"),
            io.Float.Input("strength", default=1.0, min=0.0, max=1.0, step=0.01),
            io.Mask.Input("mask", optional=True),
        ],
        ...
    )
```

### 2. 输出定义迁移

V1 元组格式：

```python
RETURN_TYPES = ("IMAGE", "MASK")
RETURN_NAMES = ("IMAGE", "MASK")
OUTPUT_NODE = True
```

V3 Schema 格式：

```python
outputs=[
    io.Image.Output("IMAGE"),
    io.Mask.Output("MASK"),
],
is_output_node=True,
```

### 3. 执行方法迁移

V1 实例方法：

```python
FUNCTION = "my_function"

def my_function(self, image, strength):
    # self 可访问实例属性
    return (result,)
```

V3 类方法：

```python
@classmethod
def execute(cls, image, strength):
    # cls 可访问类级属性（如 cls.hidden）
    return io.NodeOutput(result)
```

### 4. 注册方式迁移

V1 模块级变量：

```python
NODE_CLASS_MAPPINGS = {
    "ImageInvert": ImageInvert,
    "ImageBlur": ImageBlur,
}

NODE_DISPLAY_NAME_MAPPINGS = {
    "ImageInvert": "Image Invert",
    "ImageBlur": "Image Blur",
}
```

V3 ComfyExtension：

```python
class MyExtension(ComfyExtension):
    @override
    async def get_node_list(self) -> list[type[io.ComfyNode]]:
        return [ImageInvert, ImageBlur]

async def comfy_entrypoint() -> MyExtension:
    return MyExtension()
```

### 5. 缓存控制迁移

V1 `IS_CHANGED`：

```python
@classmethod
def IS_CHANGED(cls, image, seed):
    return seed
```

V3 `fingerprint_inputs`：

```python
@classmethod
def fingerprint_inputs(cls, image, seed):
    return seed
```

### 6. 输入验证迁移

V1 `VALIDATE_INPUTS`：

```python
@classmethod
def VALIDATE_INPUTS(cls, image, strength):
    if strength < 0:
        return "Strength must be non-negative"
    return True
```

V3 `validate_inputs`：

```python
@classmethod
def validate_inputs(cls, image, strength):
    if strength < 0:
        return "Strength must be non-negative"
    return True
```

## 迁移注意事项

1. **node_id 必须与旧类名一致**：迁移后 `node_id` 应与 V1 中 `NODE_CLASS_MAPPINGS` 的键相同，否则已保存的工作流会丢失节点
2. **返回值包装**：V1 返回元组 `(result,)`，V3 返回 `io.NodeOutput(result)`
3. **实例方法 → 类方法**：V3 的 `execute` 是 `@classmethod`，无法使用 `self`
4. **可选输入标记**：V1 在 `optional` 字典中定义，V3 使用 `optional=True` 参数
5. **隐藏输入访问**：V3 通过 `cls.hidden.unique_id` 访问，而非参数传递
6. **前端扩展**：`WEB_DIRECTORY` 声明方式不变，JS 扩展代码通常不需要修改
