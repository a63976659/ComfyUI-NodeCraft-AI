# 输入类型详解

## Widget 输入类型

Widget 输入在 UI 上渲染为控件，不显示连接端口。

### INT - 整数输入

```python
io.Int.Input("seed", default=0, min=0, max=0xffffffffffffffff, step=1)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| default | int | 0 | 默认值 |
| min | int | 0 | 最小值 |
| max | int | 0xffffffffffffffff | 最大值 |
| step | int | 1 | 步进值 |

### FLOAT - 浮点数输入

```python
io.Float.Input("strength", default=1.0, min=0.0, max=1.0, step=0.01)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| default | float | 0.0 | 默认值 |
| min | float | 0.0 | 最小值 |
| max | float | 1.0 | 最大值 |
| step | float | 0.01 | 步进值 |

### STRING - 字符串输入

```python
io.String.Input("prompt", default="", multiline=True, dynamic_prompts=True)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| default | str | "" | 默认值 |
| multiline | bool | False | 多行文本框 |
| dynamic_prompts | bool | False | 启用动态提示词语法 |

### COMBO - 下拉选择输入

```python
io.Combo.Input("sampler", choices=["euler", "euler_ancestral", "dpmpp_2m"], default="euler")
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| choices | list | 必需 | 选项列表 |
| default | str | 首项 | 默认选中项 |

### BOOLEAN - 布尔开关

```python
io.Boolean.Input("enabled", default=True)
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| default | bool | False | 默认值 |

### COLOR - 颜色选择器

```python
io.Color.Input("fill_color", default="#000000")
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | str | 必需 | 输入名称 |
| default | str | "#000000" | 默认颜色（十六进制） |

## 高级选项

所有输入类型都支持以下高级选项：

### optional - 可选输入

可选输入在没有连接时不传值，函数参数需设默认值 `None`：

```python
io.Image.Input("reference", optional=True)

@classmethod
def execute(cls, image, reference=None):
    if reference is not None:
        image = image * 0.5 + reference * 0.5
    return io.NodeOutput(image)
```

### lazy - 懒加载输入

懒加载输入仅在 `check_lazy_status` 请求时才计算，用于条件性依赖：

```python
io.Image.Input("secondary", lazy=True, optional=True)
```

### advanced - 高级选项

将输入移入 Advanced 折叠面板：

```python
io.Float.Input("epsilon", default=1e-5, advanced=True)
```

### socketless - 无连接端口

仅显示 Widget 控件，不显示连接端口（纯 UI 控件）：

```python
io.Boolean.Input("preview_only", default=False, socketless=True)
```

### hidden - 隐藏输入

在 UI 上完全隐藏，由服务器端提供：

```python
# 在 Schema 中声明
hidden=[io.Hidden.unique_id, io.Hidden.prompt, io.Hidden.extra_pnginfo]
```

## 连接输入类型

连接输入在 UI 上显示为可连接的端口。

### Image - 图像输入

```python
io.Image.Input("image")
```

接收 `[B, H, W, C]` float32 张量，范围 0-1。

### Mask - 掩膜输入

```python
io.Mask.Input("mask")
```

接收 `[B, H, W]` float32 张量，范围 0-1。

### Latent - 潜空间输入

```python
io.Latent.Input("latent")
```

接收字典 `{"samples": [B, C, H, W] float32}`。

### Conditioning - 条件输入

```python
io.Conditioning.Input("positive")
io.Conditioning.Input("negative")
```

接收条件列表（包含 prompt embeds 和其他元数据）。

### Audio - 音频输入

```python
io.Audio.Input("audio")
```

接收字典 `{"waveform": [B, C, T], "sample_rate": int}`。

### Model - 模型输入

```python
io.Model.Input("model")
```

接收模型包装对象（ModelPatcher）。

### Clip - CLIP 输入

```python
io.Clip.Input("clip")
```

接收 CLIP 模型对象。

### Vae - VAE 输入

```python
io.Vae.Input("vae")
```

接收 VAE 模型对象。

### AnyType - 任意类型输入

```python
io.AnyType.Input("input", display_name="Any")
```

接受任意类型数据，用于通用转发或路由节点。

## 隐藏输入

隐藏输入由服务器自动提供，不在 UI 上显示：

| 隐藏输入 | 类型 | 说明 |
|----------|------|------|
| `io.Hidden.unique_id` | str | 当前节点实例的唯一 ID |
| `io.Hidden.prompt` | dict | 完整的工作流提示词 |
| `io.Hidden.extra_pnginfo` | dict | 工作流元数据（节点位置、连线等） |
| `io.Hidden.unique_id` | int | 节点 ID（数字形式） |

### 访问隐藏输入

```python
class MyNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="MyNode",
            inputs=[
                io.Image.Input("image"),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
            hidden=[io.Hidden.unique_id, io.Hidden.prompt],
        )

    @classmethod
    def execute(cls, image):
        node_id = cls.hidden.unique_id
        prompt = cls.hidden.prompt
        # 使用隐藏输入...
        return io.NodeOutput(image)
```

## 懒加载输入完整示例

懒加载允许节点在运行时决定是否需要某个输入的值，避免不必要的计算。

```python
class LazyNode(io.ComfyNode):
    @classmethod
    def define_schema(cls):
        return io.Schema(
            node_id="LazyNode",
            display_name="Lazy Input Demo",
            category="example",
            inputs=[
                io.Image.Input("image"),
                io.Boolean.Input("use_secondary", default=False),
                io.Image.Input("secondary", optional=True, lazy=True),
            ],
            outputs=[
                io.Image.Output("IMAGE"),
            ],
        )

    @classmethod
    def check_lazy_status(cls, image, use_secondary, secondary=None):
        # 仅当 use_secondary 为 True 时才请求 secondary 输入
        if use_secondary and secondary is None:
            return ["secondary"]
        return []

    @classmethod
    def execute(cls, image, use_secondary, secondary=None):
        if use_secondary and secondary is not None:
            result = image * 0.5 + secondary * 0.5
        else:
            result = image
        return io.NodeOutput(result)
```

### 懒加载工作流程

1. ComfyUI 调用 `check_lazy_status()` 获取需要求值的输入列表
2. 仅对列表中的输入执行上游节点计算
3. 将计算结果传入 `execute()`
4. 未请求的懒加载输入保持 `None`

### 懒加载最佳实践

- 懒加载输入必须同时设置 `optional=True`
- `check_lazy_status` 返回的是输入名称字符串列表
- 在 `execute` 中始终检查懒加载输入是否为 `None`
- 懒加载适合昂贵的计算分支（如模型加载、大图处理）
