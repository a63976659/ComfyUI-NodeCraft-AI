# 数据类型系统

## 张量/数据类型完整表格

| 类型 | 格式 | 数据类型 | 范围 | 说明 |
|------|------|----------|------|------|
| IMAGE | [B, H, W, C] | float32 | 0.0 - 1.0 | RGB/RGBA 图像，C=3 或 4 |
| MASK | [B, H, W] | float32 | 0.0 - 1.0 | 掩膜/蒙版 |
| LATENT | dict | - | - | `{"samples": [B, C, H, W]}` |
| CONDITIONING | list | - | - | 条件列表，含 embeds 和元数据 |
| AUDIO | dict | - | - | `{"waveform": [B, C, T], "sample_rate": int}` |
| VIDEO | dict | - | - | `{"frames": [B, H, W, C], "fps": float}` |
| SIGMAS | [N] | float32 | 任意 | 去噪步长序列 |
| NOISE | [B, C, H, W] | float32 | 任意 | 噪声张量 |

### IMAGE 详细说明

```python
# 图像张量格式: [Batch, Height, Width, Channels]
# Batch: 批次大小（通常为 1）
# Height, Width: 图像尺寸
# Channels: 3 (RGB) 或 4 (RGBA)

# 从 PIL 转换为 ComfyUI 张量
import numpy as np
from PIL import Image as PILImage

pil_image = PILImage.open("photo.jpg")
image_np = np.array(pil_image).astype(np.float32) / 255.0
image_tensor = torch.from_numpy(image_np).unsqueeze(0)  # [1, H, W, C]

# 从 ComfyUI 张量转换回 PIL
image_np = (image_tensor[0].cpu().numpy() * 255).clip(0, 255).astype(np.uint8)
pil_image = PILImage.fromarray(image_np)
```

### LATENT 详细说明

```python
# 潜空间格式: {"samples": [B, C, H, W]}
# B: 批次大小
# C: 潜空间通道数（通常为 4）
# H, W: 潜空间尺寸（为图像尺寸的 1/8）

latent = {"samples": latent_tensor}  # [B, 4, H/8, W/8]
```

### AUDIO 详细说明

```python
# 音频格式: {"waveform": [B, C, T], "sample_rate": int}
# B: 批次大小
# C: 通道数（1=单声道, 2=立体声）
# T: 采样点数量

audio = {
    "waveform": waveform_tensor,  # [1, 2, 44100] 表示1批2通道44100采样
    "sample_rate": 44100,
}
```

## 张量安全操作规范

### ⚠ 切勿用 if tensor 做判断

```python
# 错误 - 张量可能包含零值，行为不可预期
if mask:
    result = image * mask.unsqueeze(-1)

# 正确 - 使用 is not None 判断
if mask is not None:
    result = image * mask.unsqueeze(-1)

# 正确 - 使用布尔方法判断内容
if mask.any():
    result = image * mask.unsqueeze(-1)
```

### 张量维度操作

```python
# MASK [B, H, W] → 扩展为 IMAGE 兼容 [B, H, W, C]
mask_3ch = mask.unsqueeze(-1).expand(-1, -1, -1, 3)

# IMAGE [B, H, W, C] → 转 MASK [B, H, W]
mask = image.mean(dim=-1)  # RGB 平均值

# 确保维度正确
assert image.dim() == 4, f"Expected 4D tensor, got {image.dim()}D"
assert image.shape[-1] in (3, 4), f"Expected 3 or 4 channels, got {image.shape[-1]}"
```

## 张量转换模式

### IMAGE ↔ MASK 转换

```python
# IMAGE → MASK (灰度)
mask = image[:, :, :, 0] * 0.299 + image[:, :, :, 1] * 0.587 + image[:, :, :, 2] * 0.114

# IMAGE → MASK (Alpha 通道)
mask = image[:, :, :, 3]  # 仅 RGBA 图像

# MASK → IMAGE (单色)
image = mask.unsqueeze(-1).expand(-1, -1, -1, 3)
```

### 调整图像尺寸

```python
import torch.nn.functional as F

# 双线性插值
resized = F.interpolate(
    image.permute(0, 3, 1, 2),  # [B, C, H, W]
    size=(new_h, new_w),
    mode="bilinear",
    align_corners=False,
).permute(0, 2, 3, 1)  # [B, H, W, C]

# 最近邻插值（用于掩膜）
resized_mask = F.interpolate(
    mask.unsqueeze(1),  # [B, 1, H, W]
    size=(new_h, new_w),
    mode="nearest",
).squeeze(1)  # [B, H, W]
```

### LATENT ↔ IMAGE 转换

```python
# 潜空间 → 图像需要 VAE 解码
decoded = vae.decode(latent["samples"])

# 图像 → 潜空间需要 VAE 编码
encoded = vae.encode(image)
latent = {"samples": encoded}
```

## 常见错误和解决方案

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `RuntimeError: expected scalar type Float but found Half` | 数据类型不匹配 | 使用 `.float()` 转换 |
| `ValueError: not enough values to unpack` | 输出数量不匹配 | 检查 `NodeOutput` 参数数量与 `outputs` 一致 |
| 图像全黑/全白 | 张量范围错误 | 确认 float32 范围 0-1，非 0-255 |
| 维度不匹配 | IMAGE 是 NHWC 而非 NCHW | 注意 ComfyUI 使用 `[B, H, W, C]` 格式 |
| 掩膜应用失败 | MASK 缺少通道维度 | 使用 `mask.unsqueeze(-1)` 扩展 |
| `if tensor` 判断异常 | 张量真值判断不明确 | 使用 `tensor is not None` |
| CUDA 内存不足 | 大批次或高分辨率 | 减小 batch_size，使用 `.cpu()` 处理 |
