# 输出类型详解

## 基础输出

### 单输出

```python
io.Image.Output("IMAGE")
```

### 多输出

```python
outputs=[
    io.Image.Output("IMAGE"),
    io.Mask.Output("MASK"),
]
```

多输出时，`execute` 返回的 `NodeOutput` 按顺序对应各输出：

```python
@classmethod
def execute(cls, image):
    mask = image.mean(dim=-1)
    return io.NodeOutput(image, mask)
```

### 仅 UI 输出

输出仅用于 UI 预览，不被下游节点消费：

```python
io.Image.Output("PREVIEW", ui_preview=True)
```

### 数据 + UI 输出

同时输出数据（供下游节点使用）和 UI 预览：

```python
io.Image.Output("IMAGE", ui_preview=True)
```

## UI 预览助手

ComfyUI 提供内置预览助手，在节点上直接显示输出预览。

### PreviewImage - 图像预览

```python
from comfy_api.latest import io

@classmethod
def execute(cls, image):
    preview = io.PreviewImage(image)
    return io.NodeOutput(image, ui=preview)
```

### PreviewMask - 掩膜预览

```python
preview = io.PreviewMask(mask)
return io.NodeOutput(mask, ui=preview)
```

### PreviewAudio - 音频预览

```python
preview = io.PreviewAudio(waveform, sample_rate)
return io.NodeOutput(audio_dict, ui=preview)
```

### PreviewVideo - 视频预览

```python
preview = io.PreviewVideo(frames, fps=24)
return io.NodeOutput(video_dict, ui=preview)
```

### PreviewText - 文本预览

```python
preview = io.PreviewText(text)
return io.NodeOutput(text, ui=preview)
```

### PreviewUI3D - 3D 预览

```python
preview = io.PreviewUI3D(mesh_data)
return io.NodeOutput(mesh_data, ui=preview)
```

## 图像保存

### ImageSaveHelper.save_images

将图像张量保存为文件：

```python
from comfy_api.latest import io, ImageSaveHelper

@classmethod
def execute(cls, image, filename_prefix="ComfyUI"):
    saved = ImageSaveHelper.save_images(
        images=image,                    # [B, H, W, C] tensor
        filename_prefix=filename_prefix, # 文件名前缀
        folder=io.FolderType.OUTPUT,     # 保存目录类型
    )
    return io.NodeOutput(ui=saved)
```

### get_save_images_ui

获取保存图像的 UI 信息（不实际保存）：

```python
ui_info = ImageSaveHelper.get_save_images_ui(images=image, filename_prefix="preview")
```

### save_animated_png

保存动画 PNG：

```python
saved = ImageSaveHelper.save_animated_png(
    images=frames,             # [B, H, W, C] tensor (B 为帧数)
    filename_prefix="anim",
    fps=8,
    folder=io.FolderType.OUTPUT,
)
```

### save_animated_webp

保存动画 WebP：

```python
saved = ImageSaveHelper.save_animated_webp(
    images=frames,
    filename_prefix="anim",
    fps=12,
    quality=80,
    lossless=False,
    folder=io.FolderType.OUTPUT,
)
```

## 音频保存

### AudioSaveHelper.save_audio

将音频数据保存为 WAV 文件：

```python
from comfy_api.latest import io, AudioSaveHelper

@classmethod
def execute(cls, audio):
    saved = AudioSaveHelper.save_audio(
        waveform=audio["waveform"],  # [B, C, T] tensor
        sample_rate=audio["sample_rate"],
        filename_prefix="ComfyUI",
        folder=io.FolderType.OUTPUT,
    )
    return io.NodeOutput(ui=saved)
```

### get_save_audio_ui

获取保存音频的 UI 信息：

```python
ui_info = AudioSaveHelper.get_save_audio_ui(waveform=waveform, sample_rate=sr)
```

## FolderType - 保存目录类型

| 类型 | 路径 | 说明 |
|------|------|------|
| `io.FolderType.OUTPUT` | ComfyUI/output/ | 默认输出目录 |
| `io.FolderType.TEMP` | ComfyUI/temp/ | 临时文件目录 |
| `io.FolderType.INPUT` | ComfyUI/input/ | 输入文件目录 |

### 自定义输出目录

```python
import folder_paths

# 获取输出目录路径
output_dir = folder_paths.get_output_directory()
temp_dir = folder_paths.get_temp_directory()

# 添加自定义模型目录
folder_paths.add_model_folder_path("my_models", "/path/to/models")
```

## NodeOutput 完整用法

```python
# 基础输出
return io.NodeOutput(result)

# 多输出
return io.NodeOutput(image, mask)

# 带 UI 预览
return io.NodeOutput(image, ui=io.PreviewImage(image))

# 阻塞后续执行
return io.NodeOutput(block_execution="Reason for blocking")

# 带元数据
return io.NodeOutput(result, metadata={"custom_key": "value"})
```
