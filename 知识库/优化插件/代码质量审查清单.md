# 代码质量审查清单

## 概述

本清单用于 ComfyUI 插件代码的质量审查，涵盖 Python 代码规范、ComfyUI 节点规范、安全性、性能和可维护性五个维度。每项均提供"合格"与"不合格"示例对比，便于快速定位问题。

---

## 一、Python 代码规范

### 1.1 命名规范

| 检查项 | 要求 |
|--------|------|
| 类名 | PascalCase，如 `ImageFilterNode` |
| 函数/方法名 | snake_case，如 `apply_filter` |
| 常量 | UPPER_SNAKE_CASE，如 `MAX_BATCH_SIZE` |
| 私有成员 | 前缀下划线，如 `_internal_cache` |
| 业务文件名 | 允许中文命名（如 `图像处理.py`），插件根目录必须英文 |

**合格示例**：
```python
class ImageResizerNode:
    MAX_RESOLUTION = 8192

    def __init__(self):
        self._cache = {}

    def _calculate_scale(self, source, target):
        return target / source
```

**不合格示例**：
```python
class imageResizer:          # 类名应 PascalCase
    MaxResolution = 8192      # 常量应全大写

    def __init__(self):
        self.cache = {}       # 私有成员应加下划线

    def CalculateScale(self, source, target):  # 方法名应 snake_case
        return target / source
```

### 1.2 类型提示

| 检查项 | 要求 |
|--------|------|
| 函数签名 | 必须标注参数和返回值类型 |
| 可选参数 | 使用 `Optional[T]` 或 `T \| None` |
| 容器类型 | 使用泛型标注，如 `list[str]` 而非 `list` |

**合格示例**：
```python
def process_batch(
    images: list[torch.Tensor],
    scale_factor: float = 1.0,
    device: Optional[str] = None
) -> torch.Tensor:
    ...
```

**不合格示例**：
```python
def process_batch(images, scale_factor=1.0, device=None):
    # 缺少类型提示，无法推断参数类型
    ...
```

### 1.3 文档字符串

| 检查项 | 要求 |
|--------|------|
| 类定义 | 必须有 docstring，说明节点功能 |
| 公开方法 | 必须有 docstring，说明参数和返回值 |
| 复杂逻辑 | 关键算法应有行内注释 |

**合格示例**：
```python
class ColorGradingNode:
    """色彩分级节点 - 通过 LUT 应用电影级调色。

    支持 .cube 格式 LUT 文件，自动适配输入色彩空间。
    """

    @classmethod
    def execute(cls, image: torch.Tensor, lut_path: str, intensity: float) -> torch.Tensor:
        """应用 LUT 色彩分级。

        Args:
            image: 输入图像张量 [B, H, W, C]，范围 0-1
            lut_path: .cube 格式 LUT 文件路径
            intensity: 混合强度，0.0=原图，1.0=完全应用

        Returns:
            调色后的图像张量 [B, H, W, C]
        """
        ...
```

**不合格示例**：
```python
class ColorGradingNode:
    # 无 docstring

    def execute(cls, image, lut_path, intensity):
        # 无 docstring，参数含义不明
        ...
```

## 二、ComfyUI 节点规范

### 2.1 INPUT_TYPES / RETURN_TYPES / Function 对齐

| 检查项 | 要求 |
|--------|------|
| INPUT_TYPES | 必须返回含 `required` 键的字典 |
| RETURN_TYPES | 元组长度必须与 execute 返回值一致 |
| FUNCTION | 字符串值必须与实际方法名一致 |
| CATEGORY | 必须设置合理的分类路径 |

**合格示例**：
```python
class BlurNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "radius": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 50.0, "step": 0.1}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "apply_blur"
    CATEGORY = "image/filter"

    def apply_blur(self, image, radius):
        # 返回单个值，与 RETURN_TYPES 的 1 个元素对齐
        return (blurred_image,)
```

**不合格示例**：
```python
class BlurNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {"required": {"image": ("IMAGE",), "radius": ("FLOAT", {})}}
        # 缺少 default/min/max/step

    RETURN_TYPES = ("IMAGE", "MASK")  # 声明 2 个返回值
    FUNCTION = "blur"                  # 但方法名是 apply_blur，不匹配

    def apply_blur(self, image, radius):
        return blurred_image           # 返回 1 个值，与 RETURN_TYPES 不匹配
                                        # 且未用元组包裹
```

### 2.2 节点注册

| 检查项 | 要求 |
|--------|------|
| NODE_CLASS_MAPPINGS | 键为节点 ID（英文），值为类 |
| NODE_DISPLAY_NAME_MAPPINGS | 键与 NODE_CLASS_MAPPINGS 一致 |
| __all__ | 包含所有需要导出的变量 |

**合格示例**：
```python
from .逻辑处理模块.模糊处理 import BlurNode

NODE_CLASS_MAPPINGS = {
    "BlurNode": BlurNode,
}
NODE_DISPLAY_NAME_MAPPINGS = {
    "BlurNode": "图像模糊",
}
__all__ = ['NODE_CLASS_MAPPINGS', 'NODE_DISPLAY_NAME_MAPPINGS', 'WEB_DIRECTORY']
```

**不合格示例**：
```python
NODE_CLASS_MAPPINGS = {"blur": BlurNode}        # 键名不一致
NODE_DISPLAY_NAME_MAPPINGS = {"BlurNode": "模糊"}  # 键名与上面不匹配
# 缺少 __all__
```

### 2.3 IS_CHANGED 实现

| 检查项 | 要求 |
|--------|------|
| 返回值类型 | 必须是可哈希的（str/int/float/tuple） |
| 稳定性 | 相同输入必须返回相同值 |
| NaN 特殊值 | 仅用于需要每次重新执行的场景 |

**合格示例**：
```python
@classmethod
def IS_CHANGED(cls, image, seed):
    return (int(image.sum().item()), seed)
```

**不合格示例**：
```python
@classmethod
def IS_CHANGED(cls, image, seed):
    return {"image": image, "seed": seed}  # dict 不可哈希
```

## 三、安全性检查

### 3.1 输入验证

| 检查项 | 要求 |
|--------|------|
| 数值范围 | INPUT_TYPES 中设置 min/max/step |
| 字符串长度 | 对用户输入的字符串验证长度 |
| 文件路径 | 验证路径在允许范围内 |
| 枚举值 | 使用 COMBO 限制可选值 |

**合格示例**：
```python
@classmethod
def INPUT_TYPES(cls):
    return {
        "required": {
            "image": ("IMAGE",),
            "output_dir": ("STRING", {"default": "./output"}),
            "format": (["png", "jpg", "webp"],),  # COMBO 限制枚举
            "quality": ("INT", {"default": 90, "min": 1, "max": 100, "step": 1}),
        }
    }

import os
from pathlib import Path

def save_images(self, image, output_dir, format, quality):
    # 路径遍历防护
    base = Path(output_dir).resolve()
    allowed_base = Path("./output").resolve()
    if not str(base).startswith(str(allowed_base)):
        raise ValueError("输出路径超出允许范围")

    # 文件扩展名白名单
    if format not in ("png", "jpg", "webp"):
        raise ValueError(f"不支持的格式: {format}")
```

**不合格示例**：
```python
@classmethod
def INPUT_TYPES(cls):
    return {
        "required": {
            "path": ("STRING", {"default": ""}),  # 无任何验证
        }
    }

def save_images(self, image, path):
    # 直接使用用户输入路径，存在路径遍历风险
    with open(path, "wb") as f:
        f.write(image.numpy().tobytes())
```

### 3.2 路径遍历防护

| 检查项 | 要求 |
|--------|------|
| 路径解析 | 使用 `Path.resolve()` 获取绝对路径 |
| 范围检查 | 使用 `is_relative_to()` 或 `startswith` 验证 |
| 符号链接 | 注意符号链接可能绕过检查 |

**合格示例**：
```python
def safe_read_file(file_path: str, allowed_dir: str = "./data") -> bytes:
    target = Path(file_path).resolve()
    base = Path(allowed_dir).resolve()
    if not target.is_relative_to(base):
        raise PermissionError(f"路径 {file_path} 超出允许目录")
    return target.read_bytes()
```

**不合格示例**：
```python
def unsafe_read_file(file_path: str) -> bytes:
    # 无任何防护，可读取任意文件
    return open(file_path, "rb").read()
```

### 3.3 代码注入防护

| 检查项 | 要求 |
|--------|------|
| eval/exec | 禁止使用 `eval()` / `exec()` 处理用户输入 |
| subprocess | 使用参数列表而非 shell=True |
| pickle | 禁止加载不受信任的 pickle 文件 |

**合格示例**：
```python
import subprocess

def run_tool(tool_path: str, args: list[str]) -> str:
    result = subprocess.run(
        [tool_path] + args,  # 参数列表形式
        capture_output=True,
        text=True,
        timeout=30
    )
    return result.stdout
```

**不合格示例**：
```python
import subprocess

def run_tool(user_input: str) -> str:
    # shell=True + 字符串拼接 = 命令注入
    return subprocess.run(
        f"tool {user_input}",
        shell=True,
        capture_output=True,
        text=True
    ).stdout
```

## 四、性能检查

### 4.1 异步 I/O

| 检查项 | 要求 |
|--------|------|
| 网络请求 | 使用 aiohttp 异步而非 requests 同步 |
| 文件 I/O | 大文件使用流式读取 |
| 并发控制 | 使用 Semaphore 限制并发数 |

**合格示例**：
```python
import aiohttp
import asyncio

async def fetch_multiple(urls: list[str], max_concurrent: int = 5) -> list[dict]:
    semaphore = asyncio.Semaphore(max_concurrent)

    async def fetch_one(session, url):
        async with semaphore:
            async with session.get(url) as resp:
                return await resp.json()

    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*[fetch_one(session, u) for u in urls])
```

**不合格示例**：
```python
import requests  # 同步阻塞库

def fetch_multiple(urls):
    results = []
    for url in urls:              # 串行请求
        resp = requests.get(url)  # 阻塞整个事件循环
        results.append(resp.json())
    return results
```

### 4.2 内存管理

| 检查项 | 要求 |
|--------|------|
| 推理上下文 | 使用 `torch.inference_mode()` 或 `no_grad()` |
| 中间张量 | 处理完成后及时 `del` |
| 模型缓存 | 使用类级别缓存，避免重复加载 |
| 批处理 | 合并小操作，减少 GPU 调用次数 |

**合格示例**：
```python
class OptimizedNode:
    _model = None

    @classmethod
    def _get_model(cls):
        if cls._model is None:
            cls._model = load_model().eval()
        return cls._model

    def execute(self, image):
        model = self._get_model()
        with torch.inference_mode():
            output = model(image.cuda())
        result = output.cpu()
        del output
        return (result,)
```

**不合格示例**：
```python
class SlowNode:
    def execute(self, image):
        model = load_model()  # 每次都重新加载
        output = model(image) # 没有推理上下文
        return (output,)       # 中间张量未释放
```

### 4.3 GPU 利用率

| 检查项 | 要求 |
|--------|------|
| 数据传输 | 避免循环内 CPU↔GPU 频繁传输 |
| 半精度 | 推理时使用 FP16 或 autocast |
| 同步 | 避免不必要的 `torch.cuda.synchronize()` |

**合格示例**：
```python
def batch_inference(images: list[torch.Tensor], model) -> torch.Tensor:
    # 一次性传输到 GPU
    batch = torch.stack(images).cuda()
    with torch.inference_mode(), torch.autocast("cuda", dtype=torch.float16):
        output = model(batch)
    return output.cpu()  # 一次性传回
```

**不合格示例**：
```python
def slow_inference(images, model):
    results = []
    for img in images:
        img_gpu = img.cuda()      # 循环内传输
        output = model(img_gpu)
        results.append(output.cpu())  # 循环内传输
    return torch.stack(results)
```

## 五、可维护性检查

### 5.1 错误处理

| 检查项 | 要求 |
|--------|------|
| 异常捕获 | 捕获具体异常而非裸 `except:` |
| 错误信息 | 提供有意义的错误消息 |
| 资源释放 | 使用 `with` 或 `try/finally` 确保释放 |

**合格示例**：
```python
def load_lut(path: str) -> torch.Tensor:
    try:
        lut_file = Path(path)
        if not lut_file.exists():
            raise FileNotFoundError(f"LUT 文件不存在: {path}")
        if lut_file.suffix != ".cube":
            raise ValueError(f"仅支持 .cube 格式，得到: {lut_file.suffix}")
        return _parse_cube_file(lut_file)
    except (FileNotFoundError, ValueError) as e:
        raise  # 重新抛出已知异常
    except Exception as e:
        raise RuntimeError(f"加载 LUT 失败: {e}") from e
```

**不合格示例**：
```python
def load_lut(path):
    try:
        f = open(path)
        data = f.read()
        f.close()  # 没有 with，异常时不会关闭
        return parse(data)
    except:         # 裸 except 吞掉所有异常
        pass        # 静默失败
```

### 5.2 日志记录

| 检查项 | 要求 |
|--------|------|
| 日志级别 | 使用恰当的级别（DEBUG/INFO/WARNING/ERROR） |
| 关键操作 | 文件读写、模型加载、网络请求应有日志 |
| 敏感信息 | 禁止在日志中输出密钥、Token 等 |

**合格示例**：
```python
import logging

logger = logging.getLogger("MyPlugin")

class ModelLoader:
    def load(self, model_path: str):
        logger.info("加载模型: %s", model_path)
        try:
            model = torch.load(model_path)
            logger.debug("模型加载成功，参数量: %d", sum(p.numel() for p in model.parameters()))
            return model
        except Exception as e:
            logger.error("模型加载失败 [%s]: %s", model_path, e)
            raise
```

**不合格示例**：
```python
import logging

logger = logging.getLogger("MyPlugin")

def load(model_path, api_key):
    logger.info("加载模型: %s, API Key: %s", model_path, api_key)  # 泄露密钥！
    # 或使用 print 而非 logging
    print(f"加载模型: {model_path}")
```

### 5.3 配置管理

| 检查项 | 要求 |
|--------|------|
| 魔法数字 | 提取为常量或 INPUT_TYPES 参数 |
| 硬编码路径 | 使用 `folder_paths` 或相对路径 |
| 环境变量 | 敏感配置通过环境变量传入 |

**合格示例**：
```python
import os
from pathlib import Path

# 常量集中管理
DEFAULT_TILE_SIZE = 512
DEFAULT_OVERLAP = 64
MAX_RESOLUTION = int(os.environ.get("MYPLUGIN_MAX_RES", "8192"))

def get_model_dir() -> Path:
    """使用 ComfyUI 的 folder_paths 获取模型目录"""
    import folder_paths
    return Path(folder_paths.models_dir) / "myplugin"
```

**不合格示例**：
```python
def process(image):
    tile_size = 512        # 魔法数字
    overlap = 64           # 魔法数字
    model_path = "C:/ComfyUI/models/myplugin/model.pth"  # 硬编码路径
    api_key = "sk-xxxxx"   # 硬编码密钥
```

## 审查流程建议

1. **自审**：开发者提交前按本清单逐项检查
2. **交叉审查**：由另一位开发者复核
3. **工具辅助**：使用 `pylint` / `mypy` 进行静态分析
4. **功能验证**：在 ComfyUI 中实际运行节点确认功能正常
5. **性能验证**：对耗时节点使用 `benchmark()` 测量执行时间

```bash
# 静态分析命令示例
python -m pylint 后端/ --rcfile=.pylintrc
python -m mypy 后端/ --ignore-missing-imports
python -c "import ast, pathlib; [ast.parse(f.read_text('utf-8')) for f in pathlib.Path('后端').glob('*.py')]"
```
