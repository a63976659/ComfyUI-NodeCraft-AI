# 插件性能优化指南

## 概述
ComfyUI 插件的性能优化是提升用户体验的关键。本文档介绍常用的优化策略和工具。

## 节点执行优化

### 减少不必要的计算
- 使用 `IS_CHANGED()` 方法控制节点重新执行的时机
- 对于输入未变化的节点，跳过重复计算
- 合理使用缓存避免相同参数的重复推理

### 批量处理
- 对多张图片使用批量处理而非逐张处理
- 合并相似操作减少 CPU/GPU 切换开销

### 异步处理
- 长时间运行的操作应显示进度条
- 使用 `tqdm` 或 ComfyUI 的进度回调
- 考虑将大任务拆分为可中断的子任务

## 内存管理

### 张量释放
- 及时释放不再使用的中间张量
- 使用 `del` 和 `torch.cuda.empty_cache()` 释放显存
- 避免在循环中累积张量

### 模型加载优化
- 模型按需加载，避免启动时全部加载
- 使用单例模式共享模型实例
- 考虑模型的 VRAM 占用和推理速度权衡

## 前端性能

### 减少重渲染
- 使用 `shouldUpdate` 或 `memo` 避免不必要的节点重渲染
- 图片预览使用缩略图而非全尺寸
- 大量节点时使用虚拟列表

### 数据传输优化
- 大文件使用流式传输
- 图片使用合适的压缩格式
- 避免频繁的小请求（使用批量 API）

## 性能监控

### 使用 ComfyUI 内置工具
- 启用执行时间日志记录
- 使用 `comfyui --verbose` 查看详细性能信息
- 关注节点的 `FUNCTION` 执行时间

### 自定义性能检测
```python
import time

class MyNode:
    def execute(self, **kwargs):
        start = time.time()
        result = self._heavy_computation(**kwargs)
        elapsed = time.time() - start
        print(f"[性能] 执行耗时: {elapsed:.2f}秒")
        return result
```

## 常见性能问题与解决

### 节点执行缓慢
- 检查是否有重复计算
- 检查是否加载了不必要的模型
- 使用 profiler 定位热点函数

### 内存泄漏
- 检查张量是否正确释放
- 使用 `torch.cuda.memory_allocated()` 监控显存
- 避免全局变量持有大对象

### 前端卡顿
- 减少实时预览的更新频率
- 使用 web worker 处理复杂计算
- 优化自定义 Widget 的渲染逻辑
